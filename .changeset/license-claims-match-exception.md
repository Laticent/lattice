The README's license section now says exactly what the Lattice Output Exception covers, and what it does not.

It used to say every rendered deck was "yours outright" and that publishing one on a web server imposed nothing. The exception covers only the engine assets that Lattice's own export pipeline embeds into a deck. It does not cover a modified engine, or HTML that another tool such as marp-cli builds from Lattice's files. The section now lists those limits. The comparison page says the same, and no longer says the engine is at v1.
