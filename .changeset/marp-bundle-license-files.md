An Export-to-Marp bundle now carries Lattice's own license and its Output Exception, so the people you send it to can read the terms that cover them.

The bundle shipped the engine's stylesheet and runtime with only the third-party license texts. It now ships the AGPL-3.0 text and the Lattice Output Exception 1.2, which covers a deck that Marp CLI or Marp for VS Code renders from the bundle, and its README lists both. The Marp kit already carried them; both now take them from the same list.
