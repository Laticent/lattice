# kpi: wrap the supports so the row count leaves CSS — retire the :has(nth-child) thresholds

## Summary

`kpi`'s briefing/spotlight grids now key their row **count** on the authored metric count via `:has(> li:nth-child(N))`. It works and is tested, but it puts a content count inside CSS — the first rule of its kind in the engine. Wrapping the supports in one element in the shared transform removes counts from CSS entirely and makes any metric count work with no thresholds.

## Swimlane

`engineering/decisions/2026-07-30-overflow-marker-register.md` § "Follow-up (2026-08-02) — #1277" — where the count-aware rows were introduced and this alternative was named as the cheaper structural answer.
