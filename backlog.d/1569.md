# lint: flag a `---`-delimited YAML block below offset 0 — the stray front matter that costs a slide

## Summary

Add a `lint-core.js` rule that flags a `---`-delimited YAML block appearing **below offset 0** — a stray front-matter block in the body of a deck. Today nothing tells the author, and the render can only refuse.

## Why now

Split out of #1551 under HARD RULE #17. That fix stops the preview from silently destroying a slide when this shape appears, but it can only **refuse**: it shows

> This preview couldn't render — this slide's source renders as 2 slides, not one — it contains a slide separator (a `---` line, or a stray front-matter block below the top of the deck)…

which is honest and visible, but reactive. The **actionable** cure is to catch it where it is authored. A paste is the obvious way in (paste a deck below an existing one and you get two front-matter blocks), but a stray interior block is a plausible hand-authoring mistake too.

## What the shape looks like

```markdown
---
theme: indaco
paginate: true
---

---
marp: true
theme: indaco
header: "Pasted deck"
---

                         
## A slide the author will not see.
```

Front matter is only front matter at offset 0, so the second block is ordinary markdown: its opening `---` is a thematic break and its closing `---` is a **setext underline** under `header: "…"`. That is why the keys render as an `<h2>` and why the slide count shifts by one rather than two.

## Done when

- A rule in `lib/authoring/lint-core.js` (HARD RULE #7 — there and nowhere else, so CLI / `validate()` / browser all get it) fires on a `---`-delimited run of `key: value` lines that starts below offset 0.
- It does **not** fire on an ordinary `---` slide separator, on a `***` rule, on a setext `---` underline under running prose, or on `---` inside a fenced code block. The false-positive surface is the whole risk here: a rule that cries wolf on a normal separator gets switched off.
- The message names the fix ("front matter is only recognised at the top of the deck — delete this block or move its keys into the one at the top"), not just the symptom.
- Covered in the lint tier's tests with the #1551 paste shape as a fixture.
