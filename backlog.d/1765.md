## Summary

Decide how the slide Inspector should expose `_focus`, `_focusStyle`, `_focusSteps` and `_build` — Lattice's own narrative grammar, reachable today only by typing the HTML comment.

## Done when

A design model lands as a dated `engineering/decisions/` note (or an amendment to the 2026-08-18 one) that:
