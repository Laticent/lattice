## Note on scope

A related but separate finding, deliberately **not** included here: `@import url(…)` and `background-image: url(…)` in a `style:` block survive into the exported HTML with no warning, so a deck authored by someone else can carry a remote reference into an artifact you export under your name. That is a network-egress question rather than an authoring-policy one, and it applies to imported `.lattice` files as much as to model output. Worth its own issue if it is worth one at all.
