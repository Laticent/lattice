# infra(gate): checkUsEnglish counts examples/**/*.html — rendering any example deck fails the build on gitignored bytes

## Summary

`lattice-emulator.js` writes an `.html` sibling next to every PDF it renders. In `examples/` that file is gitignored but still inside `checkUsEnglish`'s scan scope, so rendering one example deck adds ~375 British spellings and fails `npm run build` on bytes nobody authored and nobody commits.

## Swimlane

`engineering/decisions/2026-07-02-website-copy-positioning.md` § 8.5 — the record that established the exemption pattern for gitignored, locally-generated artifacts. This is the same class with a fifth producer.

## Done when

With a freshly rendered `examples/*.pdf` (and therefore `examples/*.html`) present in the tree, `npm run check:ownership` passes. A regression test asserts that `listRepoTextFiles()` excludes `examples/**/*.html` while still including `examples/**/*.md`.

### Reproduce

```
$ node lattice-emulator.js examples/lattice-technical-assessment.md examples/lattice-technical-assessment.pdf
HTML: 70 slides → examples/lattice-technical-assessment.html      ← written unconditionally
PDF:  examples/lattice-technical-assessment.pdf

$ npm run build
build aborted: ownership guard failed.

$ npm run check:ownership
✗ British spellings rose to 1668, above the budget of 1293 (HARD RULE #21 …).
  Heaviest files: examples/lattice-technical-assessment.html (375), lib/base/base.docs.md (35), …
```

**375 hits from one render, against a budget of 1293.** A single example deck is 29% of the entire repo-wide allowance.

### Why it happens

Three facts combine:

1. **The sibling is unconditional.** `lattice-emulator.js:2755` gates only the *log line* on `QUIET`/`OUT_FORMAT`, not the write. There is no flag to suppress the HTML — I grepped for `no-html` / `keepHtml` / `htmlOut` and there is none.
2. **The file is gitignored** — `.gitignore:57` is `examples/**/*.html`. It is never committed, never reviewed, and absent from a clean checkout, which is why CI stays green while a local tree goes red.
3. **`checkUsEnglish` scans it anyway.** It walks `listRepoTextFiles()`, whose exclusions are a hand-maintained list of directory paths. `US_SKIP_DIRS` is `{node_modules, dist, .git, coverage, .scratch}` and matches by *directory name*, so it cannot help here — `examples/` must stay in scope for the `.md` decks themselves.

The British spellings are not ours. They come from the rendered deck's embedded bundle and content, serialized into a document that exists only as a preview byproduct.

### This is a known class, and the gate already handles four instances of it

`listRepoTextFiles()` carries four exemptions written for exactly this failure mode, each with its own comment explaining the same story — a gitignored artifact that reddens a tree which merely *ran* something, while CI stays green:

| Exempted path | Producer | What the comment records |
|---|---|---|
| `docs/public/playground/v` | running the docs site | "red on any tree that had merely RUN the docs site" — 1351 → 1517 |
| `release/` | `tools/release.js` | "the release aborted on its own notes file, mid-run, after the version was already bumped" |
| `docs/playwright-report` | `npm run test:e2e` | "any tree that RAN `npm run test:e2e`" |
| `docs/test-results` | `npm run test:e2e` | same |
| **`examples/**/*.html`** | **`lattice-emulator.js`** | **missing** |

The pattern, the precedent and the reasoning are already in the file. This is the one producer that was not enumerated.

### Why this one is worse than the other four

The other four are tripped by running *tooling*. This one is tripped by doing **the thing the workflow tells authors and agents to do**: render an example deck to look at it. `CLAUDE.md` directs agents to iterate visually via `npm run preview` and to ship a committed demo deck per HARD RULE #9, and the visual-review guidance says to rebuild and actually look at the output. The first thing that happens after following those instructions is that the next `npm run build` fails with a message about British spellings, pointing at a file the author never opened.

It cost a build cycle here. The failure message is accurate but the cause is three inferential steps away from it.

### Fix

Add the path exemption alongside the existing four, with a comment in the same voice:

```js
// The emulator writes an .html sibling beside every PDF it renders
// (lattice-emulator.js:2755, unconditional — no flag suppresses it), and
// examples/**/*.html is gitignored. Same local-only false-red class as
// playground/v above: a clean checkout and CI never have these; any tree
// that previewed an example deck does, at ~375 hits for one 70-slide deck
// against a 1293 budget. The .md decks themselves stay in scope.
if (/^examples[/\\].*\.html$/.test(rel)) continue;
```

Note this must match on the **file path**, not a directory name — `examples/` has to stay in scope so the decks are still counted.
