## Why it matters more than an ordinary doc nit

1. **It is a prompt.** Skill files are read by models to produce decks and to answer questions about lenses. A retired security claim in a skill file gets restated with confidence in generated output.
2. **It already leaked.** This file is where a retired claim was sourced for an executive deck this session — "a forged approval fails exactly like no approval" and "a redaction view can never leak" both shipped before being caught.
3. **The gate cannot see it.** `checkSkillFreshness` (`tools/check-ownership.js:7696`) pins *counts* in skill prose against live source and fails closed when a count can't be derived. It has no arm for a retired *claim*, so this drifted silently while the numeric assertions stayed green.
