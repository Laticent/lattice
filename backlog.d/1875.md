# Declared layout capacity is coda-blind — seven layouts clip an in-budget slide once a key insight is added

## Summary

Declared per-layout capacity is coda-blind: a slide inside its declared item budget still overflows once a key insight or below-note is added.

## Swimlane

`engineering/decisions/2026-08-24-universal-coda-cell.md` — the universal coda Cell. That work made the coda a real, uniformly-spaced Cell on every layout that accepts one; this card is the capacity question it exposed but deliberately did not answer.

## Done when

Either (a) each of the seven layouts below renders its own gallery-default slide **plus** a one-line `> Key insight: …` with zero overflow under `npm run overflow:check`, or (b) the capacity contract is amended so an author is told before they hit it — the deck lint subtracts the coda's cost from the declared budget when a beat is present, and `npm run lint:deck` warns at the boundary rather than the renderer clipping silently.
