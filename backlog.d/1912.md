# infra(workflow): `enable_pr_auto_merge` silently arms a MERGE commit, which the repo forbids — document the trap and the verify step

## Summary

The GitHub MCP tool `enable_pr_auto_merge` **ignores the `mergeMethod` argument and arms `merge`**. Passing `SQUASH` returns a success message reading `(method: MERGE)`, and the PR is then armed to land a merge commit — which `engineering/workflow.md` §Merging forbids outright (*"Never a merge commit"*).

An agent that trusts the tool's success response puts a merge commit on `main`.

## Swimlane

`engineering/decisions/2026-06-17-workflow-efficiency-review.md` §F, which introduced the queue flow and names this exact tool: *"With `enable_pr_auto_merge`, the sequence becomes: you review → approve → (queue rebases, tests, merges)"* and *"squash stays the merge method."* That last clause is what the tool breaks.

Observed on #1870 (2026-08-26). Requested `SQUASH`; the tool reported `method: MERGE`; the REST API confirmed `auto_merge.merge_method == "merge"`; GitHub's own `pull_request.auto_merge_enabled` webhook **independently reported `"merge_method":"merge"`**. Auto-merge was disabled before it could fire.

## Done when

`engineering/workflow.md` §Merging gains the trap and the verification step, so the next agent to reach the merge gate cannot ship a merge commit by trusting a green tool response. Done when it states:

1. **The tool cannot be trusted on method.** `enable_pr_auto_merge` arms `merge` regardless of the `mergeMethod` passed.
2. **Verify, don't assume** — after arming, check
   `curl -sS -H "Authorization: Bearer $GITHUB_TOKEN" .../pulls/N | python3 -c "import json,sys;print(json.load(sys.stdin)['auto_merge'])"`
   and confirm `merge_method == "squash"`. Disable immediately if not.
3. **The method is GraphQL-only** (`enablePullRequestAutoMerge(mergeMethod: SQUASH)`), and GraphQL is blocked in Claude Code sessions — *"only the pinned set of PR-review operations is served."* So **from an agent session the arming step belongs to the human**, who does it from the PR page in one click.
4. The agent's job stops at: green, rebased, card posted, and *"ready for you to enable auto-merge (squash)."*
