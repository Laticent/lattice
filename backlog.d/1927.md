# studio(a11y): a parked preview iframe stays in the accessibility tree and tab order — Tab can land on a hidden "Live deck preview"

## Summary

A loaded `iframe.live` re-asserts its own `visibility: visible`, so the host's `visibility: hidden` cannot pull the parked frame out of the accessibility tree or the focus order. Tab from the editor can land on a parked "Live deck preview" frame — a focus stop on a surface the user cannot see.

This was an adversarial-trio finding on the shared-preview reshape, and it **pre-dates** that change (the second Present iframe had the same shape), so it was logged under HARD RULE #18's off-path rule rather than pulled into that diff. It was never converted into a card, which is why it is being filed now rather than at the time.
