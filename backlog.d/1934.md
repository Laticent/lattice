# engine(cq): the container-query self-reference survives one tier down — 50 computed values on the gallery still track the host viewport

## Summary

The section-level `cq` self-reference was fixed, and the same defect one tier down was recorded rather than fixed.

`.chart-body`, `.piechart-figure` and `section.list-criteria`'s cell are themselves `container-type: size`, so a `cq*` unit inside **their own** declarations has the identical self-reference: the value resolves against the element's own container rather than the intended ancestor. **50 computed values on the gallery still track the host viewport.**

The record is honest about severity: **none of the 50 moves an overflow verdict today.** It is latent, not currently visible. But it is the same bug the tier above was just fixed for, and it will bite the first time one of those containers is resized independently.

Fixing it needs a **per-container stamp** rather than another token rewrite — which is why it was not folded into that change.
