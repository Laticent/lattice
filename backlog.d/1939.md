# bench(studio): the edit-paint ratchet guards half the loop — the heavy `write` regime is never captured

## Summary

The Studio edit-paint budget shipped a ratchet, and the heavy-regime (`write`) numbers **were never captured** — the headless bench does not trigger a theme / mode / size change, which is what puts the Studio into the full-deck rewrite path.

So the committed budget guards the light regime only. A regression in the expensive half would not move the number the ratchet watches.

The record states the consequence directly: before any change that touches the full-deck rewrite path, extend the bench to drive one, **or the ratchet is guarding half the loop.**

## Swimlane

`engineering/decisions/2026-08-25-studio-edit-paint-budget.md` — see § 5 "What is NOT settled".

## Done when

1. The bench drives at least one theme / mode / size change, so the full-deck rewrite path is exercised.
2. Heavy-regime numbers are captured and blessed into `test/benchmark/baseline.json` via `npm run bench:bless`, so the diff is the durable record (HARD RULE #19).
3. `npm run bench:check` distinguishes the two regimes rather than averaging them — an average would let a heavy regression hide behind a light win.
