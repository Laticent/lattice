# anima(svg): a `reveal`/`slide`-only path is still incidentally stroke-drawn by Vivus's aggregate scalar

## Summary

Per-element SVG paint landed (`slide` / `highlight` / `reveal-opacity` + `SvgElement.transform`), with one documented limitation: **a `reveal`/`slide`-only path is still incidentally stroke-drawn by Vivus's aggregate scalar.**

An author who asks for a reveal or a slide on a path gets a stroke-draw they did not ask for, because the scalar is applied across the whole SVG rather than per path. The fix named at the time is a **per-path-window replacement**, described as the next slice. It was never taken.
