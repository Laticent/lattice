# anima(a11y): built scenes have no poster, so a reduced-motion viewer gets "Play the motion" over an empty stage

## Summary

**Built scenes have no poster.** Under `prefers-reduced-motion`, a viewer is shown the "Play the motion" opt-in over an **empty stage** — so the one class of viewer who has asked not to be moved is also the only one who cannot see the content without opting into motion.

This was accepted as "acceptable for the editor" when the Rig Mode foundation landed, with poster generation from the renderer named as a later slice (the drift-closure). It was never ticketed, and it is no longer only an editor concern once built scenes reach a reader surface.
