## 1 · Deployed Cloudflare preview — 10 claims, and the premise is FALSE

Ten PRs say some version of *"the deployed preview is UNVERIFIED because headless Chromium cannot reach an external host through the agent proxy (`ERR_CONNECTION_RESET`, while `curl` gets 200)."*

**That reasoning is wrong, and PR #1801 already corrected it.** Chromium does not inherit the sandbox's agent proxy; **Node does**. So put Node in the middle: a loopback reverse proxy fetches the real deployed bytes and Chromium only ever speaks to `127.0.0.1`.

**The technique, with working code, is `engineering/development.md` § 613** ("A DEPLOYED page IS reachable from here — through a loopback reverse proxy"), verified against a real deployed page. The failure mode varies by session — `ERR_CONNECTION_RESET` in some, `SSL_CONNECT net_error -101` in others — and the conclusion is the same either way.

**What to do:** re-run the deployed-preview check for the affected PRs using that recipe. This matters more than it looks: a local build is *exactly* the substitute a deployed-preview check is not allowed to make (HARD RULE #23), so these ten are currently resting on the one stand-in the rule names.

Affected: #1222, #1274, #1666, #1676, #1720, #1738, #1776, #1826, #1840, and the tablet geometry in #1301.

- [ ] Deployed-preview claims re-run through the loopback proxy

## 2 · Real iOS Safari on a physical iPhone — 58 claims

The largest group, and the one with the highest defect yield historically: **the device is what surfaced two of #1553's three defects**, and the Compose-bleed bug was originally reported from one.

Everything here is Playwright's WebKit on headless Linux — *the engine, not the device*. What that misses: real touch, the dynamic URL bar, `env(safe-area-inset-*)`, `-webkit-touch-callout` (an iOS-only property this WebKit build does not implement — `CSS.supports` returns false), tap-highlight, momentum scroll, and OS-level tab termination.

**How to clear it:** open the deployed Studio on a real iPhone and work the list. Most items are seconds each.

Concrete checks named in the PRs:

- **#1233** — press-and-hold a drawer row: **no word should highlight, no Copy / Look Up.** (Author's note: "re-test in seconds.")
- **#1198 / #1217** — the `active:` press wash, `WebkitTapHighlightColor`, and `env(safe-area-inset-bottom)` on a real notch.
- **#1580** — the eaten-release path on touch navigation; CDP always delivers *paired* touch events, so this path has only ever run in jsdom.
- **#1599** — the player's `transform`-scaling model exists **because of** an iOS `cqi` bug, and the canvas changed. This is the single highest-risk item in the group.
- **#1584** — the crash panel at 390px. Note `performance.memory` does not exist on Safari, so the memory trend is structurally different there.
- **#1625 / #1626 / #1630** — real tab suspension, as opposed to a CDP-induced freeze.
- **#1186** — the original crash was an OS-level process kill under memory pressure, not a JS exception; it cannot be forced from a desktop.
- **#1243** — the filmstrip's virtualization defeated headless capture, so the Playground evidence is numeric only.

**Evidence that counts:** a screen recording or photo *from the phone*, per check. Not a 390px desktop viewport — that is the stand-in HARD RULE #23 explicitly rejects.

Existing per-surface issues stay open and are the detailed homes: #783, #667, #1541, #1579, #1585, #1591, #1617, #1216, #1921.

## What counts as evidence

Per HARD RULE #23, a claim names its surface and carries an artifact **from that surface**. For this ticket specifically:

- **Good:** a photo or screen recording from the phone; a marp-cli render committed as an artifact; a screen-reader transcript; a screenshot through the loopback proxy of the *deployed* bytes.
- **Not evidence:** a 390px desktop viewport, Playwright WebKit on Linux, Chrome with a non-default flag, a local build standing in for a deployed one, or a green CI run.

If a surface still cannot be reached, mark it **UNVERIFIED** and say why. That is a legitimate outcome and always better than a quiet upgrade to "tested".
