## What shipped, so this reads cold

A `<tspan>` carries its own `dominant-baseline`, and both SVG 1.1 §10.9.2 and SVG 2 say its initial `auto` keeps the parent's baseline. WebKit resolves it to `alphabetic` instead — conforming to neither, so this is a browser bug, not a spec split. #2303 repeats the value on every `<tspan>` the chart bucket emits: 107 of 256 gallery labels drifting 4–13px in WebKit → 0 of 256.

`tools/audit-svg-baselines.mjs` is the committed instrument. It renders a deck through the real CLI, loads it in Chromium **and** WebKit, and reports per-class drift. It needs `npx playwright install webkit && npx playwright install-deps webkit` first — neither ships in the sandbox, and the deps install needs sudo.
