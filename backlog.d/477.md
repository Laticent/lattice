# chart(state-chart): tune the `tb` reveal-lift magnitude

## Summary

The per-state reveal lift shipped in #473 moves the active node **perpendicular to the flow** — `lr` lifts up, `tb` slides right. The `tb` rightward shift is currently `0.4 × offsetHeight`, which reads subtly because `tb` nodes are centered text with no box (until the end state). Decide whether to bump it (the `lr` up-lift is well-judged; `tb` is the open question).

## Context (what #473 did)

`liftVec` in `docs/src/playground/drawing-board-chart-interact.js`:

```js
const d = (w.offsetHeight || 28) * 0.4;
return chartEl?.getAttribute('data-sc-dir') === 'lr'
  ? `translateY(${(-d).toFixed(1)}px)`   // lr → up
  : `translateX(${d.toFixed(1)}px)`;     // tb → right
```

`offsetHeight` (not `getBoundingClientRect`) is deliberate — it's slide-space and immune to the Drawing Board's fit-scale, so the lift stays proportional on a scaled mobile slide. Note the edges don't re-route while tilted (router guard), so the lift opens a small gap under the node — that's intentional ("stepping out").
