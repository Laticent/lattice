# feat(runtime): live structural auto-split — the split as a preprocessor on every preview surface

## Summary

Every live surface should paginate a portrait, square or strip deck exactly as its export does: a cover, one page per element, and a closing page. The export has always done this. A live preview showed one tall page per slide instead.

> **Rewritten 2026-09-24.** This issue used to lock a MEASURED design ("Option B"): a runtime measurer fed `resplitDoc`, pagination-dependent values rendered as reserved-space placeholders, and an idle-time pass reconciled them. The 2026-09-01 ruling ([autosplit-splits-on-structure](../blob/main/engineering/decisions/2026-09-01-autosplit-splits-on-structure.md)) removed its premise. The split fires on **structure**, `resplitDoc` is deleted, and nothing is measured to decide a cut. So a live surface needs no measurer, no placeholders and no convergence loop. It runs the same pure pass the CLI runs, on the rendered document string, before writing it to the frame. The record is Amendment 2 of `engineering/decisions/2026-06-25-runtime-autosplit-eventual-consistency.md`.

## The design (build to it)

1. **One preprocessor, `lib/core/structural-split.js` (HARD RULE #1).** It runs stamp → size gate → `splitDoc` → run adornments (`railRun`). The CLI and every live surface call it; no surface re-implements it.
2. **Stamp before splitting.** The engine emits no `data-lattice-slide`, and the split kernels find slides by it. `stampSlideNumbers` adds it.
3. **Size gate.** Split at `square`, `tall` and `strip`, never `wide` (`splitApplies`). Landscape stays byte-unchanged.
4. **Capacity map.** Browser bundles bake it in at build time from the same `splitCapacityFrom` projection the CLI uses.
5. **Opt in per surface, at the caller.** Never hook the shared `renderMarkdown`, because exports go through it. An export opts in only through the export sign-off (CLAUDE.md Quality Bar).
6. **Surfaces that keep authored indexing** (a component tour, the Studio rail) group a split run back to its authored slide through the `data-lattice-slide` integer part, or through `authoredIndexPerPage`.
