# Add a real-surface Playwright smoke against the built Playground in CI

## Summary

CI runs unit/build/lint only — it never drives the **real** Playground/Studio, so interaction regressions (tap-to-reveal, iframe layout, gesture handling) sail through green. That gap is exactly what let PR #658's mobile-touch failure be reported as "verified." Close the machine-checkable half: a Playwright test that builds the docs and drives the actual Playground in a real browser.

Scope note: this catches the **desktop-Chromium** half (real DOM, real iframe, real event dispatch) — it does **not** cover iOS Safari (no headless iOS). HARD RULE #22 still applies: iOS/mobile claims need a real device. This test just stops the "harness passed but the real surface is broken" class from reaching a human on the common path.

## Swimlane

Verification honesty — HARD RULE #22. This is the automatable slice of the rule.

## Done when

- A Playwright spec builds `docs/` and loads the real `/lattice/playground/`, presets a `debug: on` deck, switches to Preview, and asserts the debug reveal actually fires against the real `#preview` iframe (chip appears on the tapped box) — driving the real surface, not a jsdom/Puppeteer harness on a bare iframe.
- Runs in CI (a new job in `.github/workflows/ci.yml`, gated behind `changes` for `docs/**`), green on main.
- The spec's header comment states plainly it does NOT cover iOS Safari.
