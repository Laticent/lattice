- **Fixed a cross-site-scripting hole in the slide runtime.** The verdict-grid and obligation-matrix badge transforms read their label with `textContent` — which decodes entities — and wrote it back with `innerHTML`, re-parsing markup the sanitizer had deliberately neutralized. A table cell in a shared or AI-generated deck could run script in the Studio/Playground preview origin. Both now build the badge with DOM APIs, so there is no parse step.
- The Playground's last-slide snapshot now guards its **stylesheet** as well as its markup (HARD RULE #22). The snapshot's CSS is produced by serializing the live CSSOM, which normalizes the `<\/style` escape back into a live element terminator, and it crosses `localStorage` into the top docs document. Guarded at both captures and the storage boundary; no real stylesheet's bytes change.
- New `checkRuntimeMarkupSinks` gate: every place `lib/runtime` writes markup into the live preview frame must declare where that markup comes from. A new injection point — or a second one hiding behind an already-legitimate one — now fails the build instead of landing silently.
- New behavioral coverage for the Mermaid render path on the real Playground: nine script shapes that must not execute out of a node label, the `click … javascript:` vector, and the `<br/>` line break in node labels that `securityLevel: 'strict'` was once wrongly believed to cost.
- New behavioral coverage for an imported theme's CSS reaching the Studio preview's `<style>`, driven through the real Library import.
