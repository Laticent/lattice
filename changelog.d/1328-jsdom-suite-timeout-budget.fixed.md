- **Fixed: the docs site's jsdom test suite no longer flakes under load.** The `studio.*` family failed intermittently in a full run with a different failing set each time — the failure mode that teaches you to dismiss failures, and once nearly hid a real regression. The cause was the test runner's generic 5-second default timeout, never chosen for tests that drive a full Studio render plus ten interactions: measured at 1.8–2.0s idle and 4.9–6.1s under CPU contention, they straddled the line exactly. The suite now carries a budget sized from that measurement.
