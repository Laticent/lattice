- Dependabot pull requests against `docs/` no longer fail `npm ci` with `Missing: proxy-agent@8.0.2 from lock file`. The docs lockfile held a package that only an optional peer dependency reached; npm materializes such a package and Dependabot's lockfile writer deletes it, so every Dependabot lockfile for that directory was uninstallable — whatever the bump in the diff was. `proxy-agent` is now a direct devDependency of `docs/package.json`, which gives it an edge Dependabot keeps. Every other package in the tree resolves to the version it did before.
- `build:check` now fails on a committed lockfile that holds a package only an optional peer dependency reaches, and names both the `npm ci` error it will cause and the one-line fix.
