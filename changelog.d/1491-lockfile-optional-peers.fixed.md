- Dependabot pull requests against `docs/` no longer fail `npm ci` with `Missing: proxy-agent@8.0.2 from lock file`. The docs lockfile held packages npm had placed to satisfy an optional peer dependency; npm materializes those and Dependabot's lockfile writer deletes them, so every Dependabot lockfile for that directory was uninstallable — whatever the bump in the diff was. `proxy-agent` is now a direct devDependency of `docs/package.json`, which gives it an edge Dependabot keeps. Every other package in the tree resolves to the version it did before.
- `build:check` now fails on a committed lockfile holding a package npm marked as both `peer` and `optional`, and names the `npm ci` error it will cause along with the usual fix.
