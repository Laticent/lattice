- **Breaking:** a layout stylesheet you supply yourself (`--css` / `-c`, or the positional form) now LOSES to the theme's `:root`, where it used to win. If you override engine tokens in a custom sheet, move those declarations into a theme, or pass them in a theme that imports your sheet.
- **Breaking:** exported decks now render each theme's own tokens instead of the engine's defaults. The export bundle used to concatenate the palette before the base, so `lattice.css`'s `:root` defaults beat every palette's curated value on equal specificity — 925 declarations across 37 tokens, on all 32 selectable themes. The bundle now loads the base first, which is the order every theme declares with its opening `@import 'lattice'` and the order the Studio, the docs Playground and this engine's own Mermaid token reader already used. A deck's PDF, PPTX and exported player now match its preview.
- The 37 tokens, by how many themes each was dead on: `--pass` / `--warn` / `--fail` and their `-bg` tints, `--seq-500`, and the eight `--diagram-*` state tokens (32 themes each); the twelve `--hljs-*` syntax colors (28–32); `--code-text` (30); the `--chart-state-*` trio (18–20); `--on-accent` (5); `--on-dark-primary` / `-secondary` / `-ghost` (2); and `--seq-pole-low` / `--seq-pole-high` (carbone only, which pins them literally so its single dark canvas keeps the right ramp direction). **The eight `--diagram-*` tokens change no pixel** — nothing in the engine's CSS reads them, and their only consumer, the Mermaid theme map, already resolved them palette-first. They are 8 of the 37 and 256 of the 925, and they are a paper change.
- Measured across 1,152 renders of a nine-slide deck: 36 of 36 distinct theme-modes change at least one slide, and of 9,600 rendered text runs per side, **none** falls below AA that did not before — two are fixed (`concrete`'s kanban "Done" label, 3.25:1). Contrast that does not cross a floor still moves: `cuoio`'s bookend body text goes 10.36:1 → 7.89:1 as the theme's own `--on-dark-secondary` takes over from the engine's.
- The sequential ramp's 13 curated dark anchors reach exported output for the first time: sub-3:1 word-cloud tiers 3 → 0, strictly monotonic encodings 25/38 → 38/38, and the 12 combinations where weights 5, 4 and 3 painted one color now resolve to distinct tiers. `mustard`'s light weight-2 word goes 2.86:1 → 3.41:1.
