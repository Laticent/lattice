- **`engineering/decisions/` is now officially a dated archive — notes are corrected in place and
  marked `superseded`, never deleted.** This reverses a convention that had stood since the folder
  was created ("absorb into canon, then delete — this folder is not an archive") and that had
  **never once been executed** across 391 notes. Measuring it is what settled it: four of five
  cards in one batch existed only because a `shipped` note wrote down what it had *not* finished,
  so running the delete rule would have deleted the work queue. Canon holds a conclusion; a note
  holds the measurement, the harness, the corrections, and the caveats — and those caveats are
  what scope the next session. The generated index heading stops claiming **"pending teardown"**,
  a stale assertion in a generated file being the narrower defect underneath the complaint. The
  corpus total is surfaced in the post-merge standup instead of the index, where it is spoken in
  chat rather than committed and so cannot become the line two concurrent PRs disagree about
  (#1547). CLAUDE.md's guidance to leave a durable note is unchanged and endorsed.
