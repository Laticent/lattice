- `quadrant` now sizes its item labels **per slide** instead of from one constant shared by every quadrant in every deck. That constant had to be the largest size the most crowded slide in the corpus could carry, so a sparse chart printed at a size a fourteen-dot chart needed. The kernel now takes the largest size at which every name still places: 20 of the 22 labelled quadrant slides in the corpus print larger, and 18 reach the house's smallest type tier, where none did before. A slide that cannot be lifted renders byte-identically to before.
- `quadrant`'s label width budget scales with the chosen type size, so a bigger name keeps the same characters-per-line instead of wrapping to three lines and breaking mid-word.
- The `--quadrant-dot-size` custom property is new, and is the floor rather than the size — themes can retune it, and the kernel writes the per-slide choice onto the label group.
