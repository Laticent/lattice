- The overflow / type-floor / Fix-Me markers are now measured **once per settled render** instead of on every animation frame in which anything in the document changed. A sweep is triggered by the things that can actually change a verdict — the debounced content pass, fonts settling, a resize, a scroll bringing new slides into view — and probes only the slides in the viewport band whose verdict is stale. On the filmstrip this is 9–26× cheaper per sweep (58-slide deck: 9.4ms → 0.4ms; a 40-slide all-overflowing deck: 20.7ms → 1.9ms), and it stops the watcher from forcing layout on slides the preview had deliberately virtualized away.
- The three marker tabs are now **part of the rendered slide** — the engine emits an empty, hidden `.overflow-tab`, `.illegible-tab` and `.fixme-tab` in every `<section>`, and the watchers only fill them. Nothing creates or destroys marker DOM any more, so the live preview and an exported artifact carry the same markup, and the browser runtime and the export's inline watcher write to the same element instead of each minting their own.
- The Fix-Me signal is drawn **inside the slide**: an `outline` on the culprit cell plus a corner label, replacing the floating overlay layer that was rebuilt on every pass and re-synced on scroll. It now tracks scrolling and the preview's own scale for free, and it cannot perturb the layout it is measuring.
- New on-demand bench tier, `npm run bench -- --sweep`, times the sweep in a real browser against a filmstrip-virtualized deck. Nothing measured this path before: it runs over laid-out DOM, so the in-process render tier could not see it and the whole-cycle export tier drowned it. `bench:check` gates the scoped-vs-whole-document ratio against a 3× floor.
- `window.latticeSweep` lets a host that knows when its render landed (the Studio, the Playground) drive the sweep directly rather than waiting on the observer's settle window.
