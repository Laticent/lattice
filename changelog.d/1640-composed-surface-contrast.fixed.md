- `redline` no longer fades its own text with `opacity`. A struck `<del>` run carried `opacity: 0.85` and the `.stacked` variant's OLD card another `0.78`; CSS opacity composites the ink together with the tinted band under it, so it cost legibility on every palette and mode. Measured on the rendered deck across all 32 palettes, 204 text runs newly clear their threshold — indaco's struck clause goes 4.95:1 to 6.34:1 in sampled pixels on the default variant every deck renders. **This is live on the PDF/PPTX export path now**, not only in the Studio and the docs Playground.
- Thirteen palette arms re-tuned across eight palettes so a curated status hue clears AA on the surface a component actually paints it on — its own 12% tint, whose background moves with the value — rather than only on the canvas: `--pass` and `--fail` on `ardesia`, `brina` and `laguna` (light), `--fail` on `carta` (light), `--fail` and `--warn` on `magnolia` (dark), `--pass` and `--fail` on `carbone` (dark), and the `--seq-500` ramp anchors on `onyx` and `concrete`, which `word-cloud spectrum` reads through the base's derived `--seq-700` stop. **These reach the export path too, as of #1527's concat flip in this same release**; before it they were live only in the Studio and the docs Playground.
- Each arm was solved against its companion tokens, not alone, so no palette's pass/warn/fail separation erodes under a color-vision deficiency. Ten pairs that were indistinct under a deficiency are now distinct, none crossed the collapse floor, and the one measurable loss is 0.0008 on a pair that is unreadable either way.
- New gate `tools/composed-contrast.js` (+ `test/unit/palette/composed-surface-contrast.test.js`) scores the 24 surfaces components compose — an ink on a tint of itself, that band on a second own-hue card, the OKLab ramp stops the base derives from a palette anchor, and nested element `opacity` — in both cascade orders. `tools/contrast-audit.js` checks each ink against `--bg` and never against the `-bg` mix, which is why palette values could go sub-threshold under #1527 with every gate green.
- New gate `test/unit/palette/cvd-trio-floor.test.js` freezes the OKLab distance of every status pair under protanopia, deuteranopia and tritanopia, for all 32 palettes rather than only the four a11y ones. `tools/cvd-audit.js` is a report that exits 0, so a re-tune driven by any other constraint could erode a pair with the suite green.
- `tools/check-slide-contrast.js` now reads element `opacity`. It composited the ink and its backdrop independently, which is not what a CSS group alpha does, so its number for any run inside one was optimistic — ~5:1 where the rendered pixels were 3.21:1. Validated against sampled pixels: within 0.01 on the nested-wash runs, within 0.07 across the wider set.
