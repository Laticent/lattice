- Shell code blocks now highlight the commands a deck actually shows. Lattice ships its own augmented `bash` grammar — highlight.js's, plus modern CLI tools (`npm`, `npx`, `docker`, `kubectl`, `terraform`, `aws`, `cargo`, `brew`, …) as built-ins and `--flags` as params — so a command list reads as code instead of as one flat block. It replaces `bash` and carries `sh` and `zsh` with it.
- Scripts keep everything stock bash got right and gain the same command and flag color: `${VAR:-default}` is still a single variable, quoted strings are still strings, and a hyphen inside a filename is still part of the filename.
- ` ```shell ` and ` ```console ` are unchanged — they stay on highlight.js's terminal-session grammar, and the existing lint still tells you to retag a script written under one. Retagging to ` ```sh ` now buys the CLI built-ins and flags too, not just the script grammar.
