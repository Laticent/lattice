- **Breaking (for decks that relied on it):** a front-matter or comment directive value containing `;`, `}` or `<` no longer reaches the slide's inline `style`. Values were written out verbatim as custom properties (`--header`, `--footer`, …), so a `;` closed the declaration and opened a new one at the highest cascade tier — `header: "Acme Q3; --z-canvas: 9"` lifted the finish backdrop over every word and rendered the deck with its body erased. The directive still lands as a `data-*` attribute; only the CSS declaration is dropped. A `;` inside a `url()` or a quoted string is untouched, so data-URI backgrounds are unaffected.
