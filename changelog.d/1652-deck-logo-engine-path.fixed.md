- `logo:` front matter now renders on every surface. The engine's injector selected slides by `data-lattice-slide`, an attribute the owned engine never writes, so on the canonical render path it matched nothing — the Studio, the playground and every live preview showed no logo at all, for a relative path, an absolute `https://` URL and a `data:` URI alike. It now selects slides with the shared section walker, so one pass inside the engine serves every render path and the emulator's second, post-stamp pass is gone. Exported artifacts are unchanged: every committed deck that uses `logo:` renders pixel-identical.
- An `image` slide carrying `logo:` no longer folds the mark into its `.image-text` panel, which would have duplicated it.
