- The Studio no longer flashes its chrome unstyled on reload. Astro appends a page's bundled stylesheet after the page's own head content, which put the render-blocking link 51KB into a 58KB `<head>` — behind a 12.5KB inline `<style>` and a 28KB parser-blocking inline `<script>` — so the browser painted the raw DOM before it knew a stylesheet was pending. A post-build pass now moves each page's stylesheet link as early in `<head>` as it can go without crossing a `<style>`, leaving the cascade byte-for-byte unchanged. Measured in Firefox on the built artifact over a 1.2Mbps/200ms link: first paint 347ms with the stylesheet applied at 3569ms (3.2s unstyled) becomes first paint 723ms with the stylesheet applied at 713ms — paint follows the stylesheet, and the stylesheet itself arrives 2.86s earlier.
- The site's `theme-color` sync no longer forces a style resolution while the page is still parsing.
