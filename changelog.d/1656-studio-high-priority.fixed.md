- **Breaking:** the deck lint's `bookend-finish-contrast` rule is now `info` rather than `warning`, and no longer claims a bookend's display text washes out. The defect it warned about is fixed in the engine, so the rule survives only as an editorial note about the house pattern. A consumer gating a build on lint warnings will see one fewer.
- A deck-wide `finish:` no longer erases its own title, closing, and divider bookends. Every finish layer — wash, texture, mark, edge, and the clearance mask — now composites against `--fin-canvas`, the surface the slide actually paints, instead of the deck-wide `--bg`. On the three inverse bookends those disagreed: the clearance mask painted the light deck canvas across a dark bookend whose display text is white, so a `finish:` deck's title slide exported as an almost entirely blank page. Ordinary slides, and per-slide `dark`/`light`, are unchanged to the pixel.
- Compose's ⌘A now selects the current slide, and a second ⌘A selects the whole deck. Deleting, cutting, pasting over, or typing over a selection that spans slides works — the structural guard used to reject every transaction that changed the slide count, so select-all-then-Delete silently did nothing. A locked slide stays immutable, including against a cross-slide delete.
- The Studio's insert-a-component gallery renders at its intended 1120px instead of 512px, so previews are roughly three times the area and component names stop truncating to three characters. Each tile now reads preview → name → match strength and looks, and a grid/list toggle beside the close button switches layouts (persisted per device).
- The component manifest now publishes `authoring.blocks` — which of the two universal editorial blocks (the key-insight callout, the below-note footnote) each layout actually renders. Both are opt-out, and which layouts opt out was knowledge only the render kernel and a CSS `:not()` chain held. Compose's grammar gutter now offers a register only where it will render, and a new `block-unsupported` deck-lint rule flags an `insight-*` or `no-note` modifier that has no host on the slide's layout — `<!-- _class: quote insight-key -->` was silently inert while the manifest advertised the modifier.
