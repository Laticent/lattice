- The Studio editor no longer shows two identical lint popups at once. `@codemirror/lint` ships two independent tooltip sources over the same diagnostics — one on the underlined text, one on the gutter warning icon — and neither knew about the other, so hovering the squiggle and then the icon left both on screen. Hovering the icon now dismisses the text popup, so there is only ever one.
- A lint finding whose fix is a single-token swap now offers a button that applies it, named after what it will do (`Fix: use “kpi”`), instead of prose telling you to go and type it. This covers a typo'd `_class:` token and every front-matter register — `finish:`, `mode:`, `claim:`, `stamp:`, `tone:`, `rule:`, `eyebrow:`, `pace:`, the `spectrum:` family and the rest — and "Fix all" applies them too. The suggestion is the deterministic bounded "did you mean" the map linter already used; nothing close enough still gets the prose guidance rather than a misleading button.
