- Quadrant and radar labels are measured with a per-string, per-face glyph table instead of one flat constant, so a wide name (`WORKFLOW`) no longer overruns the box it was wrapped to and a narrow one (`IL ILI`) no longer inflates the box the de-collision pass reasons about. Measured in a real browser against the shipped faces, the estimate now lands within 2–8% of the painted width across a 42-string vocabulary, where the flat `ADVANCE_UPPER` (0.68) ran from 39% short to 104% over. This affected `.quadrant-label` (and its `magic` / `threshold` variants), `.quadrant-cohort-label` and `.radar-sector-label`.
- Those same labels now follow the `sketch` finish's hand face when estimating their geometry, the way the gantt axis already did — previously the CSS painted Shantell Sans while the math still assumed the clean face. Every shipped quadrant and radar deck renders byte-identically; the fix only shows on author text wider than the galleries' own.
