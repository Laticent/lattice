- A deck served without a baked front-matter block — the marp-kit surface, where the runtime falls back to fetching the source `.md` — now converges on the same geometry the engine renders. Previously a `mode: sketch` gantt on that path built its axis with the clean face's advances and then painted it in the hand face, because the deck's registers landed after the first transform pass and nothing corrected it.
- The runtime's transform re-run is no longer gated on an unrelated signal. It used to fire only when the default-component stamp changed something, which is never true for a deck whose every slide names its own component, so those decks got no re-run at all. It now also fires when a deck-wide class lands after the pass that should have seen it. Decks carrying a baked block — every Export-to-Marp bundle — still pay nothing, because there the registers are already applied within the first pass.
- Chart sections are rebuildable. The chart-family DOM adapter keeps the authored list it built from, so a chart whose class list changes (deck-wide registers arriving late, or a live `_class:` edit in a preview) is rebuilt against the new list instead of keeping geometry measured for the old one. A chart whose class list has not changed is not rebuilt, so repeated transform passes stay free and a chart keeps its own popover and motion targets.
