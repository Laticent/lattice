- Studio toolbar: **Present** now carries the filled accent button and **Share** the outline, reversing an emphasis that was never chosen — Share had simply inherited the default button variant while Present was explicitly demoted. Present is the more frequent verb, it repeats within a session where Share is once per deck lifecycle, and the least reversible action should not also be the most attractive target. The bar now spends its accent on exactly one filled object.
- Studio toolbar: the **Read / Write / Craft** dial now sits directly after the deck switcher, with a divider closing the group, so the row reads as descending scope — which app, which deck, which view of it — and only then utilities and actions. Desktop now matches the order the tablet already used. The primary action is still the last labeled control in the row.
- Studio toolbar: the dividers are stronger. They drew in the theme's border color, which measures 1.32:1 against the bar in cuoio light — too faint to band anything. They now use the muted text color at 2.64:1, and are slightly taller. Below desktop the row keeps its tighter, divider-free rhythm, because a divider costs 7px there and the 700px layout has about 3px to spare.
- Studio toolbar: the guided-tours icon and the deck's status dot no longer draw in the accent color, and the dial's selected stop is now a tinted chip with a heading-colored label and an accent hairline. The chip's tint is mixed from the theme's own text and background colors, so it is guaranteed to be visible on every palette — including the eight dark palettes where the soft-accent color an earlier cut used is identical to the page background, and the thirteen where the accent color resolves to the same value as heading text.
- **Fixed:** the unselected dial labels, the ⌘K search placeholder, and the slide-count meta were drawing in the theme's decorative, WCAG-exempt color — 2.5–2.7:1 where 4.5:1 is required, and under that bar in 21 of 36 palette and color-mode combinations. They now use the AA-rated body color (5.95:1 and 5.46:1), and all 36 combinations pass.
- **Fixed:** the phone's deck-actions bar announced itself to screen readers as a toolbar but implemented none of the toolbar keyboard behavior — arrow keys did nothing and the bar consumed eight tab stops. It is now an ordinary labeled group, which promises only what it delivers. The workspace dial's screen-reader label is now "Workspace stop" instead of "Workspace density", matching the vocabulary every other surface uses.
- Studio: the arrow keys and the zoom keys (`+`, `-`, `0`) now turn the deck and zoom the preview from inside the phone's deck-actions bar, where they previously did nothing. This follows from that bar no longer claiming to be a toolbar — the deck shortcuts yield only to widgets that actually implement their own arrow-key handling.
