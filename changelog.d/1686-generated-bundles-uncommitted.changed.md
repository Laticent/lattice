- **Breaking for anyone fetching `dist/` from the git repository:** `dist/` and the docs-site bundles are no longer committed. They are built by `npm run build` (~16s, no browser). Measured before removing them: jsDelivr's public stats show 2 lifetime `/gh/` fetches of this repo, both against an immutable commit SHA that keeps resolving regardless, and zero branch pins.
- **npm consumers are unaffected.** `package.json`'s `files` whitelist takes precedence over `.gitignore` — `npm pack` still carries all 135 `dist/` files including the `bin` — and a new `prepack` builds them at publish time. The package's entry points and jsDelivr `/npm/` URLs are unchanged by that switch. (The npm scope itself was renamed to `@laticent` separately, after this landed.)
- The merge queue was ejecting PRs with `MERGE_CONFLICT` on these files: 36 of the last 50 commits touched `dist/`, and the minified bundles run ~9.6 KB per line, so any two such PRs conflicted with certainty and the loser's auto-merge flag was silently cleared.
- `npm run build:check` now checks only the committed generated artifacts; `npm run build:check:all` is the unscoped check (run it after `npm run build`).
- The docs site now builds its bundles at deploy time, so the deployed Playground matches the deployed engine by construction.
