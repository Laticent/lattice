- **Added: a font bump can no longer silently invalidate the chart-label glyph metrics.** `GLYPH_UPPER` — the per-glyph advance table behind uppercase tracked quadrant and radar labels — is a measurement of two specific woff2 files, and so were the browser measurements the unit suite checked it against. Both were frozen literals in the repo, so replacing `assets/fonts/outfit-700.woff2` moved the painted width while both sides of the comparison sat still: the suite stayed green (demonstrated: 39/39 passing with a different font in place) while labels would have started overrunning their boxes. The table now records each face's sha256, and `checkFontMetricsPin` fails `npm run build:check` when those bytes move.
- **Added: `npm run fonts:measure`.** Re-measures every glyph against the shipped faces in real Chromium at the labels' own CSS, and prints the corrected rows — the remediation path when the pin fires. `--strings` also re-derives the unit suite's recorded measurements. On-demand and never writes, so `npm run build` keeps its zero-browser dependency.
