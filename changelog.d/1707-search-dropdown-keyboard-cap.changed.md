- The Studio's inline ⌘K search now caps its dropdown against the **software keyboard**, not just the viewport. The list's height was `min(60vh, 420px)` — both arms blind to a keyboard, since `vh` does not shrink for one — and on an iPad Pro 11" in landscape (834px tall, ~350pt keyboard) the list ended flush with the keyboard's top edge, with a predictive or emoji row enough to cover its last rows. It takes a third arm from the visual viewport (`--vvh`, the same measurement every mobile sheet already caps against), so the list shortens exactly as much as the keyboard costs. With no keyboard up the geometry is unchanged at every width.
- The inline dropdown gains a regression test for the invariant that took three attempts to land: it paints **below** the header rather than clipped inside the 54px bar. Two ancestors can clip it away — the `Command` widget's own base-class `overflow-hidden` and the header's `overflow-x: auto` scroll valve — and clearing only one paints nothing; the test fails if either comes back.
