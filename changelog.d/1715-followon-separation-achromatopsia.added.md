- The Theme Studio's live palette meter (`lib/theme/contrast.js`) now measures de-emphasis SEPARATION, not only contrast. `--text-muted` and `--text-secondary` each get a row asserting they stay perceptibly apart from `--text-body` in OKLab (floor 0.030, the same number `checkMutedTierFloors` holds committed palettes to, pinned equal by a test). Until now `deriveTheme` could emit either ink byte-identical to body from plausible essentials and the panel showed six green rows and an "AA verified" badge. Separation rows are a distinct row `kind` carrying `distance` — never a ΔE in the `ratio` field — and the Fabricate panel renders them as `ΔE 0.007 · FAIL` rather than a fabricated ratio and a WCAG tier. The panel's heading moved from "WCAG audit / AA verified" to "Palette audit / AA + tiers" for the same reason — its aggregate verdict now swings on a predicate WCAG does not define.
- `tools/cvd-audit.js` gained an ACHROMATOPSIA arm. The audit loops all four simulated conditions instead of the three Machado matrices (`CVD_TYPES` is unchanged — achromatopsia is a monochromacy), with a per-condition AND per-group collapse floor. Only lightness survives a monochromacy, so a crowded group cannot reach the dichromacies' 0.15 — twelve tokens mutually apart need 1.65 of lightness range — and the categorical/chart groups take 0.065; a three-token status trio needs only 0.30 and `a11y-achromatopsia` reaches it, so the trio keeps 0.11, ratcheted from that palette's own 0.1180. The report names the floor on any row measured against a different one. Each group's report line now names the worst INDUCED pair beside the count, because the ΔE it leads with is the group minimum and can come from a pair that is not a collapse. Reusing 0.15 reports 1229 collapses — 1.91x the worst dichromacy arm, with seven palettes where every group reads ✗. The normal-vision half of the induced test keeps 0.15 for every condition; lowering it too would add 996 pairs a sighted reader already cannot separate. The new arm finds a `--pass`/`--warn`/`--fail` collapse on 31 of 32 palettes — the worst is `pass^warn` at ΔE 0.003 on ardesia-dark, brina-dark and laguna-dark, and `concrete`'s `pass^fail` sits at 0.004; `a11y-achromatopsia` is the only palette with no induced collapse anywhere. No palette value was re-tuned.
- `node tools/cvd-audit.js <palette> --strict` now spans all four conditions, so it can exit non-zero where it exited 0. Gate a palette against the condition it is named for with `--strict --type <condition>`; no npm script or workflow invokes the tool, so no gate changes color.
