- **Exports now say when they ship your speaker notes.** Notes still ride by default, so you can present your own file from any computer. The CLI prints one warning per file for the player, web page, PDF and PowerPoint/LibreOffice exports, and names `--strip-notes`; it stays quiet under `--strip-notes` and `--quiet`. In the Studio, the webpage export states that notes ship, and the PowerPoint (with editable text) and LibreOffice exports gain the same **Strip speaker notes** switch, which leaves every notes pane empty and turns **Re-openable** off, since that copy carries the deck's own notes.
