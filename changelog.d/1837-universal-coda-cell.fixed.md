- **Fixed: the Key Insight panel and the below-note now render on every layout that advertises them.** Both attached by selector shape — two exact DOM positions guarded by a hand-written `:not()` chain — so any component whose transform introduced a wrapper silently lost the block while the manifest went on advertising it. Measured across all 61 layouts, eight were wrong: `compare-code`, `image`, `scene` and `split-panel` swallowed the author's `> …` into a sub-container where it printed as unstyled body text; `contact`, `wifi` and `video` dropped it outright when they rebuilt their section; `premise` laid it out as a third column beside the body. The trailing beats now live in one `.cell-coda` Form Cell, harvested before any structural transform runs.
- **Fixed: the step above a trailing block is now a register change, not a prose step.** It used to be whatever `row-gap` the host happened to carry — 8px inside the stage, which on a card list is *half* the 16px between the list's own cards, so the panel read as one more card. It is now one `--coda-step` (24px): measured across the 51 layouts that host a trailing block, 49 land on it exactly, up from 34. Fourteen canvas layouts (`funnel`, `gantt`, `journey`, `kanban`, `map`, `matrix-grid`, `piechart`, `progress`, `quadrant`, `radar`, `roadmap`, `state-chart`, `timeline-list`, `word-cloud`) had been stacking a 16px section gap on top of the full step for a 40px seam, because the rule meant to make the step uniform was scoped to the stage and never matched them. The two that remain (`image`, `scene`) are centered figure compositions whose own slack supplies the difference; both are unchanged.
- **A component declares how it hosts the universal blocks, instead of being named in a CSS chain.** `coda.dock` names the section's outer structure — `column` (the default, so a new component declares nothing), `row`, or `grid` — measured in Chromium on every layout, only those three shapes occur. `coda.claims` names any trailing element the layout keeps for its own anatomy, replacing both hand-maintained exclusion lists, and the published `authoring.blocks` contract now reads the same predicate the render does, so the two cannot disagree.
- **Changed: `contact`, `wifi`, `split-panel` and `split-compare` no longer advertise blocks they never rendered**, and `compare-code`, `premise`, `scene` and `video` gained blocks they now actually render. The deck lint reports an `insight-*` or `no-note` modifier that has nothing to govern, instead of the engine silently discarding the content.
- Fixed: an `insight-*` modifier on a `split-compare` slide is no longer reported inert. Those modifiers govern the `--insight-label` seam, and split-compare paints that seam on its own verdict card.

- **Fixed: a Key Insight or below-note now sits at the bottom of the slide whatever the body does above it.** The cell used to live inside `.cell-stage`, where it was a flex item of the component's own column and inherited the component's vertical alignment — so the frame's editorial band moved when an author wrote `align-top` / `align-middle` / `align-bottom`, measured on `cycle` at 171px / 85px / 0px above the stage floor and on `content` at 117px / 58px / 0px. Layouts whose body grows to fill the stage (`list`, `cards-grid`) never moved, which is why it read as two components disagreeing rather than as one frame defect. The frame now peels the cell out of the stage wrap exactly as it peels a running `<footer>`, so the stage absorbs the free space and the band lands at content height above the footer — no positioning, no margin, and no change to how any component aligns its own body.

- **Changed: eight chart and diagram layouts no longer advertise a below-note** — `funnel`, `journey`, `map`, `matrix-grid`, `quadrant`, `radar`, `state-chart` and `word-cloud` each claim their trailing paragraph for their own anatomy, so the block never rendered there. `authoring.blocks` now says so and `npm run lint:deck` warns on a `no-note` modifier that has nothing to govern, where before it accepted it in silence. Thirteen layouts changed contract in total.
- **Fixed: the trailing blocks survive an auto-split again.** The coda Cell moving out of `.cell-stage` put it past the bound every scan in the split envelope uses, so a slide that paginated stamped its Key Insight on **every** body page, dropped its below-note, and emitted no dedicated insight page — measured on `examples/split-envelope.md` at 27 pages with the insight six times. The envelope reads the cell beside the stage now, and the same deck is back to 26 pages with each beat landing exactly once.
- **Fixed: five styling families that had silently stopped reaching the trailing blocks.** The `sketch` finish's hand-drawn insight box (its border, radius and shadow), the `head-center` / `head-right` flex, the split-insight page's size-up, and the split note's compact size — all still addressed the block's old position. Measured before the fix: a split note rendered at 46.98px instead of `--fs-body-compact`'s 39.96px on `checklist` and `cards-grid`.
- **The band spans the full width on 46 of the 51 layouts that host one.** `title`, `closing`, `divider`, `image` and `scene` keep a capped or composition-matched measure — those are compositions, not defects.
