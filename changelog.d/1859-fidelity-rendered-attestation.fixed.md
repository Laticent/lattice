- **A `mirrored` row in the Marp fidelity ledger is now attested by RENDERED OUTPUT**, not by a symbol name. The old check asserted that a function of the named shape appeared somewhere in the runtime source — it rendered nothing, compared nothing, and read the source rather than the bundle a preview loads, so it could not fail for the right reason. Each claim now renders a deck through `lib/engine` and the same content through the real `dist/lattice-runtime.js`, and compares. All ten `mirrored` rows are covered. The declared-gap list remains, empty and gated against staleness, so a new row must either get a probe or land there with a reason.
- **Fixed: the verdict-grid and pricing badge mirror dropped the last row of every card.** `transformVerdictGridBadges` assumed the final nested item is body prose and sliced it off; the engine instead tests each item against the state-marker regex. Where a card ends on a marker row — legal markdown that the convention simply does not cover — the engine rendered 6 badges and the runtime printed raw `[x]` / `[-]` markdown to the reader, and a card with one marker and no prose line rendered 3 badges against 0. The runtime now lets the marker decide, exactly as the engine does.
- A change to `lib/runtime/**` now also selects `test:core` under `affected-tests`, so the attestation written to catch runtime divergence is actually run by the edits it guards against.
