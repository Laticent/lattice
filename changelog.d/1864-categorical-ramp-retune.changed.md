- **Breaking:** every palette's `--cat-1..12-fill` and `--cat-1..12-mark` values moved. Twelve categorical slots used to be placed one at a time against a contrast target, which lands them all on the same lightness — so two neighboring hues rendered as one color. They are now solved together: hue and chroma are held exactly, and lightness separates the slots. A deck that hard-codes a categorical hex, or a screenshot baseline that encodes one, will differ; a deck that uses the tokens picks the fix up for free.
- The pale tier now holds all 66 slot pairs apart, not just neighbors — the Mermaid pie paints it with no per-slice stroke, so it is the only thing separating one wedge from the next. On `indaco`, the worst pair goes from ΔE 0.0130 to 0.0574.
- `concrete`'s light categorical chips are a luminance ramp instead of twelve near-identical grays, and `onyx`'s dark chips span a wider range. Both carry §6's spread that the texture-first palettes were always meant to have.
- New `node tools/derive-cat-ramp.js` re-solves the ramps and writes them back. It is deliberately not part of `npm run build`: the values stay hand-authorable, and the gate holds the line between runs.
