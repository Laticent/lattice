- `engineering/workflow.md` § Merging now documents the auto-merge method trap and its verify step. Arming auto-merge without naming a method takes the repository default, which here is a **merge commit** — the one method the repo's own convention rules out. Measured on a live PR: even an explicit `gh pr merge --auto --squash` stores `"merge"`, because `gh` defers to the merge queue's strategy and records the repository default. On `main` the queue's `squash` governs at merge time, so the stored value is misleading rather than dangerous today; that stops being true for any branch the queue does not cover. The section carries the one-line read-back that tells you which you have.
