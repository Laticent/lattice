- **Code slides read one type step larger.** The `code` layout now sets its block at `--fs-body-compact` instead of `--fs-meta` — the same canonical role its `compare-code-block` sibling already used — so code is no longer set at the deck's smallest chrome size. Measured ~20% larger glyphs at every slide format.
- The capacity that follows from it is now MEASURED rather than asserted: a landscape `code` pane holds **14 lines** (it held 16 before this change, while the docs claimed 20 — so the shipped stress example had been clipping its last line). `whenToUse`, `commonMistakes` and the stress sample all carry the real number, and the line-width budgets were re-measured to 102/58/37/36 columns (wide/square/tall/strip).
- `compare-code` is deliberately unchanged: its panes are half-width, and two shipped gallery slides would have started clipping.
