- **Three defects found by CodeQL on deck input are fixed.** Stripping the `debug` attribute took time that grew with the square of a deck's whitespace (over a second for 60,000 spaces); it is now linear. A chart's speaker-note detail turned an author's literal `&lt;` into `<`. The Playground's front-matter panel wrote a value ending in a backslash in a form that swallowed its own closing quote; a value holding `\` or `"` is now written in a quote form the engine reads back unchanged (single quotes, or raw double quotes when the value holds an apostrophe).
- Nine chart and slide helpers that strip tags from labels now strip to a fixed point, and four regex builders escape every special character. Neither changes the output of a real deck; both close CodeQL findings (#1958).
