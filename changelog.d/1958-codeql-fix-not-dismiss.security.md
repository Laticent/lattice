- The Playground's engine, KaTeX and fence-grammar loaders now refuse a script URL that carries a quote, an angle bracket, a backtick, a backslash, whitespace, or any scheme other than `http:`/`https:` before it reaches a `<script src>` or `import()` — closing the CodeQL `js/xss-through-dom` paths through the preview's build-time asset URLs. A well-formed asset URL is unaffected. The notes mask's raw-text HTML-block end test (`<!-- strip-notes -->`) was rewritten off a regex while kept byte-for-byte in agreement with markdown-it, so note stripping is unchanged.
