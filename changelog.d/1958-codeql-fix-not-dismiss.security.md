- The Playground's engine, KaTeX and fence-grammar loaders now refuse a script URL that is empty, carries a quote, an angle bracket, a backtick, a backslash or whitespace, or resolves off the page's own origin and scheme, before it reaches a `<script src>` or `import()`. Only the resolved URL is injected. This closes the CodeQL `js/xss-through-dom` paths through the preview's build-time asset URLs; a well-formed same-origin asset URL is unaffected. The notes mask's raw-text HTML-block end test (`<!-- strip-notes -->`) was rewritten off a regex while kept byte-for-byte in agreement with markdown-it, so note stripping is unchanged.
