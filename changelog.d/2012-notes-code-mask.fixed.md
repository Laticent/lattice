- **`--strip-notes` no longer deletes text out of a code sample.** When a deck's real speaker note also appeared inside a code sample, the scrub removed it from the sample in three shapes: a fence directly under a one-line comment, a fence directly under a line like `<span>x</span>`, and an indented code block. The code scan now reads these the way markdown-it does, so the sample in the shipped source (the player envelope and the `--embed-source` attachment) stays intact.
- **`--strip-notes` now removes notes it used to miss next to backticks.** A note written after an escaped backtick (`` \` ``), between backtick runs of different lengths, or between backticks inside a raw HTML block was read as code and shipped. Code spans are now read the way markdown-it reads them, and only where markdown-it reads inline content.
