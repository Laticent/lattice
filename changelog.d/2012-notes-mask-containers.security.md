- **`--strip-notes` no longer ships notes written inside a list item, a blockquote or a broken code span.** The code mask read a fence in a list item, a code span that crosses a line break, and an HTML block nested in a container as code, so a real speaker note there shipped and the audit stayed silent. `maskCodeRegions` now asks the engine's own markdown-it parser which comments are live and gives those back to the scrub and the audit. Measured over 100,000 generated documents: 1,278 hidden live notes before, 0 after (the scrub too, with an unclosed `<!--` shown in code ahead of the note); the 3,927 other markdown files in the repo mask exactly as before.
