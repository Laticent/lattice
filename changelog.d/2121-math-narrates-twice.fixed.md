- **A math slide no longer narrates its equation twice.** KaTeX puts an `<annotation encoding="application/x-tex">` inside the accessible MathML span, so narration read the equation's MathML and then read the raw TeX straight after it — in shipped caption bytes, `β ^ = ( X ⊤ X ) − 1 X ⊤ y \hat\beta = (X^\top X)^{-1} X^\top y`, with every inline `$X$` doubling to `X X`. The annotation is a source round-trip for copy-paste, not a reading, and is now skipped; the MathML token run a screen reader uses is what gets spoken.
