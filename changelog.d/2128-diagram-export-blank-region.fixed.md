- A diagram that has not finished drawing when a deck is exported now ships as its own source text instead of as a blank space. The export waits a few seconds for diagrams to render; when one is not ready in time the capture used to proceed with the fence hidden — because the stylesheet hides a diagram's source while it is on its way — so what landed in the downloaded file was an empty region, permanently. The unfinished diagram is now released the same way one is when Mermaid cannot load at all: you get the markdown you wrote, and the export reports how many shipped that way.
