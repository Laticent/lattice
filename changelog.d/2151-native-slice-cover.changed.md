  strategies (`redline-blocks`, `kanban-lanes`, `roadmap-horizons`, `journey-stages`) emitted body
  pages only, so a split `roadmap` opened straight into "Phase 01 · Q1" while a split `content`
  slide beside it in the same deck opened on the shared accent field — two shapes for one
  operation. The cover carries the slide's masthead plus a lead-in naming the first member,
  derived by the same `labelOf` the body pages use for "next:", and it declines rather than
  inventing one when the slide has no masthead. Each run is one page longer.
