- `cartesian.js`'s `niceDomain` orders its two arguments before using them. Handed a reversed pair it returned a domain that excluded the data outright — `niceDomain(10, 2)` gave `[7.5, 12.5]`, so the `2` plotted off the chart with no error anywhere. Neither shipped caller can reach it (`scatter` derives its pair with `Math.min`/`Math.max`, `slope` from a sorted model), but this is exported substrate and the next caller has no reason to know the order matters.
