- The quadrant's per-slide size search puts **how many names get painted** ahead of how well they are attributed. Its first cut had that backwards: the attribution budget is measured only over labels that placed, so on a slide whose smallest size already hides a name, any larger size that manages to place that name counts as one more travelling label than the budget allows — and was refused, leaving the slide at the size that drops it. A guard written to stop a chart misattributing a name was choosing to delete one instead. Measured over 600 generated quadrants: 88 slides dropped a name against the bare ladder's 74. With presence as the primary key it is 74, and 5 slides paint more names than the bare ladder ever did. No shipped deck changes — the defect needs a slide whose floor is already lossy, and none of ours is.
