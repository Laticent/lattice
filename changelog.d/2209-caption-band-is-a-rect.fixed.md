- **Fixed: a narrow walkthrough caption no longer reserves the whole width of the window.** A tour's caption always declared the rect it paints, but only its top and bottom edges were read — so a centered `progress` pill (380px) or `split` cap (560px) reported a full-width band, and a reveal whose target sat beside it scrolled the page for nothing. The band now carries its horizontal extent, published as `--vt-chrome-left` / `--vt-chrome-right`. They measure CLEAR space from each window edge, so a full-width caption reports `0px` on both sides and anything written against the existing `--vt-chrome-top` / `--vt-chrome-bottom` pair is unaffected.
