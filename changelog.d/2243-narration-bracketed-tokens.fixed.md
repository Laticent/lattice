- **A bracketed or quoted value is now spoken as a value, not as glyphs.** Any wrapped token skipped every normalization rule Cadenza has, so `($4.2M)`, `"ARR"`, `[CEO]`, `(§5)` and `(12)` reached the voice as raw characters while their bare forms — `$4.2M`, `ARR` — all read correctly. Wrapping punctuation is now peeled before the rules run — the same peel the deck lint already applied to decide a token was fine, which is why the lint had been reporting clean on exactly the tokens that would break. Punctuation that *leads* a value (`$`, `+`, `−`, `§`, `≥`, `±`) is untouched, and a section reference keeps its own parenthetical: `§1798.140(o)` is unchanged.
