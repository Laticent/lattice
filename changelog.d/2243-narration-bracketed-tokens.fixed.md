- **A bracketed or quoted value is now spoken as a value, not as glyphs.** Any wrapped token skipped every normalization rule Cadenza has, so `($4.2M)`, `"ARR"`, `[CEO]`, `(§5)` and `(12)` reached the voice as raw characters while their bare forms — `$4.2M`, `ARR` — all read correctly. Wrapping punctuation is now peeled before the rules run, and the deck lint no longer reports a deck clean on the tokens the voice would mangle. Punctuation that *leads* a value (`$`, `+`, `−`, `§`, `≥`, `±`) is untouched, and a section reference keeps its own parenthetical: `§1798.140(o)` is unchanged.
