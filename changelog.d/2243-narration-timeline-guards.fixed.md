- **A failed audio decode can no longer corrupt a caption timeline.** `align()` accepted any number a player handed it, and three of them broke the timeline silently: a `NaN` duration killed the highlight, hung the read (`onEnd` could never fire) and wrote `NaN:NaN:NaN.MMM` into the exported `.vtt` — a structurally invalid caption file; a zero duration, which a failed decode really does produce, collapsed a cue to a single instant and dragged the rest of the deck backwards; and an out-of-order onset broke the sort the cursor binary-searches, so the read-along went permanently dark. Each is now refused, leaving the cue's estimate in place.
- **New `validateTrack()`** reports a corrupt timeline in plain sentences — non-finite spans, inverted spans, out-of-order cues — for anyone assembling a track by hand or debugging a caption file a player rejected.
- `formatTimestamp` writes `00:00:00.000` for a non-finite input rather than `NaN`.
