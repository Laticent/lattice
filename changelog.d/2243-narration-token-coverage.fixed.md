- **Narration reads the shapes a boardroom deck actually writes.** Ranges (`$1.2–1.4B`, `50-60%`, `2-3x`), ISO dates, clock times, ordinals, decades, ranks (`#1`), versions (`v2.1`) and the two multi-letter finance magnitudes (`$4.2bn`, `$4.2MM`) all reached the voice as raw characters. A measured boardroom corpus went from 19 raw passthroughs to 9, and the rest are left alone on purpose: a slash means four unrelated things (`A/B`, `24/7`, `3.5/5`, `9/20`) and guessing wrong is worse than reading the glyph.
- **Four number defects fixed.** `$1` read "one dollars" (money was the one value path with no singular/plural agreement); an integer of 10^15 or more read the literal word "**undefined**"; a very small decimal like `0.0000001` was **silently dropped from the utterance entirely** while still showing in the caption; and `1x` and `1×` read differently ("one time" vs "one times") because the multiplication sign was rewritten before the multiplier rule could see it.
- **"up +18%" no longer narrates as "up up eighteen percent."** A leading sign reads as a direction word, and the most common phrasing in a commercial deck already carries one.
- **The six status marks read the same way now.** `✔` and `☑` were silenced while the visually identical `✓` and `☒` were spoken as raw glyphs — a Unicode classification, not a decision. All six read "yes" or "no", matching what the engine's own state markers already say.
