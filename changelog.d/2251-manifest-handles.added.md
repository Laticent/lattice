- Component manifests can declare `handles` — the rendered part a spoken sentence can name, and the token inside it that names it (`{ part, names, note }`). The Present Guide reads a generated catalog of these, so it points at a person's name rather than boxing the whole card, and it can place a sentence the narration composed across a part's own spans. Nine components declare one; measured over 187 decks and 10,810 cues, the share of narrated sentences the pointer can place rises from 87.2% to 89.3%, and no component loses one. `table` goes 60.9% → 97.8%, `matrix-grid` 30.4% → 100%, `team-profile` 46.8% → 100%.
- `npm run guide-handles:build` / `guide-handles:check` generate and freshness-gate that catalog; `npm run sweep:guide` now reports which tier answered each cue and prints the roster of components that never get a handle.
- Two gates behind `npm run build:check`: `checkGuideHandles` fails on a declared class nothing under `lib/` writes, and `checkMarkIdentity` pins the twelve component transforms that emit `data-label` / `data-value` — the convention the Guide's chart matcher rests on, which until now nothing enforced.
