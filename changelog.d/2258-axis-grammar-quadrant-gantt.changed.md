- **Breaking:** `quadrant` names its axes with the bracketed axis list that `matrix-grid` and `scatter` already use, one paragraph above the chart: `` `[{Effort, 0..10}, {Reach, 0..100}]` ``. Each member is `{name, min..max, threshold}`, so a threshold now sits inside the axis it cuts (`` `[{Effort, 0..10, 5}, {Reach, 0..100, 50}]` ``). The old `` `Effort 0–10 → Reach 0–100 · targets 5, 50` `` eyebrow now renders as a plain eyebrow: the axes lose their names and the points move to a data-derived scale. `lint:deck` reports the old eyebrow as `quadrant-retired-axis` and its autofix rewrites it. It also names an axis part the chart ignores (`quadrant-axis-part`).
- `quadrant` no longer prints its axes twice. The axis list is removed from the slide and drawn on the axes, the way `scatter`'s is. A plain eyebrow beside it stays on the slide.
- The typed-glyph gate (HARD RULE #29) no longer exempts anything: `isQuadrantAxisEyebrow` is deleted, and an arrow in a quadrant eyebrow now counts like any other typed glyph.
- Fixed: the documented ASCII spelling `` `Effort 0-10 -> Reach 0-100` `` never worked. markdown-it escaped the arrow before the parser saw it, so `examples/adaptive-sweep.md` drew an x-axis named "Effort 0-10 -&gt; Reach" on a 0–100 domain. The migrated deck draws "Effort" on 0–10.
- Narration speaks a quadrant's axes as one sentence each, with name, domain and threshold ("The horizontal axis, Effort, runs zero to ten, with a threshold at five."). It no longer reads the eyebrow aloud, arrow included.
- Fixed: `lint:deck` warned twice on every braced axis list above a chart body (`label-set-above-body` and `label-set-unbound`). On `scatter` one warning told the author to delete a correct axis. A list above the body is now reported as a misplaced key only when it names one of the component's key members.
- `gantt` also accepts the bracketed axis list: `` `[{Timeline, 2026 Q1..2026 Q4, Q3}]` `` gives the window and the `today` point in one span, in either order, and draws the same chart as `` `2026 Q1 .. 2026 Q4` `today Q3` ``. The keyword pills still work and stay on the slide as an eyebrow; the list is removed from the slide. A gantt draws no axis caption, so the name is not drawn. `lint:deck`'s mixed-time check reads the window in both forms.
