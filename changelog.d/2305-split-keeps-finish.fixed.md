- A split run now keeps the deck's finish on every page it emits. Before, `roleOpenTag` replaced a cover's or carousel page's class list and kept only `dark`/`light`/`print`. A `finish:` deck's split covers, and every `split-panel`/`decision` carousel page, rendered with no backdrop, while the same run's body pages kept theirs. The deck's surface registers (`finish`, `mode`, `stamp`, `tone`, `spectrum*`, `corners`, `guards`, `rule`, `eyebrow`, `inline-code`, `headline`, `lift`) now ride the swap, and the split re-injects the `.backdrop` wrapper. `claim:` and `cards:` stay behind because they compose a layout (#2305).
- A finish on an accent-field split cover now draws in the cover's own ink. The presets draw in a new `--field-accent` slot, which defaults to `var(--accent)`, so every existing slide renders unchanged. The six accent covers set `var(--on-accent)` and a `cat-N` tint sets `var(--cat-on-fill)`. Studio-generated finishes read the same slot.
- A `spectrum: solid` / `duo` / `mono` bar and a `spectrum-edge:` rail now read on an accent-field split cover. They draw in the same `--field-accent` slot, so the cover gets a bar in its own ink rather than an accent bar on an accent field.
