- **Breaking:** each shipped theme now lives in its own folder, `themes/<name>/<name>.css` beside `themes/<name>/<name>.manifest.json`, like every other Lattice package. The published import path is unchanged: `@laticent/lattice/themes/<name>.css` (and `<name>.manifest.json`) resolves to the folder's file through the package's `exports` map. Code that read `node_modules/@laticent/lattice/themes/<name>.css` straight off disk, or a CDN's raw file URL such as unpkg's (CDNs ignore `exports`), must use `themes/<name>/<name>.css` instead. Build outputs keep their layout: `dist/themes/<name>-min.css`, the Marp export's `themes/` folder and the Marp kit are still flat.
- `npm run new:theme -- <name>` writes the new palette and its `-dark` twin into their own folders.
