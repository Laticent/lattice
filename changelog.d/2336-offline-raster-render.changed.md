- **Breaking:** the CLI's PDF, PPTX, PNG and image-set renders are kept off the network. Every browser a render starts refuses web requests (images, media, fonts, stylesheets, script fetches, WebSockets), WebRTC traffic and DNS lookups. A remote image in a deck shows the browser's broken-image mark, as it already did in the Studio preview and the `.html` export; local images, `data:` URIs and the bundled fonts, Mermaid and KaTeX are unaffected. Pass `--allow-remote` to fetch as before. No shipped deck is affected: the data-viz gallery renders byte-identical PDFs either way.
- A component's sample slide may not carry an inline `<script>`, a `data:` or `javascript:` script source, an event-handler attribute or a `javascript:` URL; a package carrying one is refused on import. A script loaded by a relative path with an empty body, as the shipped diagram gallery does, is still allowed.
