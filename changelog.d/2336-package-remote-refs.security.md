- A component package whose sample slide (`gallery.md`) loads anything from the network is now refused on import — by the Studio's Library and `.lattice` import and by `lattice packages add`, `check` and `list` — with the URL in the message. The check renders the slide through the engine and reads what a browser would load: images, `<image href>`, `url()` in styles, the `logo:` front matter key, a component's own poster, Mermaid image shapes, and remote link reference definitions. Links, relative paths and `data:` images are still fine, and every shipped gallery still imports. Fabricate warns about it live while you edit a component.
- Motion art (`art` / `poster`) no longer keeps remote references: `<image href>`, `<feImage href>`, `xlink:href` and remote `url()` values are stripped when a scene is saved and again when the Library reads it, so a scene saved before this fix is drawn without them too.
- `lattice` now depends on `parse5`, the HTML parser behind jsdom, for that check.
