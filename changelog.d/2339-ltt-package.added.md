- **`@laticent/ltt`, the Lattice Timing Track format package.** One JSON shape for when each word of a narration is spoken, for decks and tours: the types (`Word`, `Cue` and `CaptionTrack` now live here, and Cadenza re-exports them), a JSON Schema generated from those types, `validateLtt`, and lossless canonical ↔ packed encodings. The spec is `engineering/ltt.md`. `lib/core/ltt-legacy.js` converts the narration inside an already-exported HTML deck into an LTT. Nothing a viewer sees changes: exports are byte-identical.
- **Tour narrators can now time a sentence the way the deck does.** Vetrina's silent and voiced Cadenza narrators accept `acronyms`, `lexicon`, `lang` and `emphasis` from the host. They used to pass only `pace` to Cadenza, so a line with a registered acronym or an emphasized phrase could not be timed as its slide times it. No shipped tour passes the new options yet; a host that does gets the deck's timing, and a test holds the three producers to identical timings.
