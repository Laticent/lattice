- **Breaking:** for a host that implements Vetrina's `Narrator` port, `Narrator.plan(text)` now returns the LTT core's `CaptionTrack` rather than a flat word list, and `findCueWord` answers with `{cue, word, match, text, startMs, endMs}`. Cadenza's narrators already return the new shape.
- Vetrina records a run as a seekable timing track. Pass `record: createTourRecorder({...})` to `run()`, and the storyboard writes one stretch per run of lines between waits. It records how long each `until` hold or awaited `act` took, turns each word cue into an action that `validateLtt` checks, and captures the screen, motion tier and pace the run played at. `replayNarrator(ltt, narrator)` plays a recording back, with the cursor's lead recomputed on a different screen.
- `@laticent/ltt` gains `isStale(ltt, hashes)`. Its first caller is Vetrina's `staleStretches`, which flags a recorded stretch whose storyboard changed and keeps its measured data. `segmentHashInput` takes a segment's emphasis spans, so a re-weighted line hashes differently.
