- `lint:deck` and the Studio Coach now split slides where the engine does under `split: headings`, the default. Suppose one `---` chunk holds two headings and a `_class` sits above the second. Before, lint judged the first slide against that class and missed the second. It now uses the engine's own split rule, so setext headings, a heading inside an HTML block and CRLF files split as they render. Finding numbers still count the `---` chunks you wrote. `--fix` and the editor underline now land on the right slide even when the same line appears on both.
- Lint no longer ends a fenced code sample early when it quotes another fence (```` ```js ```` inside ```` ```markdown ````). It also no longer reads prose that starts with three backticks as a fence.
