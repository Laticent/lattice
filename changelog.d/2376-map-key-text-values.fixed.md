- A chart key sizes its value column to the values it holds. The column was sized for a number ("100%") and right-anchored, so a text value ran left across its own row's name: on five pages of `examples/global-south.md`, a `map highlight` key printed "Caribbean / Central America" over "Global South — North America". The column now grows to its widest value and wraps past about 11 characters. A key whose values are all 5 characters or fewer keeps the old column and renders exactly as before.
