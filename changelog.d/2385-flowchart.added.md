- **`flowchart`, a free-form chart written as a list.** Every item is a shape, a sub-list of shapes makes its parent a group (a tinted background, like a Mermaid subgraph), and an arrow in a row connects shapes by name: `A -> B`, `A => B` for the heavy main path, `-label->` for a labeled line, `&` to fan out. A trailing code span styles what it follows: eight outlines (`:box` `:square` `:pill` `:diamond` `:circle` `:cylinder` `:io` `:doc`), the chart palette's eight slots (`:c1`…`:c8`, or one channel with `:fill-cN` `:border-cN` `:text-cN`), a status word, dashed or dotted lines, `open` / `dot` / `cross` heads, and `:loose` for a line that stays out of the layout. The chart draws its own key from what it uses; a bracketed span below the list renames entries. A `>` blockquote under a shape is a note on a dotted tether. `lr` / `tb` pin the direction, and otherwise the chart takes whichever direction sets the type larger. The browser lays the chart out with the shared elbow router, which weighs every line against one cost: a line never runs through a shape or along another line, a label never collides or sits across a group's border, crossings come first (33 on 1,000 test charts, against 182 for the first router), then balance and symmetry (an org chart's children hang from their parent's side middles, and a fan is drawn as a mirror image), then fewer turns.
- **`lint:deck` reads flowcharts** with the same grammar the render uses, and names each mistake: a shape style on a line, a sub-list under a connection, a shape in two groups, a near-duplicate name, an arrow that is probably a comparison.
- **A backslash escape of `-`, `=`, `<`, `>` or `&` now survives into the rendered HTML** as `<span data-esc>`, so a flowchart can tell an escaped `\->` from a real arrow. It renders exactly as before.
- **A flowchart or state chart pasted into a Studio deck that had none now draws at once.** The preview frame loads the layout engine only if the deck already holds such a chart when the frame is built, so a pasted chart showed as plain tiles until a reload. The runtime now fetches `lattice-dagre.js` from beside itself when a chart needs it.
