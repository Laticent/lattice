- **A zip plugin runs through the CLI.** `lattice packages add <plugin folder or .zip>` installs a plugin that arrives as data (one fence, one `render.js`, its CSS), `lattice packages trust plugin/<name>` approves its code at its SHA-256, and a deck that lists it under `plugins:` draws its fence in the PDF, the HTML and the other exports. A deck that uses it before approval fails with the digest and the command to run. A plugin whose fence is a code language or a shipped plugin's, or that declares `render.exec`, `payload` or `vendor`, is refused at `add`.
- **`lattice packages add` says when it leaves something out.** A package folder or zip that held files below its top level (a plugin's `shared/`) now reports them instead of dropping them silently.
- **`lint:deck` warns about attributes after a plugin fence's name.** ```` ```gantt title="Q3" ```` ignores `title="Q3"` today; the warning (`plugin-fence-attributes`) says so, because the words may take on a meaning later. A listed zip plugin is no longer reported as an unknown plugin.
