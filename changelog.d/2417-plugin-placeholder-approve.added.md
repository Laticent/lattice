- **A zip plugin the deck did not list shows a placeholder, and one click approves it.** Where a block of an installed plugin's fence sits in a deck whose `plugins:` line does not name the plugin, the preview draws a Nacre-toned placeholder with the plugin's name, and a strip above it offers **Approve**: it adds the plugin to the deck's `plugins:` line and records consent for the plugin's code in this browser.
- **A plugin can no longer take over a code language.** A plugin whose fence is a highlight.js language (`python`, `js`, …) is refused at import, and a plugin that conflicts with another in the same zip is refused with the reason instead of being saved and silently not run. A renderer with a lone UTF-16 surrogate is refused (two files could share one approval).
- **A plugin's output loses a `name=` attribute and an empty `<img src="">`.** Both are dropped in the Studio and the CLI door.
