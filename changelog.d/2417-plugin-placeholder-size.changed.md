- **The plugin placeholder takes space the way the plugin says.** A zip plugin declares `contributes.fences.<fence>.placeholder` in its manifest (new in `plugin.schema.json`): `placement` is `stage` (fills the stage, like a diagram), `figure` (the default: the content width at an `aspect`, within the stage's height, like an image) or `chip` (a mark-only square in the avatar size scale, `size` `sm` to `xl`). For a figure, the proportions of the plugin's last drawn output, remembered in this browser, win over the declared `aspect`. It was a thin strip.
