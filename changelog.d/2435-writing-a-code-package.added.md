- **A guide to writing a code package** (`/guides/code-packages/` on the docs site). It covers the one shape Lattice runs, the `"facts": 1` line every code package's manifest needs, the slide a transform receives (`facts` as the stable promise, `html` as the markup it may adjust), `kit.measure`, the worker it runs in (no document, no network), the class and address rules its output follows, how a user approves it, and a complete package to copy. An integration test installs and renders that example from the page itself, so the guide cannot drift from what runs.
