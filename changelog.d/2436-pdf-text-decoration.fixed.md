- The shared PDF writer (the CLI's PDF export since #2404, not yet released) keeps underlines and strikethroughs. It hid each drawn word by its fill color, and Chrome paints a default-colored decoration with that fill, so the line vanished with the text: a `compare-prose rejected` or `decision` slide showed the rejected option's tag unstruck. The writer now pins each decoration's color before it photographs the slide, so the line stays exactly where the browser drew it.
