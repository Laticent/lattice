- **A code package declares which slide facts it reads.** Its manifest carries `"facts": 1`, the version of `slide.facts` it was written for, and Lattice hands it facts in that version. A code package without the line, or with a version this Lattice does not know, is refused by name at `lattice packages add`, at render and at the Studio's Library import, with the line to add. So the day the facts change shape, a package written for the old shape is kept on it or refused plainly, never handed a shape it cannot read.
- `tools/verify-code-sandbox` is a guided check a tester runs on Linux, macOS or Windows: each step shows a command, runs it, checks the result and asks the tester to confirm, and the tool writes a report to send back. It proves a code package is refused until approved, reaches no server once approved, and that the OS sandbox Lattice reports is the one the system applied.
