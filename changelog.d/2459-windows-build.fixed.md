- **`npm ci` builds Lattice on Windows.** The `prepare` step was a shell one-liner that cmd.exe could not run, so a Windows checkout started with no `dist/` and every render failed with "layout CSS not found". It is now `tools/prepare.js`, and the build steps that failed on Windows (the esbuild and tsc calls, the anatomy catalog's console encoding and CRLF output, the CLI bundle's entry path, the agent kit's `import()` of a Windows path) run there.
