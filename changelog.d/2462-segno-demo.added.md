- **Segno has a live demo at `/segno`, and joins the site's Libraries menu.** Segno is a new
  general-purpose grammar engine: it refuses any grammar it cannot read in one pass, and writes
  the parser it accepts as straight-line code. The page runs the real library: write a grammar
  and parse with it, try the inline notation against example slots, and see how it compares
  with six parser libraries on the same inputs. Nothing in a deck uses Segno yet.
