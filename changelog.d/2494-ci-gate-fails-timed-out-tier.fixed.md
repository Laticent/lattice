- The `ci` gate now fails a PR run whose test tier timed out. A tier killed by its own `timeout-minutes` reads `cancelled`, the same word a push-superseded run gets, so the gate passed it (#2494, #2900). The gate asks the API whether the PR's head still equals the run's commit: still the head means nothing superseded the run and the gate fails; a moved head means the newer run decides and the old one still passes.
