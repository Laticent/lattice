- A drawn plugin figure now carries the host's marker, `data-lattice-figure="<plugin>"`, on its container on every surface (the Mermaid pass's `div.mermaid` in a browser, the CLI bake's `div.mermaid-svg`). The Studio's exports, the CLI player capture, Anima's diagram host, the Guide, the diagram layout's CSS and the fit and label gates select it instead of Mermaid's own classes; diagrams look and export exactly as before. A plugin manifest may declare its own output classes as `render.figureClasses` (LPM 0.5-draft), and `checkPluginMigration` keeps every selector outside the plugin off them.
- The CLI has a `--disable-plugin <names>` flag (comma-separated). It switches the plugins off for the engine **and** their CLI bakes, which until now ignored a switched-off plugin and baked its figures anyway; an unknown name fails the run.
- The Studio's and the docs site's previews take a generic `drawn` prop where they took `mermaid` (the sample holds a fence a runtime draws).
