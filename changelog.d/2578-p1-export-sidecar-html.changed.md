- A PDF, PPTX, ODP, PNG or ZIP export no longer leaves a live `<out>.html` sidecar on disk. The emulator captures the raster from that file and then deletes it on success, because the file keeps the deck's own raw HTML and runs it when opened (theme-css note § 10). Pass `--keep-html` (or set `LATTICE_KEEP_HTML=1`) to keep it. An `.html` output, an extensionless output (the sidecar idiom), and the `--player`/`--fluid`/`--read` viewers are unaffected — there the `.html` is the deliverable.
