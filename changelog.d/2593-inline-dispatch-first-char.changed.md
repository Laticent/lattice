- **Changed: inline code renders faster on both paths.** The inline-code dispatcher asked all five kinds (state mark, pill, spark, icon, avatar) about every span. It now looks up the span's first character and asks only the kinds that open with it, so `` `npm run build` `` reaches none. Per ordinary span on the markdown-it path (the escape, `renderHtml`, `offPlugin`) that is 112 ns down to 18 ns, and with one plugin switched off 1,426 ns down to 58 ns. The backslash escape also stopped building reasons it threw away: `` `\^{databse}` `` searched the whole icon set for a "did you mean" (173 µs) only to decide whether to strip a backslash, and now takes about 1.6 µs. Render output is unchanged.
- **Changed: an inline kind's `resolve` and `diagnose` take a trailing flag.** `resolve(text, off, probe)` may return `true` without building its fields, and `diagnose(text, off, explain)` may return `true` without building its reason. A plugin kind that ignores them is still right, only slower (`plugin.schema.json`).
