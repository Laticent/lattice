- The Playground's Galleries sheet has an "All examples" section: a searchable list of every `examples/*.md` deck by title, with its slide count. Choosing one opens it in Explore, so a per-feature demo deck can be reviewed without pasting its source. A new example appears with the next build — there is no list to edit. The decks are static files fetched on demand (the index when the sheet first opens, a deck when you pick it), so the Playground page does not carry them: +0.6 KB eager JS gz measured.
