- **Fixed: a JPEG stored rotated (EXIF Orientation) no longer prints sideways in the PDF.** The PDF writer embeds a JPEG's own pixels and ignored its Orientation tag, so a phone photo stored as landscape pixels came out turned a quarter. A rotated JPEG now stays in the slide photo, where the browser has already turned it upright. The `collage` demo deck gains a slide that proves it, using the new `lib/samples/photo-tall-rotated.jpg`.
