- **Compose edits every inline kind an installed plugin declares.** A kind that declares no `slot` used to stay plain code in Compose; it is now one tappable object whose panel holds its record as a line of text, and a change writes `@kind{…}` whole. Compose and the plugin door now share one rule for what a whole `@kind{…}` call is (`lib/core/named-span.mjs`), so Compose never writes a span the door would not draw.
