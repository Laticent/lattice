- **A plugin's fence drawing can no longer paint over the rest of the slide.** An approved zip plugin whose renderer returned a `position:fixed` box covered the whole slide, heading and page number included. The plugin's root now contains its own paint (`contain: paint`), so anything the renderer positions stays inside the plugin's block, and the door drops `popover` and `command` attributes, which would open the browser's top layer over everything. Two layout effects follow for plugin drawings: anything drawn outside the plugin's box is now clipped at its edge, and a child's margins no longer collapse through the root, so a drawing whose first or last child has a margin grows by that margin. Decks without plugins are unaffected.
