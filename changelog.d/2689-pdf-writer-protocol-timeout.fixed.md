- A very large deck no longer falls back to Chrome's print when the PDF writer needs more than 3 minutes. Puppeteer's 180 s per-call limit cut the writer off before its own watchdog (slides x 4 s), so a 151-slide deck such as `themes/palette-audit.md` came out as a Chrome print (Type 3 fonts) on a slow machine and as the composed PDF on a fast one. The render now raises that limit to one hour; every call stays bounded by the render guard.
