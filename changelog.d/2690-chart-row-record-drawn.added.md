- A chart data row written as one `{…}` record (`- Uptime `{4.2M, target=5.0M}``, `- EMEA `{4.2}``, a heatmap cell `{4.2}`, a matrix-grid cell `{done}`) now draws what its old spans drew, on all 16 charts in the chart authoring model, in the engine, the runtime and the narration. A pill in the row's label, in its `>` description, in a detail row (per the chart's `rows.nested`), in a later list or in a later table still renders as a pill.
- A `{N}` that is the last span of a chart data row is now that row's value (it was a pill the chart did not read); on `map` any `{word}` is now the region's value, and on a `matrix-grid` slide a sole-cell `{done}`, `{partial}` or `{todo}` (any case) is a state, not a label pill.
- Lint `chart-table-unescaped-pipe` warns on a bare `|` inside a table cell's `{> …}` description, which adds a cell and shifts every value after it, and names the fix: write `\|`.
