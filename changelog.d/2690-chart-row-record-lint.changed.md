- Lint `chart-row-record-unread` no longer warns on a record the chart now draws. It reports a record with a field that has no span form yet (bullet's `band=` and `floor=`, progress's `note=`), one that follows another code span on the row, and one the chart's row schema refuses that is not a pill either (`{3, targt=5}`), which used to drop the row from the chart silently.
