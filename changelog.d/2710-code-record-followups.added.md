- **`@code{indent=2|4|tab, quotes=single|double}`** — the code record and the deck's `code:` default set the formatter's indentation and string quote. Prettier, ruff and sql-formatter honor the indent; the quote changes only languages with a choice (JSON, Java and SQL keep theirs). A block that sets `indent=` draws a tab that wide (`tab` is four columns) instead of the browser's eight.
- **`lint:deck` measures code lines on plain slides.** `code-line-clipped` now covers a fence on a slide with no layout, not only `code` and `compare-code`; it no longer reports a `wrap` block, which cannot clip, and it counts a tab at the block's `indent=` width.
