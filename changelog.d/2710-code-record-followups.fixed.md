- **Fixed: "Copy as HTML" keeps a `diff` line's band and a `mark=` line's tint.** The copy wrote each run's own background, so a pasted block showed the bands as ragged patches behind some words and none behind others. Each banded line now pastes as one full-width band, written as `rgba()` so a word processor or mail client reads it.
- **Fixed: `lint:deck` checks a `@code{…}` record inside a blockquote.** The render applied a record written under `>`, but the lint read only unquoted lines, so a bad field or a line range past the end of a quoted block said nothing. It now gets the same four checks as any record.
- **Fixed: a code block's copy buttons show their tooltip in the Studio preview.** The preview takes no pointer events, so hovering a button there left it dim and its label hidden. The Studio now passes the pointer's position into the preview, and the buttons and their labels respond as they do in the Playground.
- **Fixed: `code-line-clipped` judges every slide against the width it really has.** The column budgets are now measured in Chromium for every canvas and every class that moves the code panel: `claim-*` and `compact` (which the rule used to skip), a `venue:` or `scale-*` (which it ignored on a plain slide, so a 90-column line at `venue: conference`, where 68 fit, said nothing), and `align-*` or `stats`. `capacity-scale` reads the same table, so a 60-column line at `venue: hall` and an 89-column one at `venue: huddle`, which render whole, are no longer named. `node tools/measure-code-columns.js --write` re-measures the table.
- **Fixed: a code block's copy buttons no longer sit over its code.** They floated at the panel's top right, so a long first line ran under them (from about 95 columns at 16:9 and 40 at portrait). They now sit in the block's title bar, which every copy block has (empty without `title=`) in every surface, so the browser and the PDF lay the block out alike. The buttons take the bar's type size instead of the browser's 13px, which left them tiny on a 4K deck, and a long `title=` wraps inside the bar instead of running off the panel.
