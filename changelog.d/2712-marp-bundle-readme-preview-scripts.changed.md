- The Export-to-Marp bundle's README now states what the Marp for VS Code preview does with the deck's scripts, instead of saying nobody can confirm it. At VS Code's default preview security level (*Strict*) the scripts do not run, so Mermaid and the other runtime-built slides show as plain markdown. They run at one level only: trust the folder, then **Markdown: Change Preview Security Settings → Disable**. The two "Allow insecure … content" levels do not run them. VS Code stores the level per workspace, so the bundle cannot set it.
