- Every `.vscode/settings.json` Lattice generates for Marp for VS Code (the Export-to-Marp bundle and the Marp kit) now writes `"markdown.marp.html": "all"` instead of `"markdown.marp.enableHtml": true`. marp-vscode deprecated the boolean key in 3.0.0 (2024-12-31), and 3.6.1 shows a warning popup when it is set. The new key needs Marp for VS Code 3.0 or later; an older extension ignores it and shows the deck's raw HTML as text.
