- Mermaid diagrams in an Export-to-Marp bundle no longer go blank in the Marp for VS Code preview. VS Code's built-in `mermaid-markdown-features` extension removes every `<svg>` inside a `.mermaid` element each time it processes a Markdown preview: on load and on every update. When it ran after the Lattice runtime had drawn, the diagrams vanished and stayed blank while the source stayed hidden. The runtime now redraws a diagram whose SVG another script removed, from its cache, or re-renders it when nothing is cached. Measured on code-server 4.141.0 with marp-vscode 3.6.1 at the Disable security level: 4 blank runs in 19 before the fix, 0 in 12 after it (the strip fired in 5 of those 12, and every diagram came back).
