- A `![bg]` picture on an `image` slide now lands on the slide the engine renders it on. The lift reads the engine's own slide boundaries, so a setext heading (`Title` over `---`), the default `split: headings` divider, `***`, a list item's continuation paragraph and a `---` inside math all divide slides as they render. A slide whose `image` class sits in code or has text after its closing `-->` no longer gets a panel, and a `![bg]` quoted in a fence or a comment stays text.
