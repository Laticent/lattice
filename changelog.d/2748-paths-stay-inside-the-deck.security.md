- **A picture a deck names can no longer reach outside the deck folder through a symlink or a typed `file:///…` address.** The CLI checks the real path of every local file it reads: the PDF/PNG/PPTX render, the `--player` inliner, logo-wall marks and the SVG rasterizer all refuse a file whose real path is outside the deck's folder and Lattice's install, draw the missing-picture stand-in, and name the address on stderr. Before, a symlink to `/etc/hostname` or a stranger's `file:///` address was loaded into the render and baked into the shared player. Decks whose pictures sit inside their folder export byte-identical.
