- The CLI now draws function-plot figures for its PDF, PNG, PPTX, `--player` and `--read` exports in a locked page: a fresh, isolated context of the export's own browser, with no network and a strict content policy. It sanitizes each drawing before inserting it into the page being captured. That page no longer loads the function-plot library, and no extra browser starts; an export with plots takes about half a second longer. The plain `.html` export still carries the library, so its plots keep zoom and drag. Exports are byte-identical.
