- The CLI and the library API now typeset math with KaTeX behind a wall: QuickJS compiled to WebAssembly, in the same process, with no browser, no access to files, the network or the process, and hard limits on memory (128 MB) and time (5 s per formula). Each result is checked against what KaTeX emits before it is used. Exports are byte-identical. A formula past those limits (nested about 100 deep, or a matrix of thousands of cells) shows its source. A math-heavy deck takes about a quarter of a second longer to render.
