- A sandboxed plugin can now hand back values besides its drawing. It declares them under `contributes.returns.fields`; each is a `word` from a list, a `number` in a range, a `flag`, plain `text` (256 characters at most) or `markdown` with no HTML, link, image or fence (2,000 at most). The host checks every value and writes it as `data-returned-<plugin>--<field>` on the slide's `<section>`. One value outside its declaration disables the plugin for the whole render, with a warning in the CLI and a note in the Studio. The declaration is part of what you approve, so a plugin that widens it asks again.
