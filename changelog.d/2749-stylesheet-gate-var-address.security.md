- A package stylesheet that holds a network address in a custom property (`--q: "https://…"`, read by `image-set(var(--q))`) or in an `@property` `initial-value` is now refused. Before, the gate passed it and the export fetched the address. The `image-set()` check now reads past an earlier `url(data:…)` or `type()` option. A plugin's `styles.css` is held to the same rules in the CLI and in the Studio import, ahead of the step that applies it.
- The code-package door's markup filter now reads an address with a tab or newline escaped into it (`ht\9 tps://…`), and a style attribute that uses a form feed or a bare CR as a line break. Both used to slip an address past it.
