- Plugins: a plugin can be **embedded** (`"embedded": true` in its manifest, in-tree only). The host admits it on every render, and no `plugins:` list, host narrowing, `disabled` setting or `--disable-plugin` turns it off. A zip or npm package that declares `embedded` is refused.
- Plugins: a plugin manifest can declare an `untagged` inline kind (the bare record `{…}`); only the embedded plugin may claim it, and only one may.
- Docs: the Plugins page gains a Pills page (a demo with three live examples, and the Learn guide) and the site navigation lists it. The hub now says there are eight plugins and that pills are always on.
- Build gate `checkHandRolledPills`: no stylesheet outside `lib/plugins/pills/` may read a `--pill-*` or `--lat-pill-*` token, counted per file against a measured allowlist that only shrinks (a stale entry fails too).
- Pill interface property `--lat-pill-cap`: how much of the surrounding text a pill may fill (0.85 by default). A component whose pill sits beside a caption sets it to 1 so the pill matches the caption instead of undercutting it.
- Pill interface properties `--lat-pill-case` (uppercase labels) and `--lat-pill-tracking` (letter spacing, with the optical-centering indent following it), for components whose pills read as stamps.
- Pill interface property `--lat-pill-size`: a component whose type follows something other than the surrounding text (a chart label sized from its grid cell) states the pill's font size outright.
- Plugin classes have names: **embedded** (always on), **essential** (comes with Lattice; what the docs called a "shipped plugin"), **external** (from an author). `lib/plugins/README.md` and `spec/LPM.md` §3.1a say what each can do. The pill's full contract moves from `base.docs.md` to `lib/plugins/pills/pills.docs.md`.
- The demo deck `examples/pills-plugin.md` replaces `examples/universal-pill.md` (which described the removed universal trailing-code rule): one pill, placed and tinted by cards, a KPI tile, an owner row, a legal update, a roadmap header and a glossary.
