- A slide's `_backgroundImage: url(…)`, an `![bg](…)` image and the deck `logo:` now follow one scheme allowlist (`lib/core/url-scheme.js`): relative paths, `https:`, `data:image/…`, `sample:` and `asset:` render; `javascript:`, `file:`, `http:`, `data:text/…`, `blob:` and protocol-relative `//host/x` are dropped. A dropped `_backgroundImage` or `logo:` carries a `meta/url-scheme` diagnostic; a dropped `![bg]` is silent. A background image may no longer read another value (`var()`, `env()`, `attr()`), which closed a route that turned a `header:` string into a URL of any scheme. Before, a hostile scheme reached a real `background-image` or `<img src>` unchecked. A Windows drive path (`C:\logo.png`) and `http://localhost` are refused too.
