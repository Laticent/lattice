- The installed `lattice` command no longer crashes with `Invalid manifest: dist/styles/manifest.json: name must be a non-empty string`. The crash hit any deck with a class the CLI checks against the deck linter, meaning anything that is not a component or a reserved name, such as `ratio-50-50` on a pane slide. The bundled component loader walked `dist/` instead of `lib/components/` and read the CSS-module index as a component manifest. The loader now resolves `lib/components/` from the package root, the same way it already finds the manifest schema.
