- **Breaking:** a slide's `<!-- header: … -->` or `<!-- footer: … -->` comment now sets that slide only, with or without the underscore. It used to carry onto every later slide, as in Marp. Front matter is the one place to set them for every slide, and `_class: no-header` or `no-footer` drops them from one slide. Export to Marp writes these comments in the underscore form, so the exported deck renders the same. No example or baseline deck uses the plain form.
