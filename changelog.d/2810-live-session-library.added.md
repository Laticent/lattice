- **A live session shares the saved themes and finishes the deck uses.** A guest used to see fallbacks wherever the host's deck used a saved theme or finish from the host's own Library. The host now sends the ones the deck used when sharing started: themes pass the same safety check as a theme in a file from someone else, and finishes travel as recipes each browser rebuilds. A guest holds them only for the session; nothing is added to their Library, and their exports are unchanged.
- **The Live panel lists what the others don't have yet.** When the deck uses a saved theme, finish or custom component the session does not have, or the host's own site palette is a saved theme, it stays listed under "Not shared yet" with a Share button until the host shares it. Custom components are shared by name only, which stops the others' editors from flagging them; their code is not shared yet.
