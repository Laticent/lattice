- **Live sessions render the deck the same way for everyone.** A deck used to follow each member's own site palette and light/dark mode, so the host could see a navy slide while a guest saw a cream one. The host's palette and mode are now frozen when the session starts and apply to every member's preview of a deck with no `theme:`, and the mode to any deck that pins none, through a host drop and a takeover. A host whose own palette is a saved theme is told it is not shared yet, and everyone sees the default theme. Each member's Studio keeps its own palette around the deck, and exports are unchanged.
