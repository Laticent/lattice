- The Studio's and the Playground's live previews no longer run function-plot in the page that holds your deck. A plot is drawn in a sandboxed frame (`sandbox="allow-scripts"`, an opaque origin, no network) and the drawing comes back as sanitized markup. The library is fetched and checked against its SHA-256 pin before the frame runs it, and only that frame may `eval`, because the library compiles expressions. The exports and the plain `.html` have no host page and load the library as before, and the Studio's Webpage bake frame draws in-page so its bytes stay the CLI's. A plot's first draw is at parity with the in-page path (1247 / 1355 ms before, 1292 / 1496 ms after, headless Chromium).
- Mermaid still draws in the page in previews. Its sandboxed frame is built and passes in the real Studio on Chromium, Firefox and WebKit, but it costs a fresh page's first diagram about 1.0 s (2341 ms in page, 3366 ms through the frame), so the host does not offer it yet (`KINDS` in `docs/src/lib/preview-draw-host.ts`).
