- **Compose edits slides that hold math or a block of HTML.** Inline math (`$x^2$`), a `$$` display block and a block of HTML used to lock their slide read-only, which held 51 of the 96 locked slides in the shipped decks (30 for math, 21 for HTML). Each is now one unit that writes its source back byte for byte: a math span and a math block are drawn as the formula (the engine's KaTeX, as native MathML), and a tap opens a panel with a TeX field and a live preview; a block of HTML is drawn as a labeled box and opens a source field. The panel refuses what would break the deck (a blank line inside an HTML block, a `$` inside inline math) and says why. The same constructs inside a list item still lock the slide, because modeling them there would change the render, and so does a slide with an escaped dollar (`\$5`) or an HTML block of the `<?php` / `<!DOCTYPE` kind.
