- Compose opens an installed plugin's inline object (`@gantt-bar{…}`) in a panel drawn from the kind's `slot` in its manifest: a text field for a text word, chips for a vocabulary, a toggle for a flag, numbered slots for a deck color. A pick changes only that word. The span shows as written in the editor (the plugin's code runs only in the preview's sandbox); a parameter the writer cannot take (a list, a range) is named, with "Edit as text" for it. A plugin cannot take an in-tree name (`pill`, `spark`, `icon`, `avatar`).
