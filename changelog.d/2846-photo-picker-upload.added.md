- **The photo picker can add a photo.** A new author with an empty Library no longer has to leave Compose to find the Library first: "Add a photo" in the picker imports through the Library's own flow (the same format dialog, the same naming, saved to all decks), then puts the new photo on the slide. The import loop now lives in one place, `media-import-batch.ts`, and the Library uses it too. (`docs/src/components/studio/PhotoPicker.tsx`, `Library.tsx`)
