- The Studio shows its first slide sooner on a phone. The code editor, which is hidden on the phone's opening view, now builds after the first slide, and the engine, base theme and preview runtime start downloading as soon as the Studio's own code has arrived. On a throttled phone profile over HTTP/2 (what production serves) the first slide moved from 3.97 s to 3.29 s (median of 15 cold loads; the 2026-09-22 build measures 3.86 s on the same machine).
- The Studio's loading animation, in the app and in the page shell that paints before any script, draws its grain with a gradient instead of an image. Chrome no longer counts the loader as the page's largest paint, so Lighthouse's mobile largest-contentful-paint reads 4.5-5.3 s instead of 13.6 s on the Studio. The loader looks the same.
