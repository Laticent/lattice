- The Studio shows its first slide sooner on a phone. The code editor, which is hidden on the phone's opening view, now builds after the first slide, and the engine, base theme and preview runtime start downloading as soon as the Studio's own code has arrived. On a throttled phone profile the first slide moved from 5.0 s to 4.5 s (median of 9 cold loads; the 2026-09-22 build measures 4.2 s on the same machine).
- The Studio's loading animation draws its grain with a gradient instead of an image, which stops the loader from being counted as the page's largest paint: Lighthouse's mobile largest-contentful-paint reads 4.5-5.3 s instead of 13.6 s on the Studio, and the grain dithers as well or better.
- Every lucide icon now ships in one chunk, so the Studio makes about 24 fewer requests at startup; the Playground and the docs pages load about 8-9 KB more JavaScript, and the Playground's first slide is not slower (2.35 s against 2.40 s).
