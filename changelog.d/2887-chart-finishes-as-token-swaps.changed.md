- **Chart finishes are token swaps.** `pigment`, `etch` and `tone` each set a block of `--finish-*` values on the slide, the way `dark` does, and one shared set of mark rules reads them. The generated finish CSS drops from 194 KB to 79 KB raw (9.8 KB to 5.9 KB gzipped). Under pigment and etch every computed paint on the chart gallery is unchanged. No chart stylesheet names a finish any more: the border a pill, bar or key tile drops under `etch` and `tone` is `--finish-border`, and the grouped-hub and quadrant-bubble ink moved into the generator.
- **Under `tone`, a mark's outline takes its own category ink** instead of category 1's, so a pie, tower, stacked bar and quadrant keep one hue per category in the edge. Bodies are unchanged.
- **A chart in a pane now drops the border under `etch` and `tone`**, as the same chart on its own slide does. The rule that dropped it named the chart's slide class, which a pane host does not carry, so a progress bar, status pill or key tile in a pane kept a halo outside its ink edge. The box holds: the pane's own pill padding now gives back the border a finish drops.
