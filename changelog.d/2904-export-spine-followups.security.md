- **A deck's own script can no longer stand in for the CLI's slide camera.** The camera ran in the deck's JavaScript world and skipped loading its code when `LatticePdfCompose.captureSlide` already existed, so a deck that defined that global first was handed the export's picture reader and could replace every slide picture in a PNG set, PowerPoint or LibreOffice export. The camera now runs in an isolated world (a second JavaScript context over the same page, the one browser extensions use), and its file reader is bound to that world alone. A deck can still see a picture the camera has already read for one of its slides, as the PDF export already lets it. Every export's pictures are byte-identical to before.
