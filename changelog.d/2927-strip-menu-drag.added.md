- **Studio:** every slide in the strip (the slide pills and the slide map) has a menu with New slide before, Duplicate, Move earlier, Move later and Delete. Open it from the ⋯ beside the current slide, a right-click, Shift+F10, or a tap on the slide you are already on. The command palette has the same five actions, and an empty deck's strip offers "+ Add your first slide".
- **Studio:** the slide strip is a keyboard surface. Tab reaches the current slide, the arrows, Home and End walk the deck with focus following, and ⌘D / Ctrl+D, ⇧⌘← → / Ctrl+Shift+Left Right, ⌘↩ / Ctrl+Enter, ⇧⌘↩ and Delete act on that slide, only when the strip has keyboard focus. A screen reader hears what each action did, and "?" lists every shortcut. A focused thumbnail no longer drops keyboard focus to the page when the map scrolls it away.
