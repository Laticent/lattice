- **Fixed: the iOS Simulator platform suites now restart a device once when safaridriver cannot start a session, instead of failing at once.** Every iOS failure in `main`'s first three nightlies was a session that never started, so no test ran. `docs/scripts/ios-safari/run.mjs` now reports that case with its own exit code, and `run.sh` answers it once by rebooting the simulator, relaunching Safari and restarting safaridriver, within a time budget that keeps the job under its 30-minute limit. A failed probe is still a failure and is not retried. The Studio suite's photo check now closes the Coach sheet on an iPad with the sheet's own close button rather than a synthetic Escape, which the iPad simulator sometimes ignored. The Studio suite's photo check is now its own suite, `ios-safari-photo`, so each runs only when its own code changes and neither runs out of the job's 30 minutes.
