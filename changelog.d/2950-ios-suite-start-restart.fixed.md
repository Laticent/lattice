- **Fixed: the iOS Simulator platform suites no longer fail a nightly when safaridriver cannot start a session.** Every iOS failure in `main`'s first three nightlies was a session that never started, so no test ran. `docs/scripts/ios-safari/run.mjs` now reports that case with its own exit code, and `run.sh` answers it once by rebooting the simulator, relaunching Safari and restarting safaridriver. It also restarts safaridriver before the next device if it died. A failed probe is still a failure and is not retried.
