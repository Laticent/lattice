- `@laticent/segno-markdown`, the deck model: one CommonMark block pass (markdown-it's block rules, ported rule for rule and held to markdown-it token for token on every committed deck, a rule-surface fuzz and the 652 CommonMark spec examples) that returns a deck's slides, slide boundaries, front matter, directive, fence, plugin-block and leaf ranges from one tape, and re-parses only the edited slide after a keystroke. About 3x faster than markdown-it's block parse on the gallery, 4x on the corpus.
- Slide boundaries now come from the deck model in `slide-boundaries.mjs` (and through it the Studio's outline and rail, and the linter) and in narration export's per-section split. No deck renders, splits or numbers differently.
- `lib/plugins/blocks.generated.mjs` exports `BLOCK_TRIGGERS`, each plugin block rule's start characters from its manifest, so the deck model tries a plugin rule only on lines it can open.
