- **The Studio stays responsive while it exports a PDF.** The vector PDF export used to read every slide in one uninterrupted task and then write the file on the page: on a 40-slide deck at phone-class CPU speed that froze the Studio for up to 4.3 s at a time. It now yields between slides and writes the file in a background worker, so the longest freeze is about 1.7 s. The PDF it produces is byte-for-byte the same.
