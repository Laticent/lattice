- **Every kind of table now has a narrow layout.** When its box runs out of width, a measure-over-time or cross-tab table (Revenue × Q1–Q4, Region × Product) splits its columns into blocks of two, each block repeating the row labels, and goes to one column per block at the narrowest; an option comparison becomes one block per option, each listing the criteria beside its values; a ranked list and a schedule become two-line rows (rank, name and figure on one line; the date above its item), the other columns labeled beneath. Independent lists (Strengths · Weaknesses · Risks) become one block per column; the engine cannot tell them from a record list, so the author names them with the new `table-lists` modifier. The switches stay low (below 20em of the table's own box), so a full-width or half-pane 16:9 slide never changes, and on a slide a layout that would overflow keeps the table form, as the first two layouts already did. A text label column over a body of one number format is now read as a cross-tab (one of five or more columns switches below 24em, as the card table it used to be did), and a year column over figures (`Year | Revenue | Growth`) is a record list rather than a schedule. `matrix-grid` and `roadmap` still keep their grid. In a table whose layout repeats the row labels, each value cell carries its row's label as `data-lat-row`.
- **Fixed:** in a box only a few words wide (a record table in a narrow pane of a 16:9 deck viewed on a phone in the fluid view), a card's fixed label column left its value one letter per line. Below 12em (8em for labels of up to six characters) each label now sits above its value; option and run blocks do the same below 10em, and a ranked row puts its figure under the name. No 16:9 slide reaches these widths.
