- **Raw HTML with many unclosed tables, code paragraphs or tags no longer slows a slide's render with the square of its size.** The engine read table cells, code-only paragraphs (a chart's eyebrow, a masthead's eyebrow, a label set, a legend, a split page's subtitle) and top-level tags with patterns that rescanned to the end of the slide from every unclosed `<tr`, `<td`, `<p`, `<a` or `<!--`. One-pass readers in `lib/plugins/chart-family/shared/html-tables.js`, `lib/core/code-paragraph.js` and `lib/core/tag-scan.js` read the same structure in linear time, and what a slide renders is unchanged. A chart slide that opens with 20,000 unclosed `<p><code>` renders in about 0.15 s, down from 4.8 s. Other patterns on the render path, such as headings, sections and markdown emphasis, are still being converted (`followups.d/3045-p2-regex-recheck-gate.md`).
