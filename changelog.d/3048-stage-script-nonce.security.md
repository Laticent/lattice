- **The Stage now refuses any script it did not write.** The presenter's Stage window seals itself with the same nonce `script-src` policy the Studio preview carries, and stamps each of its own scripts with the page's nonce. A `<script>` or inline handler that gets past the sanitizer in a shared or AI-written deck no longer runs there. Before, the sanitizer was the only wall.
- New test (#2024): an export made with `--allow-remote` now proves in a real browser that `media-src` and `connect-src` refuse remote video, audio, `fetch`, XHR, WebSocket, EventSource and `sendBeacon`, with a control run that shows the same requests arriving when the policy is removed.
