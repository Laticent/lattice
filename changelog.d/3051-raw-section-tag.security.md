- **Security: raw HTML can no longer add or remove a slide.** A raw `</section><section>` in a deck closed the engine's slide and opened a new top-level one, which the engine framed and numbered, so every later slide's number moved up by one; a lone `<section>` swallowed the next slide. The engine now renames a raw `<section>` or `</section>` to `<x-section>` / `</x-section>` in every raw-HTML token, the way it already renamed the split's reserved attributes. The content still shows; group it with a `<div>` instead. Speaker notes, descriptions and say lines that mention `<section>` still read as written.
