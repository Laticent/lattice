- `npm run overflow:check` renders each deck with Chrome's PDF printer (`--chrome-pdf`) again, which cut a full sweep from 1703 s to 643-908 s on a 4-vCPU sandbox. The shared vector PDF writer, the CLI default since #2404, costs about 3 s a deck and runs after the overflow measurement, so it changed the sweep's time and never its verdict. `--writer shared` (or `--writer=shared`) renders the old way for a parity check, `--json` now lists every deck's clipped pages under `clipped`, and the `⏱ sweep cost` line names the writer it measured.
