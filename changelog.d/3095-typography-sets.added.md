- **`typography:` front-matter key — curated type sets.** One word picks the heading and body faces, the eyebrow's voice and the chart's text voice together: `classic` (Playfair Display + Outfit, the default), `ledger` (Newsreader + Inter), `poster` (Barlow Condensed + Inter) and `festival` (Fraunces + Inter). The four new faces ship self-hosted and embed in every export; a deck that names no set never loads them, and the player's Read · Article view follows the deck's set. **Existing `preset: editorial` and `preset: brand` decks change faces**: `editorial` now carries `ledger` and `brand` carries `poster`; write `typography: classic` to keep the old faces. A slide can return to classic with `_class: typography-classic`. In the Studio: Look → Typography.
- **The eyebrow now reads as content, not chrome.** Every deck's eyebrow (the code-only line above a heading) is set in the heading face's italic, as written, a step larger than the header beside it, and half the heading's size on a title, divider or closing. `eyebrow:` still picks its mark; `mode: sketch` keeps its own hand-drawn eyebrow.
- **Chart text speaks the body face.** Axis ticks, category labels and legend keys moved from the mono face to the body face with aligned figures, so they no longer read as the page number and footer. Data labels take the heading face only in `ledger`, whose Newsreader has tabular figures; every other set draws them in the body face. The quote credit is set in tracked capitals.
- New lint: `unknown-typography` for a typo, `type:` answered with "did you mean `typography:`?", and `typography-style-override` when a deck's own `style:` re-points a face the set owns.
- **A deck's own `font-family: Inter` now draws the bundled Inter at 87%.** The set faces ship under their real names with an `@font-face` `size-adjust` that holds Outfit's x-height, so an author's `style:` that names Inter, Newsreader, Fraunces or Barlow Condensed gets that face and its size factor rather than a system install.
- **Translucent text in an ODP is written as the color it appears as**, also over a gradient (the dark title, divider and closing slides). Collabora Online drew each letter of a translucent run as a solid block, which turned the new italic eyebrow on those slides into a gray bar; the PPTX keeps its opacity.
