- Every PowerPoint file Lattice writes now comes from Calco's own PPTX writer: the plain picture-per-slide `.pptx` and the `--editable` one from the command line, and both from the Studio. pptxgenjs is no longer a dependency, so installing `@laticent/lattice` no longer pulls in `image-size` 1.x and its infinite-loop advisories. The files say the same thing (text, fonts, positions, notes, alt text and groups match the old writer's, tested), with three visible differences: identical pictures are stored once, a slide with no notes has no notes page, and the document subject is no longer "PptxGenJS Presentation" when the deck gives none.
- **Breaking:** `@laticent/calco`'s `writePptx` takes JSZip as its first argument, `writePptx(JSZip, deck, outputType)`, as `writeOdp` does. `buildPptx(JSZip, deck)` returns the unwritten zip. `tidyPptxPackage`, `embedPptxFonts`, `groupShapes`, `applyRoles`, `uniqueShapeIds` and the `PptxGenJSClass` / `PptxGenJSLike` types are removed: there is no PptxGenJS output left to mend.
