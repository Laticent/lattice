- Every PowerPoint file Lattice writes now comes from Calco's own PPTX writer: the plain picture-per-slide `.pptx` and the `--editable` one from the command line, and both from the Studio. pptxgenjs is no longer a dependency, so installing `@laticent/lattice` no longer pulls in `image-size` 1.x and its infinite-loop advisories. The files say the same thing (text, fonts, positions, notes, alt text and groups match the old writer's, tested), with these differences: identical pictures are stored once; a slide with no notes has no notes page; a note's line breaks become paragraphs; the document subject is no longer "PptxGenJS Presentation" when the deck gives none; a slide's picture is named "Slide N" rather than "Image 0"; the title and slide-number placeholders use the type and index PowerPoint itself writes; and a drawn mark whose corners the page rounds (`stroke-linejoin: round`) keeps round corners even when its line ends are square. The new bytes pass the ISO 29500 schema, Microsoft's Open XML SDK and LibreOffice; they have not yet been opened in PowerPoint, Keynote or Google Slides.
- **Breaking:** `@laticent/calco`'s `writePptx` takes JSZip as its first argument, `writePptx(JSZip, deck, outputType)`, as `writeOdp` does. `buildPptx(JSZip, deck)` returns the unwritten zip. `tidyPptxPackage`, `embedPptxFonts`, `groupShapes`, `applyRoles`, `uniqueShapeIds` and the `PptxGenJSClass` / `PptxGenJSLike` types are removed: there is no PptxGenJS output left to mend.
- The PowerPoint writer now follows the spec and the browser where pptxgenjs had its own defaults. Text is kerned at every size, as the browser kerns it, so small labels and letter-spaced headings no longer come out wider in PowerPoint. Each run carries the page's language (`lang:` in the front matter, or a `lang` attribute on an element) instead of always US English. A font the reader lacks is described by its own PANOSE and pitch, or by the deck's `serif` / `sans-serif` / `monospace` fallback, so a code font falls back to a fixed-pitch face, not Arial. A slide that is not exactly 16:9 keeps its own aspect at PowerPoint's 13⅓ in, and lengths and opacity are written exactly. A portrait deck's notes page shows its slide undistorted, and a layout that numbers its slides says so to PowerPoint's Header & Footer dialog. The file's properties state only what the deck says: its title is the deck's own title rather than the file name, with no "deck" stand-in, no "Lattice" or "Calco" author, no zero word count, and "Widescreen" rather than "On-screen Show (16:9)".
