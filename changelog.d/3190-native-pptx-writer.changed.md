- Every PowerPoint file Lattice writes now comes from Calco's own PPTX writer: the plain picture-per-slide `.pptx` and the `--editable` one from the command line, and both from the Studio. pptxgenjs is no longer a dependency, so installing `@laticent/lattice` no longer pulls in `image-size` 1.x and its infinite-loop advisories. The files say the same thing (text, fonts, positions, notes, alt text and groups match the old writer's, tested), with these differences: identical pictures are stored once; a slide with no notes has no notes page; a note's line breaks become paragraphs; the document subject is no longer "PptxGenJS Presentation" when the deck gives none; a slide's picture is named "Slide N" rather than "Image 0"; and the title and slide-number placeholders use the type and index PowerPoint itself writes. The new bytes pass the ISO 29500 schema, Microsoft's Open XML SDK and LibreOffice; they have not yet been opened in PowerPoint, Keynote or Google Slides.
- **Breaking:** `@laticent/calco`'s `writePptx` takes JSZip as its first argument, `writePptx(JSZip, deck, outputType)`, as `writeOdp` does. `buildPptx(JSZip, deck)` returns the unwritten zip. `tidyPptxPackage`, `embedPptxFonts`, `groupShapes`, `applyRoles`, `uniqueShapeIds` and the `PptxGenJSClass` / `PptxGenJSLike` types are removed: there is no PptxGenJS output left to mend.
