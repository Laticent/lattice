- **matrix-grid:** on a portrait, 9:16 or phone box, a five-column grid no longer runs off the right edge (the last column read `FIELI`, and its pill `Chie`). The row-axis title now lies flat above the column title, so the columns get the width its rotated side gutter used to take, and either title wraps instead of running off the box when it is long. Landscape and square boxes keep the rotated title.
