- The exported HTML player (`--player`, the Studio's Webpage) now opens a chart's detail cards in Present: hover a mark, or tap it on a phone, and its card opens beside it with the mark's name, value and description in the deck's own theme and mode. Digits 1–9 open mark *n*, 0 or Escape closes, and each chart with details is one Tab stop whose arrow keys walk its marks. A deck without chart details ships none of the card code.
- `@laticent/cenno`, a new zero-dependency popover library (`docs/src/lib/cenno/`): placement that matches Floating UI, the top layer above fullscreen, steady size under pinch zoom, hover with a grace corridor, tap-to-pin, and a card skinned by `--cenno-*` tokens and named parts. 5.4 KB gzipped.
- The exported HTML player no longer turns the slide on a tap in Mobile Safari. Safari reported the end of every touch at the page's top-left corner, so the player read a tap as a long drag; it now measures a swipe from where the finger went down to where it last moved.
