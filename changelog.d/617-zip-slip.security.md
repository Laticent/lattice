- **`lattice packages add` refuses a zip with a hostile entry name.** An archive whose entries name `..`, an absolute path, a drive letter or a backslash is now refused whole (a harmless `./` prefix is still accepted), before anything is read. Before, JSZip quietly cleaned such names up and the package installed; nothing was written outside the package store, but the archive was accepted. The store's own `install` and `uninstall` now also refuse a package type or name that is not one plain path segment, so a future importer cannot write or delete above the store by skipping the manifest checks.
