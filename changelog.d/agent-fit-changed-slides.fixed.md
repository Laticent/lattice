- **Studio:** the Architect no longer lays out your whole deck every time it edits a slide. The fit check that rides each edit now renders only the slides the turn changed and leaves the rest empty, so the page stops hanging for as long as the deck is long (a 40-slide deck blocked the page for about 2 seconds at 4x CPU). The agent is told the other slides were not re-measured and no longer says the whole deck fits; `check_deck`, and any turn that changes front matter (a theme, a size), still measure every slide.
