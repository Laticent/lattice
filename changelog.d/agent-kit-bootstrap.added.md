- **The agent kit now has a small-context read path.** `README.md` is the routing file — a read-path table costed in tokens, the 13 component families with their members, and the cross-cutting authoring rules — and every component now ships as its own `components/<name>.md`. An agent that knows which layout it wants reads **~3.2k tokens** instead of the **~108k** the full catalog costs; one that needs to choose adds `components.pick.md` for ~7.4k. The aggregate files are unchanged for anyone who wants them whole.
- **Fixed a dangling pointer inside the kit.** `components.pick.md` tells the reader to open `lib/components/<bucket>/<name>/<name>.docs.md` — a repository path a kit consumer with no clone does not have. Every such reference in the kit is now rewritten to the file's own kit path, and a test resolves every link in the kit and fails on any that dangles.
- The shared `chart-family` contract ships as `components/_chart-family.md`; eight of the chart component docs point at it, and it was previously unreachable from the kit for the same reason.
