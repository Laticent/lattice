- **The agent kit is now organized by where you are putting it, not by what kind of file each page is.** `README.md` routes by destination — a Claude Project, a Custom GPT, a Gemini Gem, NotebookLM, Copilot, a coding agent, a local model, or one paste into any chat — and each `start/` page names the exact text to paste and the exact files to upload.
- **New `paste/`: three ready-made instruction texts**, each sized to a documented platform cap and gated in the build so it cannot outgrow it. `standard` fits every instruction box measured (Windsurf's 6,000-char global rules file truncates silently past it); `max` fits the 8,000-char Custom GPT and M365 caps; `solo` is self-contained — 20 layouts with their real skeletons and a worked deck — for a local model or a single paste.
- **New `upload/`: ten pre-bundled knowledge files** with globally unique names. Knowledge uploaders cap file *count*, not bytes, and flatten folders; the kit's 92 files cleared none of those caps and carried six files named `README.md`.
- **New `render/`: how to turn a finished deck into a PDF.** The kit previously documented no render step at all — a search of all 92 files for `npx`, `marp-cli` or an install command on the authoring path returned nothing.
- **New `examples/`: five complete, renderable decks.** The kit shipped none; the most `_class` directives in any single fenced block was one, and no two slides were ever separated by a `---`. The four real decks are copied from `exemplars/` with two transformations, both so they render through the route the kit documents: the palette line becomes `cuoio`, and the runtime `<script>` tags are appended.
- **New `repo/` and `plugin/`:** `AGENTS.md`, `CLAUDE.md`, a Cursor `.mdc` rule and a skill for coding agents, plus the same skill as an installable Claude Code plugin.
- **Fixed:** generated front matter and every worked example now say `theme: cuoio`, not `indaco`. The Marp kit published beside this one registers only `cuoio` and `cuoio-dark`, and Marp resolves palettes by name — so the kit told every model to write a theme its own no-install render route could not resolve, and the deck rendered unstyled with no error.
- **Fixed:** the 61 empty `## Demo deck` headings — every component file now links to its live page on the docs site, which carries every variant rendered plus an in-browser editor. Also 244 links that pointed at component files a bundle does not contain.
