- **New LLM agent kit, published to the orphan `dist-kits` branch under `agent/`.** Everything a model or coding agent needs to author a Lattice deck, fetchable one file at a time with no clone, no `npm install` and no build: the six generated catalogs (`components.pick.md`, `components.md`, `components.json`, `grammar.json`, `forms.json`, `concepts.json`) plus `lattice-primer.md` — the **same** authoring primer the Studio chat sends to its own model, generated from the live manifests by the same two functions the Studio calls, so it cannot drift into a second source of truth.
- **`dist-kits` replaces `dist-marp-kit`,** carrying both kits (`marp/` and `agent/`) behind one name, one ruleset and one publish. It is republished on every push to `main` that changes an input, with a nightly backstop, by `.github/workflows/publish-kits.yml`.
- **The branch root carries a `.vscode/settings.json` fallback.** Moving the Marp kit from the branch root into `marp/` would otherwise break its workspace-relative theme paths and render **unstyled slides with no error**; opening either the branch root or `marp/` as a VS Code workspace now works.
- **`npm run build` gained an `agent kit (dist/agent-kit)` step** (`tools/build-agent-kit.mjs`), behind the same freshness gate as every other generated artifact.
- The three places that route an agent to `dist/docs/components.pick.md` — `CLAUDE.md`, `AGENTS.md`, `README.md` — now say the file is generated, name the command that produces it, and link the published branch for anyone without a clone.
