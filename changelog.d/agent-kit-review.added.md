- **The kit ships a runnable, independent deck checker.** `review/check.mjs` is the *same* reviewer AND the *same* linter the Lattice Studio runs on decks its own model writes, bundled as one self-contained file. `node check.mjs deck.md` names what is wrong — an invented `_class`, a card written flat where the layout needs nested bullets, placeholder titles, headings that are labels rather than takeaways, a missing ask, elements past their word budget — each with the fix, in about a tenth of a second, **offline and at zero token cost**. `--json` emits one envelope carrying a `partial` flag, `--strict` exits non-zero. It reads the kit's own `reference/components.json` for per-element word budgets, and says plainly when that is absent rather than reporting a partial check as clean.
- **Why it is there:** a model reviewing its own draft against a rubric it just read will declare the draft fine. The checker is code, so it cannot be talked into approving. It catches the falsifiable half; `review/rubric.md` lists the same checks in plain form for a human pass, and taste is still the reader's.
- **Every folder is now its own entry point.** `README.md` in each of `authoring/`, `components/`, `skills/`, `review/` and `reference/` says what is inside and in what order to read it — and GitHub renders them on open, so a human browsing lands oriented. The root `README.md` is the single front door, costed by task — one door, so a reader is never choosing between two.
- **`components/README.md` carries what to use a component FOR, what it is NOT for, and what to use instead.** All 61 components, derived from their manifests' `antiPatterns` and the 244 `related` edges. The pick list truncates to a first sentence and says the when-not-to-use half is deliberately off that surface; choosing between two plausible components is exactly where an agent goes wrong, and the deciding fact is the anti-pattern.
- **`skills/README.md` resolves the rules the skills cite.** The seven skills still ship byte-identical to `design/skills/`, so their "HARD RULE #N" citations and repo paths remain — a generated glossary now says what each cited rule means, and the index states plainly that repo paths and `npm run` commands assume a clone.
