- The issue mirror is now `backlog.d/`, one generated file per open issue, and `BACKLOG.md` is gone. Each file carries the issue's column, its area, type and priority labels, its `needs:` flags, and its swimlane and acceptance check, read by the triage gate's own parser. `npm run backlog` lists the open issues and every `followups.d/` item in one view, grouped by area and sorted by severity, and filters with `--area`, `--min`, `--issues` and `--followups`.
- Every `followups.d/` item now carries `area` (an `area:*` label name), `severity` (`high`, `medium` or `low`) and `swimlane` (the governing doc's repo path). `checkFollowups` requires all three and refuses `severity: critical`, which belongs on an issue. All 215 existing items were classified, and one duplicate was merged, leaving 214.
