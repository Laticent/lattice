- PDF exports draw finish slides fast in iOS Preview and Acrobat (they used to draw about a second a slide, in pieces) and now match the Studio, soft `clear` edge included. The export rebuilds each finish backdrop: the soft layers become one tiny image, the texture plain vector lines, marks stay vector. File size stays close to before (a 16-slide finish deck: 197 KB → 214 KB). `--keep-vector-finish` keeps the stylesheet's own drawing.
- **`color-mode: print` no longer draws a finish**, on screen or in any export: the black-and-white handout carries no glow, texture or margin bar.
