- **LibreOffice Impress export.** `lattice deck.md deck.odp` writes an OpenDocument Presentation: one full-bleed image per slide, like the `.pptx`, with speaker notes on each page's notes view and each slide's `describe:` text as the picture's alt text. Lattice builds the file itself, so exporting needs no LibreOffice install. `--strip-notes` removes the notes.
- **Editable office export.** `--editable` on a `.odp` or `.pptx` turns every paragraph into a real text box in the deck's own font, over a picture of the slide with its text removed, so the file can be edited in LibreOffice Impress or PowerPoint. Both formats embed the deck's fonts, every weight included, so the text looks the same on a machine that does not have them. Charts, diagrams and equations stay part of the picture.
- **Studio: LibreOffice export and editable text.** The Share sheet has a LibreOffice row (`.odp`), and the PowerPoint and LibreOffice options steps have an Editable text switch that does the same as `--editable`.
- **Calco (`@laticent/calco`), the office-export library.** A new sibling library that turns a rendered HTML slide into an editable `.odp` or `.pptx`: a reader that measures each paragraph and hides it for a clean background photo, and writers for both formats. It has no dependencies of its own (JSZip, PptxGenJS and a font pinner are passed in). Lattice is its first user.
- **`/calco`, the Calco page.** A live demo on plain HTML slides: see what Calco reads, lift the text, and download a real `.odp` or `.pptx` written in the browser. Listed under Libraries.
