- The Studio editor now offers `cards-top`, `cards-center`, `cards-stretch` and `cards-spread` after `_class: cards-stack`. They already moved the default column's cards (`cards-top` lifts the first card from 206 px to 178 px down the slide; `cards-stretch` grows each card from 116 px to 135 px), but the measured modifier table still recorded them for the `horizontal` variant only, so the editor hid them on the default column.
