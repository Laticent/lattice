- Chart SVGs now hide their marks from the accessibility tree, so a screen reader hears each chart's curated description once instead of hearing it and then walking every tick, category and value again as loose text. `role="img"` was believed to do this — ARIA calls it children-presentational and ten docblocks across nine components said so outright — but Chromium does not implement it that way for SVG: measured over the rendered gallery, all fifteen chart roots leaked their whole subtree, 24 unignored nodes under `bar` and 223 under `map`. The marks now ride in an explicit `aria-hidden` group, with `<title>`/`<desc>` left outside it so every chart keeps its accessible name.
- Nothing changes visually, and nothing changes for find-in-page: `aria-hidden` text still paints, stays in `textContent`, and is still matched by the browser's text finder.
