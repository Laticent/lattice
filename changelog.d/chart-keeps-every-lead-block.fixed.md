- **A chart keeps every block written before its figure.** The chart wrap kept paragraphs only and dropped a code block, blockquote, table or raw HTML between the heading and the figure without a warning, on a chart slide and in a chart pane alike. Each now renders above the figure, whole and in the order written, in a `div.chart-lead-block`. It hides at `claim-hero` and `claim-bleed`, a split chart carries it on its first body page only, and the Read · Article view carries it ahead of the figure. A table before a table-data chart (`heatmap`, `matrix-grid`, `roadmap`) is still read as the chart's data. No shipped deck had such a block, so every committed deck renders byte-identical. `examples/chart-lead-blocks.md`.
