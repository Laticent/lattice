- **Icons on flowchart and state-chart nodes.** A shape's style record takes `icon=` from the icons plugin, which draws the icon beside the name (above it when the chart is pinned `tb`): `` `{#api, diamond, c2, icon=gateway}` ``. `icon-only` draws the icon alone and keeps the name as the hover title and what a screen reader says. `lint:deck` coaches an unknown icon name, `icon-only` with no icon, an icon on a group, and an icon-only row with no words. With the icons plugin off, a node shows its name, as if no icon were written. Charts that write no icon render byte-identically. Demo: `examples/chart-icons.md`.
