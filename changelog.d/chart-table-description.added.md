- Heatmap: a `{> prose}` description in a table cell describes that cell (replacing the `note=` annotation, which still reads), in a header cell it describes the column, and a column headed `{>}` holds one plain-text description per row (only the first such column; lint warns on a second, and on a header description with no column name before it). A description on an empty cell is kept and the cell stays unmeasured, the `{>}` column is taken out before the 12-column cap, and the narrator and the chart's text description say all three.
- Lint: `chart-description-unread` warns on a `{> …}` description in a list row or in a table cell of a chart that does not read one, and moves a list row's description into a `>` quote with a fix.
