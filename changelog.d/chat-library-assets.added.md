- The Studio chat can use the Library. When the Library holds photos or videos, the chat sees a short list of them (name, shape, whether they are kept to this deck, and a caption once it has one), so "make a collage of my photos" writes real `asset:<name>` references instead of placeholders. It can search the Library (`list_assets`) and, on a model that accepts images, look at up to six small thumbnails a turn (`view_asset`), then save a one-line caption on each photo (`caption_asset`). A captioned photo is read as text from then on and never looked at again. A deck with an empty Library sends the chat nothing extra. A model that cannot read images says so and works from names and shapes. Videos are listed but cannot be viewed.
