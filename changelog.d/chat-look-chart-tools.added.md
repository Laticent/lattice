- The Studio chat can change a deck's theme or finish (only to names the Studio ships). It can turn numbers into a bar, line, pie or stacked-bar slide; a value that is not one number is refused instead of drawing an empty bar. And it can look at a slide: on a model that takes pictures, `render_slide` sends it the slide as export would draw it, up to three per turn. Theme, finish and chart changes stage on the draft like any edit.
