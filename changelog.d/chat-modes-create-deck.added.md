- The Studio chat has three modes on its composer bar. **Talk** reads and answers and changes nothing. **Review**, the default, stages edits for you to apply. **Auto**, for one visit, applies a clean edit at once after saving a History checkpoint. An edit that deletes slides or rewrites most of the deck still waits for Apply, and Auto never applies during a live session or after a stopped turn. Code enforces the mode twice: the tools each request carries, and a gate on every tool call.
- The Studio chat can create a new deck. It drafts the whole deck and shows a confirm with the title, the slide headings and any checker errors. Nothing exists until you press "Create and open"; the new deck then opens with a chat line pointing back to the conversation that made it.
