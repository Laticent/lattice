- The Architect chat header now has a **Chat metrics** dropdown where the bare session figure used to be. It shows what this session, this deck and today have cost (a new spend ledger, bucketed by local day and deck, kept 120 days), how full the model's context window is (a ring beside the figure turns amber at 70% and red at 90%), the share of the prompt read from cache, and the last reply's cost, model calls and thinking tokens. All of it comes from the `usage` block each reply already returns, so it adds no request and no charge.
- Architect replies now have a **Show work** link that opens what the Architect sent, thought and ran: tokens by part of the prompt (primer, deck, conversation, tools, documents, photos), then each model call with its cost, its thinking when the provider streams it, and every command as a link that expands to the arguments it sent and what came back. The trace is saved with the reply (capped near 8 KB, thinking cut first) so it survives a reload. While a reply streams, a one-line excerpt of the model's thinking shows above the status line. None of it adds a request: it reads the thinking, arguments and usage already in the stream, and no `reasoning` setting is sent to get it.
