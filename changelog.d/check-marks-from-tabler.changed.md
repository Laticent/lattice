- The six check marks (check, dash, x, slash, question mark and the chart dot) are now drawn from Tabler Icons, the same pinned set the icons plugin uses, instead of hand-made SVG, in HTML slides, SVG charts and PowerPoint exports alike. Every check style looks the same; the one visible change is a slightly steeper slash on `[/]`, and the bold slash on SVG charts now matches the HTML one's weight.
- Every check is now the same size, height and gap as its siblings, in every style and container: the open `[ ]` and unknown `[?]` rings no longer paint larger than the solid answers, `checks-ringed` checks no longer crowd their pill's edge, and `checks-bold` discs sit centered in running text. `@check{…}` takes a pill's size, `sm`, `md` or `lg` (`@check{yes, label=Residency, lg}`), and a check pill matches an icon pill of the same size. The open and unknown rings read slightly heavier than before, and a solid disc in the default style is about 2.6px smaller on a 1280-wide slide, its rim now inside the same footprint as every other answer.
