- **Fixed: on a busy machine the CLI no longer gives up starting Chrome after 30 seconds.** Puppeteer's own 30-second launch limit fired before the CLI's 90-second render watchdog, so a slow Chrome start failed with "Timed out after 30000 ms while waiting for the WS endpoint URL". Every browser `lattice` starts to render or export a deck now gets the watchdog's limit, which `LATTICE_RENDER_WATCHDOG_MS` still sets. A Chrome that never starts now fails after about twice that limit (180 seconds by default), because the render is retried once with hardening flags; it used to fail at 30 seconds. `lattice video` keeps Puppeteer's default.
