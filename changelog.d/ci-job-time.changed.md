- **CI:** `studio-smoke` no longer records a trace and a video for each of its 155 tests (`E2E_RECORD=off`, set only on that job). Recording was about a third of the job's time, and the job was hitting its 20-minute cap. The nightly e2e suite and local runs still record everything.
- **CI:** the docs Vitest suite moved out of `docs-build` into a new required job, `docs-test`, that runs beside it, and runs on 4 workers instead of 3 (387 s to 313 s on 4 cores, same 639 files passing). It was docs-build's longest step. The `ci` gate requires `docs-test` as it does `docs-build`.
- **CI:** `docs-build` and `studio-smoke` no longer run a separate root build: their `npm ci` already builds the built-not-committed artifacts (the root `prepare` script), so the step built them twice. The route-budget base build runs `npm run build:uncommitted` instead of the full build. The committed artifacts are already in the checkout, and `lint` checks them against their generators.
- **CI:** the docs horizontal-overflow guard (`npm run check:overflow`) checks its four widths at once instead of one after another: the same 40 states and the same pauses, 106 s to 62 s.
