- The CLI renders a `.lattice` project file from the Studio: `lattice deck.lattice deck.pdf` (or `.pptx`, `.odp`, `.html`, `.png`, `.zip`). It opens the file with the same checks the Studio uses and takes the photos the deck names from the file as the Library stored them. The saved themes, components and plugins the file carries are used for that render only, never installed, and the ones you installed still work alongside them. A package in the file wins over an installed one of the same name, and the CLI says so.
- `--trust` runs the code in the components and plugins a `.lattice` input carries, for that render only. Without it, or an approval from `lattice packages trust`, a render that needs that code fails and names the package. Nothing is written to the trust store.
- The CLI writes a `.lattice` too: `lattice deck.md deck.lattice` packs the deck and the installed theme and components it uses. It starts no browser and runs no package code. From a `.lattice` input, the deck's title, its review comments and every package the file carried go back out with it. Photos that came in a `.lattice` input go through the same cleaner as the Studio's Library, so one the Studio made comes back out byte for byte and a camera original packed by hand loses its location; only the ones the deck names go, as in the Studio. Photos from an `assets/` folder go the way the Studio keeps an original: their location, camera data, text and comments are removed, and the pixels, transparency and rotation stay. A photo the CLI cannot clean (a HEIC, an AVIF, a damaged file), or a link in `assets/` that points outside the deck's folder, is left out and named with the reason, and photos past the size cap are named too.
- `--strip-notes` and `--strip-say` work on a `.lattice` output the way they do on `--reopenable`'s copy: the speaker notes and say lines are removed from the deck it carries, and its review comments stay out.
- `--reopenable` now carries the deck's photos by the same rule, up to 32 MB. It used to carry none, so a re-openable PDF made by the CLI opened in the Studio with every photo missing.
- The CLI now refuses an input that is neither Markdown nor a `.lattice` (a PDF, a picture) at once. It used to read the bytes as Markdown and fail after a 60-second timeout.
