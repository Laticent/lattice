- **CLI `--reopenable`** puts the deck inside a `.pdf` or `.pptx` as a `.lattice` project, so whoever you send it to can open it in the Studio with Import deck… and edit it. It is the same payload the Studio's "Re-openable in Lattice" switch embeds: `lib/core/reopenable.js` now builds and places it for both tools, so a deck is re-openable whichever tool exported it. Comments never ride along. Hidden slides do, and so do speaker notes unless you add `--strip-notes`, which scrubs the embedded copy too. The installed theme and components the deck uses travel with it as package folders, and the payload's clock is pinned like every other PDF date, so an unchanged deck still re-renders to the same bytes.
