- **A code block that overflows a phone or tablet slide splits between its lines.** Every code line wraps on a square, portrait, story or mobile slide, so a single block of a few long lines could run off the bottom while the split still counted it as under 12 lines. The split now measures each line, wrapped rows included, and cuts the block between lines, with the heading on a cover page. Line numbers continue across the pages. The first page of a split block no longer opens with a blank line.
