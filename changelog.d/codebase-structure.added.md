- `npm run structure` reports the codebase's parts and layers: each part's size, coupling and cohesion, plus any loop between parts, any import that points up a layer, and any break in the plugin boundary. `build:check` now fails on all three (`tools/check-structure.js`). `lib/` and the docs site no longer form import loops. See `engineering/decisions/2026-10-11-codebase-structure.md`.
- The plugin boundary is the Hollywood contract: the host calls a plugin and hands it what it needs through `ctx`, and a plugin imports only its own folder, the workspace libraries and the plugins its manifest `requires`. The interim `lib/plugin-kit/` is gone. The host tools that still import a plugin's files are listed in its manifest's `hostApi` and held at 14 files by a ceiling that can only fall. See `engineering/decisions/2026-11-01-plugin-contract-hollywood.md` §9.
- The charts are one plugin with many kinds. The 28 chart components now live in `lib/plugins/chart-family/kinds/`, and the engine's chart frame (`lib/transformers/chart-frame.js`) runs the section walk, the title and caption frame, and the record bridging that every chart shares; a kind only draws. The kinds' remaining imports of engine code are counted, and the count can only fall (`tools/structure.js`). Every deck renders byte-identically to before. See `engineering/decisions/2026-11-01-charts-one-plugin.md` and `2026-11-02-slide-facts-for-kinds.md`.
- `npm run identity:check` renders every shipped deck (442 of them: examples, the baseline decks and every gallery) through this tree and through another commit (`--ref`, default `origin/main`), and compares the HTML, the CSS and the deck linter's findings. It exits 1 on any difference, so a refactor that must not move output can prove it.
- The tag stripper the engine and the Playground use to read plain text out of markup (`removeTags`, `@laticent/markup`) now runs in linear time on any input; a slide full of unclosed `<` could make the old pattern take quadratic time. Output is unchanged.
