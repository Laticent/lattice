- `npm run structure` reports the codebase's parts and layers: each part's size, coupling and cohesion, plus any loop between parts, any import that points up a layer, and any break in the plugin boundary. `build:check` now fails on all three (`tools/check-structure.js`). `lib/` and the docs site no longer form import loops, and a plugin imports only its own folder and `lib/plugin-kit/` (chart-family, the in-tree chart dispatcher, is the one exception).
