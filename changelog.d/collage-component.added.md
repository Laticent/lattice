- New `collage` component (imagery): four to six photos of any shape, packed edge to edge into one frame with no cropping. List the photos (`- ![Alt](photo.jpg)`) under an eyebrow, title, subtitle and one description paragraph; the layout reads each photo's size and finds the tightest arrangement. The packer picks the order by default, and `ordered` keeps the order you wrote. `fill` allows up to 8% crop to close empty space, `above` puts the text above the photos, `bleed` runs the photos across the slide, and `mirror` flips the text side. A trailing code span after a photo sets hints for that photo (`hero`, `top`, `bottom`, `left`, `right`, `center`, or a ratio like `3:2`). The page number is hidden on a collage. A collage never splits across slides. Hover focus is in the PDF-safe CSS; click-to-enlarge on live surfaces follows separately.
- `masonry` and `mood-board` join the component tag vocabulary so catalog search finds `collage`.
- Narration names each photo of a `collage` by its alt text, one sentence apiece, and the Present Guide's pointer lands on the photo as it is named. The article view lists every photo, not only the first.
- Four lint rules for the collage: `collage-count`, `collage-alt`, `collage-bg` and `collage-hint`.
