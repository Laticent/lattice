- New `collage` component (imagery): four to six photos of any shape, packed edge to edge into one frame with no cropping. List the photos (`- ![Alt](photo.jpg)`) under an eyebrow, title, subtitle and one description paragraph; the layout reads each photo's size and finds the tightest arrangement. The packer picks the order by default, and `ordered` keeps the order you wrote. `fill` allows up to 8% crop to close empty space, `above` puts the text above the photos, `bleed` runs the photos across the whole slide with no header, footer or page number, under a translucent title card, and `mirror` flips the text side. A trailing code span after a photo sets hints for that photo (`hero`, `top`, `bottom`, `left`, `right`, `center`, or a ratio like `3:2`). The page number is hidden on a collage. A collage never splits across slides. Hover focus is in the PDF-safe CSS. Click or tap a photo to enlarge it on the Playground, the Studio preview and the exported HTML player (Enter or Space on a focused photo works too; Escape, a click away or the close button closes it). The player carries the opener only when the deck has a collage, so every other export is byte-identical. The Present audience window does not enlarge in this release.
- `masonry` and `mood-board` join the component tag vocabulary so catalog search finds `collage`.
- Narration names each photo of a `collage` by its alt text, one sentence apiece, and the Present Guide's pointer lands on the photo as it is named. The article view lists every photo, not only the first.
- Four lint rules for the collage: `collage-count`, `collage-alt`, `collage-bg` and `collage-hint`.
- The description sits straight under the header as a plain paragraph. The header's own rule (the `rule:` register styles it) is the only line, with no second hairline above the description and no empty gap between them.
