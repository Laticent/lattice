- A component manifest can now say `"spectrum": false` (no spectrum bar) or a style name (`"on"`, `"solid"`, `"duo"`, `"mono"`) to pin one. The engine and the browser runtime apply it identically and drop any spectrum class the author set on that component's slides. No shipped component uses it yet. `npm run check:edge-shift` fails if an opted-out component draws a bar or moves with the placement.
