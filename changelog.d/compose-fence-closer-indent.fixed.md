- Compose now reads a fenced code block's closing line the way CommonMark does. A line indented four spaces (or a tab) inside a ``` fence is code, not the fence's end — so the math or table after such a fence still locks the slide in Compose, instead of unlocking it and letting the next edit corrupt it. A fence nested in a list item still closes at its own indent. Compose also stops lengthening a fence around a body line indented four or more spaces, so the author's ``` comes back unchanged.
