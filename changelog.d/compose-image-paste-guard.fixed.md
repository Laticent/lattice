- **A pasted image can no longer write a slide boundary or a background-image directive into the deck.** An `<img>` pasted into Compose with a line break in its alt text or title wrote the line break into the deck source, which started new slides and could carry an `_backgroundImage` directive the export would fetch. A pasted image now takes only a clean source, and the Markdown writer keeps an image's alt text, title and source on one line.
