- Compose's clipboard now speaks Markdown. Pasting Markdown (from a text editor, a chat reply, VS Code or a `.md` file's text) turns slide breaks into slides, `<!-- _class: … -->` comments into layouts and inline syntax into formatting. Before, it saved the text escaped into the deck (`\- \*\*Revenue\*\*`, `\---`). Copying from Compose puts the selection's Markdown on the plain-text clipboard: a phrase as its inline Markdown, slides with their layouts and breaks, and the whole deck as the deck file. ⌘⇧V still pastes text literally.
- Pasted slides go after the slide the caret is in (before it at its very start, in place of an empty one), never splitting it. Pasted Markdown with headings or lists keeps them as blocks.
- A pasted deck's front matter (theme, size, pagination) is set aside, not applied to the open deck, and the Studio says so. Markdown that would load anything from another site is refused with a message (the paste is rendered through the engine and checked the way Insert checks a sample slide); paste it in Source if you trust it.
- A deck file dropped on Compose opens as a new deck, as it does anywhere else in the Studio. Before, the editor swallowed the drop with no message.
