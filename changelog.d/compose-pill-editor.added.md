- Compose draws a pill as the slide draws it, in the deck theme's own colors, and hides its `{SHIPPED, c2}` text. Click the pill to change its label, shape, color and size from one editor (a popover on desktop and tablet, a sheet on the phone), so authors no longer type the grammar. Each pick rewrites only the word that was changed (a pill written `{BETA, c4, tag}` keeps its order and spelling, and every other pill is untouched). Move the cursor onto a pill and its text comes back with a small tag button, so editing the text works as before; "Edit as text" in the editor does the same. The "+ Pill" button on the slide bar inserts a new pill and opens its editor. A pill stays as text, with the tag button, on a slide edited in Markdown, and nothing is drawn in a deck set to `inline-code: literal`.
- `editPill` in `lib/core/inline-pills.js` is the matching writer: it changes one word of a pill using Segno's own item offsets, keeps the author's casing and order for every word it does not touch, and returns null (writes nothing) unless the pill reads back as the old fields plus the requested change. A property test runs it over every readable pill in the shipped decks and galleries.
