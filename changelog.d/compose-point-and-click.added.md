- **Compose edits avatars and icons by pointing.** A tap on an avatar opens a panel for its name, tile color, size, shape, frame and every trait of the face, with "From name" on each trait saying what the name picked. A tap on an icon opens a panel for the icon (the same searchable grid the pill uses), color, size, frame, look, corners and the name a screen reader says. Each pick rewrites only the word that changed.
- **Compose draws images and lets you choose one from the Library.** A Library photo shows as the picture, not a broken image, and a background says which side it takes. An Image door opens a photo picker with thumbnails and search, and a tap on an image opens a panel for the photo, its description and a background's placement. Compose fetches nothing for a web image; the slide preview draws it.
- **One Insert menu replaces the four insert buttons** (table, code, pill, spark) in the slide bar, so it fits a phone. It holds Table, Code, Diagram, Equation, Plot, Image, Pill, Spark, Avatar and Icon, and says why an item is unavailable (a locked slide, a layout a table does not suit, the cursor in a code block) instead of hiding it. Diagram, Equation and Plot write a fence with a body that works at once.
- **A schema-driven record writer** (`lib/core/segno-edit.js`) changes one word of any inline record from its slot spec and refuses a write that does not read back as asked. Avatars and icons use it; a plugin that declares a slot spec can reuse it.
