- **`npm run conformance -- <kind> [<name>]` shows what a kind or one instance owes.** Run it with `--before` to save a baseline and `--after` to see what got fixed, what still fails and what newly fails; a name that does not exist yet needs `--new` and prints the checklist it will owe, and a typo exits 3 with a suggestion. `--tier=render` runs the rendered checks for that instance.
