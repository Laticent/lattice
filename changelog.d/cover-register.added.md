- **`cover:` front-matter register.** `cover: light` paints the title and closing slides on the deck's own light canvas, with the heading, subtitle, eyebrow, chrome and logo inks a content slide uses, in both color modes. `cover: inverse` (the default) keeps the dark panel and stamps nothing, so existing decks render as before. A slide opts out with `_class: … cover-inverse`. Dividers and `topic` keep their own surfaces, and `title light` keeps its meaning (a scheme, not a surface). The HTML player export learns the new `cover-light` class, so a light cover stays light when the viewer toggles dark; the player's dark-mode CSS text changes for every export, while what renders changes only on a `cover-light` slide. See `lib/base/base.registers.docs.md` § cover and `examples/cover-light.md`.
