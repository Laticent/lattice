- **Dark mode no longer repaints a frame that paints its own canvas.** `section.dark` set the deck-wide canvas at the same `(0,1,1)` specificity as a frame's own rule, and component stylesheets are bundled before `base.modifiers.css` — so at equal specificity source order decided it and the deck ground won. Nine frames are now exempt: the four anchors (`title`, `divider`, `closing`, `topic`) and the five accent covers the splitter emits (`decision-cover`, `compare-code-cover`, `compare-split-cover`, `list-tabular-cover`, `split-panel-cover`). A tenth painter, `lat-split-cover`, needs no entry — it is declared after the rule and already wins.
- **The accent covers were an accessibility defect, not only a cosmetic one.** A cover keeps `color: var(--on-accent)` — the theme's inverse surface under dark — while losing its accent ground, so it rendered dark ink on a dark ground. Measured in Chromium on indaco: `decision-cover` and `split-panel-cover` both went from **1.52:1 to 6.10:1**.
- **`divider` gets its spectrum rail back** — `background-size` was collapsing from `6px 100%` at the default 16:9 export to the deck-wide `100% 1px` hairline, and it had been shipping that way in `divider.gallery.dark.pdf`.
- **A dark split cover now draws the spectrum bar above it.** The old rule carried `border-top: none` deck-wide; the four anchors set their own, the five covers did not. The same covers already draw that bar in light mode, so this brings dark into line rather than adding a treatment.
- A new gate, `test/unit/palette/dark-canvas-ownership.test.js`, parses the built bundle with css-tree — source order is a property of `dist/lattice.css`, so no source-tree walk can ask the question — and fails on a painter declared ahead of the rule without an exemption, on an entry that no longer paints, and on `lat-split-cover` moving ahead of the rule.
- **Not fixed: the `spectrum:` register repaints the same frames** through `section.dark.spectrum-off` and `section.dark:is(.spectrum-edge-*)`, which out-specify a frame's own canvas rather than merely outranking it on order. Pre-existing, unchanged here, tracked as #2291.
