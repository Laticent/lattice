- **Desk completion meter.** A desk now sends its ledger (each item it owns, with a PR number or a stage) as a `meter:` block with every report, and `npm run card` turns it into a 10-cell bar and a percent. Stages weigh 0 (not started), 0.25 (working), 0.5 (PR open), 0.75 (green with a 🚦 card), 0.9 (queued) and 1 (merged); a PR closed without merging counts 1 only when it is marked dropped with a reason. Nobody types the percent, so the same item states always give the same number. The meter also shows `+N new` items since the last report, says why when it drops, estimates a finish date from merges per day over the last two days, and lists what is blocking. The fleet board shows it in the desk's card and in `--table`; a desk can post it alone as `card: meter`. Contract: `engineering/workflow.md` §Desks, "Completion meter".
