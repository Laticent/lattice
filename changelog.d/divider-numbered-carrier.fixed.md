- **Fixed: the `numbered` bookend stamp renders again — on every render path, alongside `silent`, and legibly.** `divider numbered` / `closing numbered` wrote the numeral onto `section::after`, the pseudo the engine reserves for the page number. Two owners took it back: the pagination mask (ours, and Marpit's own on the marp-vscode / marp-kit / export-to-Marp path) comments out any non-pagination `content` on that pseudo, so the counter was stripped from every browser surface while the emulator PDF kept it; and `silent` / `no-paginate` null the same pseudo at an equal specificity from a later file, so `divider silent numbered` — the sample shipped in the docs, the manifest and the gallery deck — rendered nothing anywhere. The numeral now rides the slide heading's `::after`, which neither can reach; it keeps the same slide corner and no longer suppresses the page number.
- **Changed: the `numbered` stamp is inked to be read.** It was bound to `--on-dark-watermark`, the 12% decoration rung, at `opacity: 0.85` — 1.4:1, present but not readable. A section marker exists so a reader and a room know which section they are in, which is content, so it now takes `--on-dark-secondary` on the dark bookends and `--text-secondary` on `divider light`, with no CSS opacity — the same rungs the eyebrow beside it uses. Measured 5.05:1 to 11.79:1 across the shipped palettes. It also moves from `--z-atmosphere` to `--z-content`, which is cosmetically a no-op and makes the plane say what the element is.
