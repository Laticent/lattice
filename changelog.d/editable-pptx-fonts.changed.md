- **The CLI guide now says what an editable `.pptx` needs from the reader's fonts.** An app that ignores embedded fonts (LibreOffice, Keynote, Google Slides) substitutes the deck's fonts, so lines run wider or narrower and a small picture inside a sentence (an icon, spark or avatar) can sit off its words. With the fonts installed the file matches the slide. Install the fonts, or use the picture `.pptx` or the PDF when the layout must hold exactly.
