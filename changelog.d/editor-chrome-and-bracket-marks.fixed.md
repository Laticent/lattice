- The Playground editor's matching-bracket highlight now tracks the palette. It painted CodeMirror's fixed teal (`#328c8252`) on all 36 palette-modes because the theme rule read `--cm-match` through a bare `.cm-matchingBracket` key, which compiles to two classes and loses to `@codemirror/language`'s three-class base rule — so the token resolved and nothing read it.
- A bracket with no partner is themed for the first time. It fell through to the base theme's fixed red, including on the four a11y palettes that exist to avoid that hue; it now seeds from each palette's own `--fail`, and is **dashed** where a matched pair is solid. The line style is load-bearing rather than decorative: the a11y palettes tune `--accent` and `--fail` for their own CVD, which leaves the two rings 1.40-1.52:1 apart there — the same color, to a reader.
- Both bracket marks now ring the cell instead of washing it. The bracket at the caret is always on the active line, so a fill stacks on the active-line band: swept over 18 palettes x 2 modes against the six inks these editors paint, that stack drops below AA from 10% alpha upward (4.42 for `--text-body` on cuoio/light), and 8% is too faint to be worth a token. A ring sits at the cell's edge rather than under the ink, so the ink keeps the active line's own 5.03.
- **The Playground's editor no longer draws its own text selection.** It installed CodeMirror's `drawSelection()`, which replaces the browser's native highlight with DOM it paints itself — so the Playground ringed a selection with a 1px accent hairline that the Studio's editor never drew, and needed a duplicate `--cm-selection` token because the drawn band cannot read `::selection`. Nothing on either editor used what that extension is for (no multiple selections, no rectangular selection, no search multi-cursor). Selection is now the native highlight everywhere, owned by one rule — `::selection` in `styles/native-widgets.css`.
- The editor caret now tracks `--text-body` on every code surface, not `--accent`. It marks the insertion point among the text you are typing, so it has to stay as legible as that text, and `--accent` carries no AA guarantee against the canvas.
- The two deck editors share one chrome definition (`docs/src/lib/editor-chrome.js`) instead of each declaring the canvas, ink, gutter, caret, focus reset and iOS zoom guard for itself. Genuine per-surface differences — type size, padding, line-height, the gutter divider — are now passed in rather than forked. Four dead rule groups were deleted from the Studio's theme, including a third, unreachable copy of the selection wash.
