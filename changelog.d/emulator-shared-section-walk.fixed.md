- A deck whose body quotes a section tag now renders every slide. A `<section` inside an HTML comment or inside `<style>` text used to derail the export, which shipped a multi-slide deck as a one-page PDF with exit code 0. It also derailed the per-slide passes, so every slide after the quoting one lost its masthead band and stage cell. Every section walker now uses the shared one, which reads comments and style text as text.
- An empty comment written `<!-->` or `<!--->` no longer hides the slides after it. The section walker read it as a comment running to the next `-->` in the deck, so every slide in between lost its masthead band and stage cell.
