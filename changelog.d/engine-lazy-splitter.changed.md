- The browser engine loads its slide splitter on demand. A docs page that never renders a square, portrait or story deck no longer downloads it: the engine's startup JavaScript is about 22 KB gzipped smaller on every page that loads it.
- **Breaking:** for a host that drives the engine bundle (`LatticePlayground`) directly: await `splitReady(width, height)` before `splitForPreview` at a size that splits. Called before the splitter has loaded (or after a load failed), `splitForPreview` returns the slides stamped but unsplit, with `pending: true`. The Studio's webpage export refuses in that case rather than ship an unsplit file. At 16:9 nothing changes.
