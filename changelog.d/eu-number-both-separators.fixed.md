- A chart value written as a whole European number, dot-grouped thousands then one decimal comma (`1.234,5`, `€1.234.567,89M`), now plots at its own value: 1234.5, not 1.2345. `1,234.5` reads as before, and so does anything looser, so a list comma after a decimal in prose never moves a number. A lone `12.000` is still read US-first, as 12.
- The narration says a value the way the chart reads it: `1,5` is "one point five", not "fifteen", and `1.234,5` is "one thousand two hundred thirty-four point five". The change it reports between two points is the change the chart draws.
