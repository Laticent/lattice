- Noto Color Emoji is now self-hosted like every other font, as 11 `unicode-range` woff2 slices (about 2 MB together) in `dist/fonts/`, and it leads every emoji fallback. A deck draws the same emoji on every machine. An export embeds the font only when the deck has emoji, and the HTML player and the plain `.html` cut it to those emoji (about 2 KB each; see `fonts:`). PDF, PowerPoint and image sets draw emoji into the slide picture and carry no emoji font.
- `dist/lattice-emoji.css` and `npm run fonts:emoji` are retired. The file stays, empty, so existing imports resolve.
