- Studio exports now carry the deck's name on the download link itself, not only in the `download` hint. A save made from a bare `blob:` link could land as `76f752a8-….html` — the link's UUID for a name — whenever the browser dropped the `download` hint, and the Print panel's 2-up / 4-up / Notes PDF tab showed the same UUID in its title and offered `document.pdf` from its Save button. Every Studio download now builds its link from a file named like the export, so the name travels with the link: PDF, PowerPoint, Webpage, Markdown, Marp bundle, image sets, captions, Library and workspace backups.
