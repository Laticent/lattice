- Studio exports keep the deck's name on iPhone and iPad in Firefox, Chrome and other non-Safari browsers. Those browsers saved every export as `76f752a8-….pdf` — an internal ID — because Firefox for iOS names a page's download after its link and ignores the name the page asks for. There, an export now finishes with a **Save** button that opens the share sheet with the named file; **Save to Files** keeps the name. Safari on iOS keeps its one-tap download, which already kept the name.
- Every Studio download now carries the deck's name on the download link itself, not only in the `download` hint, so desktop Firefox keeps it too when the hint is dropped, and the Print panel's 2-up / 4-up / Notes PDF tab shows and saves the deck's name instead of an ID and `document.pdf`.
