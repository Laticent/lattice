- **Editable PowerPoint and LibreOffice exports now say which fonts they could not embed.** A font used in a deck was left out of the file silently when no font file was available (a system font such as Arial) or its license forbids embedding, and the reader's office suite then substituted its own font. The command line now prints one warning per font on stderr (`font "Arial" is not embedded (…)`), and the Studio adds it to the "ready" message. None of the fonts Lattice ships (Playfair Display, Outfit, JetBrains Mono, Caveat, Shantell Sans, KaTeX) forbids embedding.
