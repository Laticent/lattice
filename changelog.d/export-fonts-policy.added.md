- A `fonts:` front-matter line and `--fonts` flag choose how much of each typeface an export carries: `exact` (only the characters shown), `used` (the whole face for the scripts the deck uses, so edited text keeps every glyph; the default for text), `full`, or `system` (embed nothing). A word ending in `-emoji` sets the Noto Color Emoji font (default `exact`): `fonts: used exact-emoji`. The player, PDF and editable PowerPoint and LibreOffice files read it from one shared kernel (`lib/core/font-policy.js`). `unknown-fonts` warns on a word it does not know.
- The exported player now keeps the text faces whole by default (`used`) instead of cutting them to the shown characters, about 130 KB more on a small deck; `fonts: exact` restores the old size.
