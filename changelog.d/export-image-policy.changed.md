- **PDF and the offline player now shrink big pictures by default.** A photo or screenshot over 150 KB is capped to 2560 px on its long edge and re-encoded as JPEG (quality 88), but only when that saves at least 30% (a format change) or 10% (a resize). A file that does not win, a transparent PNG, a GIF and an SVG are embedded exactly as before. On a 52-slide deck of 21 PNG screenshots (23.9 MB), the PDF went from 33.5 MB to 6.0 MB and the player from 66.6 MB to 12.6 MB. A deck of photos that were already tight JPEGs came out byte-for-byte the same size.
- **You decide.** `images: original` in the front matter (or `--images original` on the command line) embeds every picture as added; `images-quality: N` (or `--images-quality N`) sets the JPEG quality, 1 to 100. The Studio and the command line read the same keys and run the same plan (`lib/core/image-policy.js`) with the same Chromium JPEG encoder.
