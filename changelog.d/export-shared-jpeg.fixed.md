- **Exports write their JPEGs with one encoder of our own, so a picture's size no longer depends on the browser.** The PDF photo layer, picture PowerPoint and LibreOffice files, image sets, cropped pictures in editable Office files and recompressed author photos all used the browser's own JPEG encoder, which differs by engine: Firefox keeps full-resolution color and writes about twice Chromium's bytes, and a 52-slide picture PowerPoint came out 43.3 MB from an iPhone where Chromium wrote 12.5 MB. `lib/core/jpeg-encode.mjs` writes the same bytes from the same pixels in Chromium, Firefox, WebKit and the command line, within 0.1% of libjpeg's size, in the Studio's worker pool.
