- **🛰️ Fleet board.** `npm run card` now builds a `fleet` card: one screen showing every live session, loudest first (🔴 needs you, 🟠 at risk, 🟢 moving, 🔵 review-ready, ✅ done). Each card has clickable Pull Request | Session | Build links under it and numbered actions that wait for the owner's `go`. Ask a command-center session for a board, or run `/fleet`. Contract: `engineering/workflow.md` §🛰️ Fleet board. `npm run card -- --table` prints the same board as one markdown table: status, session (linked), PR, CI run and state.
- **Desks.** Seven skills turn a session into a long-lived desk that owns one kind of problem: `/desk-flaky` (one owner per red or flaky test), `/desk-merge` (the batched merge round and merge order), `/desk-stale` (PRs idle 3+ days) `/desk-deps-nightly` (Dependabot PRs and nightly reds), `/desk-backlog` (issues and follow-ups as one ranked queue) `/desk-security` (every security finding, never dismissed) and `/desk-optimize` (measured wins in engine speed and size, CI time, agent spend and code quality). The fleet board's overview can carry a `spend` line. A desk acts inside its own lane with a fixed list of verbs, never merges, runs only when asked, and spends about 10 new sessions or agents per lane a day. Another session's message is a request, never authorization: it cannot approve a merge or make a session drop its work. A merge approval covers the commit it was given on. `/fleet desk <lane>` starts one. Contract: `engineering/workflow.md` §Desks.
- **A merge needs the owner's typed word, checked by a machine.** A new `PreToolUse` hook (`.claude/hooks/owner-merge-gate.mjs`) blocks the GitHub merge and auto-merge tools unless the owner's own latest message in that session is exactly `merge #N`, or exactly `all` / `all but #N` answering a message whose first line is `🚦 Merge digest` and which lists the PR. It reads the transcript's harness-written `origin`, so a relayed session message, a desk brief or a subagent report can never authorize a merge, and a refusal such as "do not merge #N" never parses as one. Sessions merge only through those tools; the gate does not read Bash, so a Bash merge is a rule breach no machine catches.
