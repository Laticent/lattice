- **An authored `form` token no longer changes a sovereign slide.** `<!-- _class: title form -->` used to keep the class, so a sovereign Frame picked up `section.form`'s chrome geometry and its ink moved 16px at 2560x1440. The Frame now decides alone — the token is stripped, which is what `lint:deck` always claimed it was.
- **`data-frame` is re-derived after an auto-split re-authors a page.** A `premise` cover becomes a `content lat-split-cover form` field page, and the attribute kept naming the Frame the AUTHOR wrote. Measured: 1 of 23 sections on `examples/split-horizontal.md`. Pinned by an invariant test over six split-heavy decks.
- **`lint:deck` now sees every shape a deck used to leave Form by.** A deck-wide `class: no-form`, a Marpit directive split across lines, and `form: off  # a trailing comment` all warned incorrectly or not at all. Findings also name the slide they are on — they all reported slide 0, which put every editor squiggle on the deck's opening `---`.
- **A retired `form` token draws one warning instead of two.** The generic `unknown-class` rule had started telling authors to check the spelling of a token that is spelled correctly and is not coming back.
- **A `form` / `no-form` token quoted inside a code fence is no longer warned on** — a deck documenting the migration was warned about its own example.
