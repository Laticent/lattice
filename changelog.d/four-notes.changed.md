- **Breaking:** a slide's notes are now four named comments, each named for where it shows up: `<!-- @note{…} -->` (speaker notes), `<!-- @say{…} -->` (the voice and the captions), `<!-- @alt{…} -->` (alt text) and `<!-- @handout{…} -->` (the handout and the player's Read view). A plain `<!-- comment -->` is no longer the speaker note: it reaches no rendered, spoken or annotated surface, and `--strip-notes` removes it from every export that carries the source. Run `lattice migrate notes deck.md` to rewrite a deck.
- **Breaking:** removed with no alias, each reported by `lint:deck` with its replacement: `<!-- say: … -->`, `<!-- describe: … -->` (now `@alt`), `<!-- reader: … -->` (now `@handout`), the Studio's `<!-- note: … -->`, the front-matter `say:` map (put each line on its slide as `@say`), and a record's `note=`, `say=`, `describe=` and `reader=` fields. The lint rules `caption-key-retired` and `say-key-case` are replaced by `note-key-retired` and `note-malformed`.
- PPTX and PDF label the handout `Handout:` after the speaker note (it was `Reader:`), and the HTML player's Read view now prints each slide's handout under the slide.
- The export to Marp writes `@note` as a Marp speaker note and `@handout` as a `Handout:` note, and drops `@say`, `@alt` and plain comments, which Marp would otherwise show as speaker notes.
- `list-steps-inline-body` also flags a step written as one whole sentence on its `1.` line with no nested body, which renders as a single bold block; `examples/meta.md` had three such slides.
- A deck written the old way (no named note, two or more plain comments) gets an info finding, `plain-comment-notes`, whose fix migrates the whole deck, so the Studio's quick fix converts it in one step; every CLI export with a notes channel says so once. `lattice migrate notes` lists converted comments that read like a TODO or a draft, for review.
- `lattice migrate notes --back` writes the four notes back in the LFM 1.x forms (a plain comment, `say:`, `describe:`, `reader:`), so a deck can go back to 1.x with one command, and lists what 1.x reads differently.
