- **A Frame now declares which stage kinds it can host.** `admits` (`flow` · `canvas` · `sovereign`) is the frame side of the `accepts`/`fits` containment contract in `design/forms.md` §7. The component side has shipped since 2026-07-14 as each manifest's `stage` field; the frame side did not exist, so a Frame could not state what it accepts and admissibility lived only in the render. A sovereign Frame admits exactly `["sovereign"]` — it hosts the one component carrying its name, which is what `exemptFromChrome` has always meant.
- Two checks tie the field to the generated stage catalog: a Frame that claims a kind no component declares fails validation, and a stage kind left with no Frame to compose in fails the catalog load. **Both are declared with their limits, in the schema and in `design/forms.md`:** the catalog's `sovereign` values are themselves derived from `exemptFromChrome`, so that arm is self-referential, and a root Frame that *under*-claims — omitting `canvas` it really hosts — passes every gate today. It is a declaration with a consistency check, not a verified contract.
