- **`logo` and `watermark` now name the Cell they actually render into.** Both Tile manifests claimed a band Cell that nothing ever docked them in — `logo` said `masthead-bay`, `watermark` said `stage` — while `base.modifiers.css` and `watermark.css` position both against the section box. The manifests said one thing and the render did another, a divergence invisible for as long as a single Frame existed.
- **They get a Cell each, not a shared one.** The two have exactly one property in common — neither docks in a band — and it is a negative one; every other Cell in the catalog names a position. A shared Cell forced a single `z`, `accepts` and `capacity` onto two Tiles that agree on none of them. `logo` is content-plane and accepts `chrome`; `watermark` is atmosphere-plane and accepts `surface`; both are `capacity: "one"`, `fill: "anchor"`.
- It also makes per-Tile suppression **expressible**, which one shared Cell made impossible: a Frame suppresses by Cell id, so no Frame could name the watermark without also naming the logo. **This is a model capability, not a behavior change** — both Cells are non-materializing and no Frame declares either, so suppressing one is inert at render today. Nothing can hide either Tile that could not hide it before.
- The Cell `region` vocabulary was defined in **three** places — the enum in `schema/cell.schema.json`, `CELL_REGIONS` in `lib/forms/index.js`, and the slicing-relocation enum in `schema/frame.schema.json` — with nothing keeping them in step; adding a region passed one and threw in another. All three now carry the same list (`coda` was already missing from the third), and a test compares them.
- `region` is now pinned **1:1 with Cell `id`**. It held by convention across all 12 Cells and nothing enforced it, while `checkSlicingIntegrity` resolves a relocation target through a region → Cell map where the first entry wins — so a second Cell claiming an existing region would have bound relocations to whichever loaded first.
- No rendered output changes: `examples/frame-chrome-and-notes.md` (logo) and `examples/form.md` (watermark) export byte-identical HTML and PDF across the change.
