- Charts now read money the way global clients write it. A currency code (`EUR 4.2M`, `CHF 4.2M`), a country dollar (`US$4.2M`, `R$4,2M`), a currency after the number (`4.2M €`, `4200€`, `4.2M EUR`) and the magnitude words `Mio`/`Mrd` (and, beside a currency, `mn`, `Md` and `Cr`) used to make the value unreadable, so the chart drew nothing. They now plot, `lint:deck` flags a typo inside one (`EUR --4M`), and narration says them in the currency's name ("four point two million euros"; `¥` and `₹` too).
- Chart axes and value labels keep the currency where the author put it (`4.5M €`, `EUR 4.5M`) and print a decimal comma when every value with a decimal uses one (`4,2` gives `4,5`, not `4.5`). This reaches every chart that prints computed numbers: `bar`, `bullet`, `heatmap`, `line`, `scatter`, `slope`, `stacked-bar` and `waterfall`.
- `line`, `stacked-bar` and `waterfall` size the value-axis label column to the widest label, so `$12.5M` and `EUR 5.5M` no longer print cut short as `$12.…` and `EUR…`.
