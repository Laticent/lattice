- Pull requests no longer commit PDFs. The `lint` job fails a PR that adds or changes one; the nightly bless bot renders and commits every golden PDF, including the first PDF of a deck or gallery merged without one. A PR's golden-diff comment links the rendered PDF of any new deck. The pre-commit hook that rendered and staged PDFs is gone; `node tools/build-staged-pdfs.js <deck.md>` renders one locally without staging it.
