- **`heatmap`** — a new chart-family member: a numeric matrix read as intensity, for when the finding is where a value concentrates across two dimensions rather than how individual values compare. Authored in the family's existing nested list (top-level item = row, nested items = columns with a value pill), up to 12 columns by 10 rows. It closes the gap the Cartesian expansion named and deferred: the family covered the qualitative grid (`matrix-grid`) and the geographic one (`map`), but nothing put a number at every row-by-column crossing.
- A crossing with no authored value paints as unmeasured — a bare neutral with a dotted edge — rather than as zero at the bottom of the ramp, so a ragged cohort table reads as incomplete instead of as a collapse.
- Intensity rides `map`'s choropleth ramp (one hue mixed into a neutral anchor) rather than a second sequential mechanism, so low values stay above the empty cell on both canvases.
