- **Breaking:** `heatmap` is authored as a **markdown table**, not a nested list. The header row names the columns, each body row leads with its label, and a **blank cell is a crossing nobody measured**. Heatmap data starts in a spreadsheet, and a table is paste-compatible where the list had to be transcribed by hand — the 10×12 stress matrix is 94 authored lines as a list against 12 as a table. Every deck in this repo is migrated; a heatmap deck kept elsewhere must be converted, and until it is, the slide renders as the plain table it contains rather than erroring.
- A heatmap cell can carry its own description with a `` `note=prose` `` annotation — `` | 62 `note=dipped after onboarding` | ``. The `note=` name keeps it apart from a hex color or an issue ref in a cell.
