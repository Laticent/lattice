- Icons draw as glyphs of **Lattice Icons**, our own font of the curated icons, by default. They look the same on the slide (within a third of a pixel), and the exports carry the font: in an editable PowerPoint or ODP an icon is a character the recipient can recolor and resize like a letter, and in a PDF it copies as its label. A file carries each icon once (about 0.3 KB) in every theme and color mode, sized by the Emoji font setting; under `system` icons draw as SVG. `icon: svg` keeps the drawing for a deck or a slide (`engineering/decisions/2026-11-01-icon-font.md`).
- `npm run icons:font` rebuilds the font from the curated drawings when the icon list changes; `fonts:check` fails while it is stale.
