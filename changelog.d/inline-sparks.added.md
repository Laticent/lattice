- **Inline sparks.** A `~{…}` in inline code now renders as a word-sized chart that sits wherever inline code can go: a `kpi` line, a table cell, a `big-number` caption, a sentence. `` `~{12 14 13 17 21}` `` draws a line; `:area`, `:bar`, `:step` and `:winloss` draw the same series other ways; `` `~{72%}` `` draws a ring and `` `~{72/80}:bullet` `` a bar against a target. `:sm` / `:lg` / `:fill` size it, `:c1`–`:c12` color it, `:end` / `:minmax` mark values, `:zero` starts a line at zero, and `:framed` puts a pill's capsule behind it. A span that doesn't parse stays code, and `lint:deck` warns with the reason (`spark-literal`). See `lib/base/base.docs.md` § Inline sparks and `examples/inline-sparks.md`.
