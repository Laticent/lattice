- A brand mark for the **Laticent** org, in `design/logo/laticent/` — an incised `L`, the letter with its load path cut into it as a groove. It ships in two forms with different jobs: a **bare letter** (light/dark adaptive) that sits beside the five product marks, and a **bluestone tile** for app icons, favicons and avatars, where the same groove is brass. Both have `-min` variants that drop the groove below ~46px, plus light and dark lockups in each form. `generate.py` rebuilds all eight and asserts four invariants from the geometry — every one mutation-tested until it fired; `audit.py` checks every asset against a round-avatar crop and is transform-aware.
- The lockup's wordmark is an **outlined path**, not live `<text>`. Measured in real Chromium, "Laticent" spans 219.6 to 315.9 units across the family's own fallback chain, so no fixed viewBox allotment is both tight and safe — the five sibling lockups still set live text and still carry that defect. `outline-wordmark.py` re-derives the path from Fraunces on demand and pins the exact face by sha256.
- Only the two adaptive assets carry an inline `<style>`, and their class names are prefixed. An inline `<svg><style>` is document-scoped, so inlining two of these on one page let a single-scheme lockup's bare `.sf` win on source order and paint the adaptive mark at 1.99:1.
