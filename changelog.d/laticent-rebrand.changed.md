- **Breaking for anyone importing by package name:** the npm scope is now `@laticent`. `@workwel/lattice`, `cadenza`, `lente`, `suono` and `vetrina` become `@laticent/*`. Nothing was ever published under the old scope — all five 404 on the registry — so no consumer is pinned and there is no deprecation path to run; the rename is breaking only for anyone building against this tree directly.
- **The org, product and dba are renamed from SlideWright to Laticent**, and the retired `@workwel` scope goes with them. `TRADEMARKS.md` and `LICENSE-EXCEPTIONS` now assert the Laticent name; the AGPL grant and the copyright holder are unchanged.
- **"Lattice Style" is retired as the umbrella project name** — the project is Laticent. The docs stay at `lattice.style`, so the brand and the domain now differ.
- Repository, Pages and schema URLs move with it: `github.com/Laticent/lattice`, `laticent.github.io`, `laticent.dev`, and the five JSON Schema `$id`s. The 31 committed demo PDFs were re-rendered, so their footers and QR payloads carry the new domain.
- Two dated records deliberately keep the old names, because the rename is their subject: `engineering/decisions/2026-08-09-org-rehost-playbook.md` is a run sheet written from inside the source org, and `CHANGELOG.md`'s frozen `## 1.0.0` section notes that 1.0.0 shipped under the former name.
