- **Breaking for anyone importing by package name:** the npm scope is now `@laticent`. `@workwel/lattice`, `cadenza`, `lente`, `suono` and `vetrina` become `@laticent/*`. Nothing was ever published under the old scope — all five 404 on the registry — so no consumer is pinned and there is no deprecation path to run; the rename is breaking only for anyone building against this tree directly.
- **The org, product and dba are renamed from SlideWright to Laticent**, and the retired `@workwel` scope goes with them. `TRADEMARKS.md` and `LICENSE-EXCEPTIONS` now assert the Laticent name, and the exception document goes to **version 1.1** so two different texts never both claim v1.0; the AGPL grant and the copyright holder are unchanged.
- **"Lattice Style" is retired as the umbrella project name** — the project is Laticent. The docs stay at `lattice.style`, so the brand and the domain now differ.
- Repository, Pages and schema URLs move with it: `github.com/Laticent/lattice`, `laticent.github.io`, `laticent.io`, and the five JSON Schema `$id`s. Demo payloads and schema `$id`s point at `laticent.io`, a domain the project owns, rather than the retired `slidewright.dev`. The 31 committed demo PDFs that carried the old brand were re-rendered, so their footers and QR payloads carry the new domain.
- The old name survives in six files, for three reasons. **The rename is their subject:** `engineering/decisions/2026-08-09-org-rehost-playbook.md` (a run sheet written from inside the source org), `engineering/decisions/2026-08-09-changesets-multi-package-release.md` (keeps the scope names its dated registry check actually covered), and `engineering/decisions/2026-07-02-website-copy-positioning.md` (a dated record of the three-brand debate). **They record a shipped fact:** `CHANGELOG.md`'s frozen `## 1.0.0` section notes that 1.0.0 shipped under the former name, and [`changelog/pre-release-archive.md`](https://github.com/Laticent/lattice/blob/main/changelog/pre-release-archive.md) is untouched — it declares itself frozen, and a decision record pins it byte-for-byte. **It is generated:** `BACKLOG.md` mirrors live issue titles verbatim.
