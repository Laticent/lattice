- Every `@laticent/*` library ships ES modules only. The CommonJS copy (`dist/*.cjs`) and the `require` branch of each package's `exports` are gone, and `main` points at the ES build. `require('@laticent/<name>')` still works on the supported Node versions (22.13 and later) through Node's built-in `require(esm)`, and TypeScript projects on `module: nodenext` or `node20` typecheck either way. The libraries are 0.x and have never been published, so no installed user is affected; for anyone tracking the workspace packages directly, this is the breaking part: a tool that read a library's `.cjs` file by path must read the `.mjs`.
