- A workspace backup now carries the one-line caption the chat writes for each Library photo, and a restore brings it back, so a restore no longer makes the chat look at every photo (and pay for it) a second time. Captions in a backup file are cleaned on the way in: invisible and blank-looking characters, look-alike separators and curly quotes are removed, and a long caption is cut on a whole character instead of through the middle of an emoji.
- The chat no longer stores the text "[object Object]" as a photo's caption, and a caption that is empty once cleaned (only zero-width or blank-looking characters, for example) is refused instead of silently clearing the caption the photo already has.
