- A deck can show a Library photo by name: `![](asset:team-photo)`, `![bg](asset:hero)`, or in a `collage` photo list. The name is the one the Images tab shows on the card. The reference works in the live preview and the Present overlay; the Library card counts the decks that use it. A photo that was deleted, or that belongs to another deck, shows the drawn missing-image stand-in instead of a broken picture. The CLI keeps the reference as written, because a Library lives in the browser.
