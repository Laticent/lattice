- **Libraries and Plugins hubs on the website.** `/libraries/` introduces all eight libraries, grouped by the job each one does, and `/plugins/` introduces the five plugins an author writes: Math, Mermaid, Icons, Avatars and Function plots. It also explains how plugins load, how a plugin differs from a component or a library, and how to write your own. Each library and plugin has a live demo and a Learn page beside it. The Learn page covers the problem it solves, the idea, how to use it, where else it fits, how Lattice uses it and what it doesn't do, and ends with links to the repository docs.
- **Plugin demos.** Each plugin has a live, editable slide at `/plugins/<name>/`, with captioned examples that open in the Playground.
- **A plugin manifest can carry its icon.** The new optional `icon` field holds path data tagged `line`, `accent` or `fill`, and the website's Plugins hub draws it in the active theme's colors, so a plugin's mark keeps its contrast on every palette and can't carry a color or markup of its own (spec/LPM.md §3.1, `lib/plugins/plugin-icon.mjs`). Math, Mermaid, Icons, Avatars and Function plots ship one.
