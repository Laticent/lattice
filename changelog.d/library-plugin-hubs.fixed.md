- **Code blocks in the Studio's and the Playground's live preview get their line numbers, copy buttons, diff bands and panel.** The code plugin's stylesheet wrote its rules as `:where(section) pre…`, which the live preview's slide scoping (and Marp's) turned into a selector that matched nothing, so `@code{numbers}`, `copy`, `diff`, `mark`, `wrap` and the panel on a plain slide drew only in the PDF and the exported players. They are now written `section :where(pre)…`, which weighs the same and scopes correctly; the PDF is unchanged.
- **Lines a `_focus: line` slide recedes stay readable in the live preview.** The code plugin's quieter color for them missed the same way and fell back to 24% opacity, which left receded code and its line numbers near blank.
