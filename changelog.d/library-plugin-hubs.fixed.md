- **Code blocks in the Studio and the Playground get their line numbers, copy buttons, diff bands and panel.** The code plugin's stylesheet wrote its rules as `:where(section) pre…`, which the browser's slide scoping (and Marp's) turned into a selector that matched nothing, so `@code{numbers}`, `copy`, `diff`, `mark`, `wrap` and the panel on a plain slide drew only in the CLI's PDF. They are now written `section :where(pre)…`, which weighs the same and scopes correctly; the PDF is unchanged.
