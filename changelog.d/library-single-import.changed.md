- **Studio Library: one Import button, the same on every tab.** It takes a package `.zip`, photos, videos and reference files together (and, on a phone, the camera). The Library sorts each file by what it is and opens the matching section: photos open Images, clips open Videos, a package opens Design, reference files open Files, and a mixed batch opens All. The new items sort to the top and wear a ring for a few seconds.
- **Studio Library: four sections instead of eight pills.** All · Design · Media · Files, with a second row of kinds inside Design (Themes, Components, Finishes, Motions) and Media (Images, Videos). Everything is sorted by date added, newest first.
- **Studio Library: packages that came from a `.zip` or `.lattice` file carry an "Imported" tag**, so they read apart from the themes, components and finishes you made in Fabricate. Items saved before this change show no tag.
- **Exported bundle READMEs** now say **Library → Import** instead of **Import .zip**.
