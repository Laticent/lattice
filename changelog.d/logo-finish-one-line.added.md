- `logo-finish:` styles the deck logo on one line, one word per axis, autocompleted in the editor: a placement (`top-left` … `bottom-right`), a color (`auto`, `accent`, `ink`, `muted`, `canvas`, `inverse`, `brand`, or the blends `accent-ink`, `accent-canvas`, `ink-canvas`), a size (`sm`, `md`, `lg`) and a scope (`all`, `title`). Naming a placement hides the header, footer or page number in that band, since the logo wins. Colors follow light and dark mode. `_class: no-logo` hides the logo on one slide.
- Studio → Chrome → Logo has a Position, Color, Size and Show on control, all writing that one line.
