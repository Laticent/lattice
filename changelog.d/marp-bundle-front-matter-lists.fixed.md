- The Marp bundle export no longer breaks a deck's front matter when a list is written at its key's own column (`class:` then `- lead` on the next line, which YAML allows). The exporter's reader left the list items behind when it moved the key into the settings block, Marp then rejected the whole front matter, and the bundle lost its title, footer, page numbers and color mode in VS Code and marp-cli. A quoted value or a flow map that runs past its key's line is now kept with its key as well.
