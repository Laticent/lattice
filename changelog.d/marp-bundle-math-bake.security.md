- **Fixed a script-injection hole in the Export-to-Marp bundle's math.** Marp typesets `$…$` with MathJax, which writes an unescaped `"` into an attribute for `\style`, `\cssId` and similar commands, so a deck could run a handler or load a remote resource in the recipient's `npm run pdf` or VS Code preview, with no click. The export now typesets every equation itself with Lattice's own KaTeX, rebuilds the markup through a strict grammar, escapes every other `$` in the deck (a `header:` or `footer:` directive included), and turns Marp's math off in `marp.config.cjs` and `.vscode/settings.json`.
- Math in an Export-to-Marp bundle now looks like Lattice's own render (KaTeX instead of MathJax) and carries MathML for screen readers. A `math` fence now renders as an equation instead of a code block. The TeX is kept inside each equation's annotation; edit equations in the source deck and re-export.
- In VS Code, open an Export-to-Marp bundle's folder as trusted: in Restricted Mode the extension turns HTML off and the typeset equations lose their layout.
