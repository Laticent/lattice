- **The Export-to-Marp bundle no longer runs a deck's own script on the recipient's machine.** The bundle's `marp.config.cjs` needs `html: true` to load the Lattice runtime, and that same flag let marp-cli run a deck's `<script>`, `on…` handlers and `srcdoc` frames during `npm run pdf`. One of them could reach the network. Both the CLI and the Studio's Share sheet now drop those from the bundled deck, along with `javascript:` URLs, and keep Lattice's own runtime tags. Code samples are untouched, and the CLI says what it removed.
