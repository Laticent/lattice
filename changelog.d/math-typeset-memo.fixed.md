- Typing on a slide that contains math no longer re-typesets equations that did not change. The engine now memoizes KaTeX by expression, so a keystroke costs **0** `renderToString` calls where it used to cost one per expression on the slide — 90 calls per keystroke on the math gallery, now none. A cold render also gets cheaper, because expressions repeat between an equation and its legend: 90 calls down to 58 on the same deck.
- `npm run bench` gains a `math` render row and a new **edit tier** that reports what an author pays per keystroke, for a single character and for a 12-character burst. The burst case was measured nowhere before — every existing typing harness inserts a 700 ms settle between keys, which is precisely the case the frame scheduler already handles. The tier gates on typeset **counts** rather than wall clock, so it is exact on every machine.
