- Mermaid `click` directives now work in the live previews that take a pointer: the Playground, and the VS Code Markdown preview of an Export-to-Marp bundle. A flowchart or class diagram's `click A "url" "tooltip"` keeps its tooltip, and a gantt chart's `click task href "url"` keeps its link, when the preview reuses a diagram it already drew: after a keystroke outside the diagram, and every time VS Code's built-in Mermaid extension removes and the runtime redraws it. VS Code's extension removes the diagrams on every edit, so until now the tooltip and the gantt links stopped working there at the first edit.
- With two gantt charts on slides of the same palette, the first chart's `click` links now work on the first render too. The charts share Mermaid's gantt state, and the second chart's parse erased the first chart's links before the runtime bound them.
