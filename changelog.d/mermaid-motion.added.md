- **Mermaid diagrams now animate under `motion:`, like charts.** A deck with `motion: on` (or a slide with `motion-on`) builds each diagram in: subgraph boxes first, then nodes, then the arrows between them, then the words. `motion-style` and `motion-speed` apply, `motion-off` opts a slide out, and a viewer who asks the OS to reduce motion sees the diagram settled. It runs in the Playground, the Studio, Present and the exported HTML player. Twelve families are mapped (flowchart, state, class, ER, mindmap, sequence, pie, gantt, XY chart, quadrant, git graph, timeline); any other family stays a still picture. The PDF is unchanged.
