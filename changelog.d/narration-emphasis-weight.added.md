- Narration can now spend time on what matters. Cadenza's `buildTrack` takes an optional `emphasis` map — `[{start, end, weight}]` char ranges over the narration text — and a cue where an emphasized passage ENDS holds a beat afterwards, so a deck's key claim no longer gets exactly the same pacing as a footnote. The hold sits in the gap between cues, the one place both playback paths already insert real silence. An unweighted deck is timed byte-for-byte as before.
