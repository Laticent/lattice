- Present with narration no longer builds up decoded audio as the deck plays. The Studio now holds decoded audio for the sentence being read and the next two only, and releases each sentence once it has played. Before, every sentence stayed decoded until the cache filled, which on an iPhone could push Safari past its memory limit and reload the tab.
- A voice that answers raw audio (Google's Gemini voice through OpenRouter, and on-device Kokoro) is now kept on the device as Ogg Opus at the workspace's Audio quality setting rather than as WAV, about a sixth of the size at the default 64 kbps. Workers encode it after the WAV has played and been stored, so nothing waits on the encode and a reload loses no clip. Exported files and Present together still carry MP3: a clip kept as Opus is decoded back to WAV and compressed to MP3 as before, so its MP3 is made from the Opus copy rather than the original WAV. If a kept clip cannot be decoded, the export refuses and names it rather than shipping Ogg.
- In Present, the caption band now keeps its own space while captions are on, so pressing Play or Pause, and every slide's start, no longer shrinks and regrows the slide. Showing and hiding the caption only fades it. Turning captions on or off changes the slide's size once, with no animation.
- Present on a 4K deck uses far less memory on iPhones and iPads. While Present is open the editor's own preview is no longer drawn behind it, and a slide's frame now fades in through a screen-sized box instead of animating the full-size frame. In WebKit at iPhone resolution, opening Present on a 4K deck peaked at 957–1,015 MB instead of 1,445–1,756 MB.
- The Guide's focus fades the rest of a slide exactly as before, but without a CSS opacity transition: it steps the opacity itself, so iPhones and iPads no longer build a full-resolution layer for every receded part of a 4K slide. Exported players carry the same change.
- A 4K deck now lays out on HD wherever the screen shows the slide at 2,560 device pixels or fewer across: a phone, an iPad, the editor's preview, a thumbnail. A 4K display presenting full screen keeps 4K. The Studio and the exported player both follow the screen, and switch when a window is resized across the line. Sharpness does not change, because text and icons are drawn at the screen's density whatever the layout size; memory does, because iPhones and iPads pay for every layer inside a slide at the slide's own layout size. Rules and accents can look slightly heavier on HD than in a 4K export, and a few card texts can wrap differently; making the two identical is a follow-up. Exported PDF, PowerPoint and image files are unchanged.
