- **The door now enforces the owner's admission rules for npm plugins.** A plugin entry marked `source: 'npm'` is admitted as bytes against its pinned SHA-256 and refused if it leaves a dependency external (`import`, `export … from`, `import()`, `import.meta`, any use of `require` or `importScripts`); it does not run where the OS sandbox layer reads OFF or cannot be measured on Linux (code packages keep today's behavior); and nothing in admission or render loads it in Node. No npm door exists yet, so nothing user-facing changes. (`lib/packages/npm-plugin-admission.js`, `lib/core/os-sandbox.js`, `lib/packages/code-door.js`)
