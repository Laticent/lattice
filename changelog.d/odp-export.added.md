- **LibreOffice Impress export.** `lattice deck.md deck.odp` writes an OpenDocument Presentation: one full-bleed image per slide, like the `.pptx`, with speaker notes on each page's notes view and each slide's `describe:` text as the picture's alt text. Lattice builds the file itself, so exporting needs no LibreOffice install. `--strip-notes` removes the notes. The Studio does not offer `.odp` yet.
