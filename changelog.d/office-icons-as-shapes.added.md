- An editable PowerPoint or LibreOffice file draws each icon as a native outline shape by default, so apps that ignore the file's fonts, such as Google Slides and iPhone Preview, draw the icons too, not only desktop PowerPoint. Turning off "Icons for every app" under the Studio's Editable text (or `--no-icon-shapes` on the command line) sends the icons as icon-font characters instead, which flow with the text but draw only in desktop PowerPoint. It is an export choice, so no front-matter line sets it.
