- An editable PowerPoint or LibreOffice file draws each icon as a native outline shape by default, so the icons look right in Google Slides, iPhone Preview and every other app, not only in desktop PowerPoint. `office-icons: font` (or `--office-icons font`, or Icons → Font in the Studio's Editable text) keeps the icon-font characters, which flow with the text in desktop PowerPoint and LibreOffice.
