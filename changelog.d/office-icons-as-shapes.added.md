- An editable PowerPoint or LibreOffice file draws each icon as a native outline shape by default, so the icons look right in Google Slides, iPhone Preview and every other app, not only in desktop PowerPoint. Turning off "Icons for every app" under the Studio's Editable text (or `--no-icon-shapes` on the command line) sends the icons as icon-font characters instead, which flow with the text but draw only in desktop PowerPoint. It is an export choice, so no front-matter line sets it.
