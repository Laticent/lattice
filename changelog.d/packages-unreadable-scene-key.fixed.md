- **Restoring a backup can no longer overwrite a saved theme with a scene.** A scene the Studio could not read rides in a backup with the record id it was stored under, and the restore saved it under that id, so a hand-edited row carrying one of your themes' ids replaced that theme, with no version history to recover it from. The restore now files an unreadable scene by its name, among scenes only: it updates an unreadable scene of that name, and leaves a working scene of that name alone.
