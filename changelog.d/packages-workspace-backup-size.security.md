- **A workspace backup no longer inflates without bound.** Restoring a backup used to inflate `workspace.json`, the side files and the nested `library.zip` in full, so a few-KB file whose `workspace.json` was a deflate bomb could exhaust the Studio tab's memory. Every read now goes through a size budget: the Studio's own text shares the 64 MB package cap, `library.zip` the 25 MB asset-zip cap, and `refdocs.json` its own 256 MB cap, because reference docs are the one legitimately large part of a backup (a 5 MB PDF rides as 6.7 MB). An oversized backup is refused with "That workspace backup is too large to restore." before any deck or setting is imported, and so is a backup whose `refdocs.json` does not parse.
