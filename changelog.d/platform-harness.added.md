- **Warm harness for the macOS and Windows platform suites.** Dispatch `platform-suites.yml` with `harness=<PR number>` and one runner installs and builds once, then runs `/harness` commands posted on that pull request (a suite, a shell block, a re-run), syncing each new push and replying with the result. Only the person who dispatched it can post commands, and an edited comment never runs; with watch on, a push to the branch re-runs the last job. One harness runs per OS, so a macOS and a Windows harness can serve the same PR: every reply names its OS, and `--on=<os>` sends a command to one of them. An iOS round no longer pays about 17 minutes of queue wait and setup each time (`tools/platform-harness.js`, `engineering/development.md` §Platform suites).
