- **Warm harness for the macOS and Windows platform suites.** Dispatch `platform-suites.yml` with `harness=<PR number>` and one runner installs and builds once, then runs `/harness` commands posted on that pull request (a suite, a shell block, a re-run), syncing each new push and replying with the result. Only the person who dispatched it can post commands; with watch on, a push to the branch re-runs the last job. An iOS round no longer pays about 17 minutes of queue wait and setup each time (`tools/platform-harness.js`, `engineering/development.md` §Platform suites).
