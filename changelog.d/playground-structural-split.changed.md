- The Playground preview now splits a portrait, square or strip deck the way the PDF export does. The structural auto-split (a slide with several rows becomes a cover, one page per row, and a closing page) used to run only in the CLI export, so a `size: portrait` deck showed one tall page per slide in the Playground and one page per row in its PDF. Both now run the same preprocessor, `lib/core/structural-split.js`: your gallery deck at portrait renders 43 pages in both. Landscape decks are unchanged, and Studio exports are unchanged. The component tour keeps one step per authored slide when a slide splits.
