- Studio: approving a plugin no longer shows its block unstyled for a moment. A preview that was already drawing when you clicked Approve filled the plugin's block without its stylesheet, so the first frame showed the right words with none of the plugin's colors. Each preview now draws a plugin only once the stylesheet it paints with has it, so the words and the colors arrive together. An approval given in another tab of the same browser now reaches this tab's previews too. Reloading the Studio with a plugin already approved no longer shows its block unstyled for a moment either.
