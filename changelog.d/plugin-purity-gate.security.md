- **`build:check` now fails when plugin or component code uses the network, storage or our key.** `checkPluginPurity` (G1 of the npm-plugin threat model) parses every source file under `lib/plugins`, `lib/components` and `lib/runtime` and fires on `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon`, `localStorage`, `sessionStorage`, `indexedDB`, `importScripts`, `WebTransport`, `RTCPeerConnection` or an OpenRouter key name, including `window['fetch']` and `process.env.OPEN_ROUTER_KEY`. A file named `.min` or `.generated` is scanned like any other. One use is sanctioned, with its justification: the runtime fetching the deck's own markdown. It adds about 0.3 s.
