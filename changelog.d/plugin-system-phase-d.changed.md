- Mermaid is a plugin now (`lib/plugins/mermaid/`): its ` ```mermaid ` fence is declared by the plugin, and the CLI's diagram bake moved out of `lattice-emulator.js` into the plugin's `mermaid.bake.js`, run by the plugin host before the deck renders. Exports are unchanged: the engine's HTML is byte-identical, and the CLI's HTML for every tracked diagram deck matches `main`. A bake that fails now exports its fences as highlighted source with a warning instead of stopping the export.
- The plugin model gains three contribution points (LPM 0.2-draft): `bake` with `render.exec.bake`, a fence rendered `as: "code"`, and `render.exec.hydrate: "runtime"`. `mermaid` is no longer a host-reserved fence name; `lattice packages new plugin mermaid` is refused because the plugin exists.
