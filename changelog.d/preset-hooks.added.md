- **Preset hooks: five tokens for a deck's weight.** `--rule-w`, `--rule-style` and `--rule-mark` set the heading rule's weight, line style and ink (the `form` masthead hairline, `rule: full`, the `rule: short` / `accent` segment, the `split-panel` kicker and the split-page runheads); `--rail-w` sets the `spectrum-card:` rail's thickness; `--radius-card` sets the corner of every card surface (`cards-grid`, `cards-stack`, `stats`, `pricing`, `verdict-grid`, `list-steps`) without touching `corners:` or pills. Unset, each falls back to today's value, so no existing deck changes. Presets will set them; a deck can set them today in a `style:` block. See "Preset hooks" in `lib/base/base.docs.md` and the demo `examples/preset-hooks.md`.
