- **Preset hooks: five tokens for a deck's weight.** `--rule-w`, `--rule-style` and `--rule-mark` set the heading rule's weight, line style and ink (the `form` masthead hairline, `rule: full`, the `rule: short` / `accent` segment, the `split-panel` kicker and the five split-page runheads); `--rail-w` sets the `spectrum-card:` rail's thickness; `--radius-card` sets the corner of every card that can carry a card tag, such as `cards-grid`, `stats`, `decision` or `statute-stack`, and of the tag sitting in its corner, without touching `corners:`, pills, quote panels or diagram tiles. Unset, each falls back to today's value, so no existing deck changes. Presets will set them; a deck can set them today in a `style:` block. See "Preset hooks" in `lib/base/base.docs.md` and the demo `examples/preset-hooks.md`.
