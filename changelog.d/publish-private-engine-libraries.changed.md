- `@laticent/markup`, `@laticent/lastra` and `@laticent/segno-languages` are now publishable (they were `"private": true`), so all eleven libraries `@laticent/lattice` depends on can go to npm and a clean `npm i @laticent/lattice` resolves. Each gained `publishConfig.access: public` and a README fit for npmjs.com (an install line, no repo-relative links); `@laticent/segno-markdown` also ships markdown-it's MIT license beside its port of markdown-it's block rules, and `@laticent/lastra`'s Independent JPEG Group notice now covers its JPEG encoder as well as its decoder.
