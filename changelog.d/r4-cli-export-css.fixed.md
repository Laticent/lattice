- The CLI's self-contained player (`lattice deck.md -o deck.html --player`) now embeds local pictures its own CSS tokenizer missed, though Chromium loads them: an escaped `u\72l(photo.png)` or `image-s\65t("photo.png" 1x)`, an unquoted `url(` or an `image-set()` string that the end of a style closes, and an address holding a no-break space. Each used to ship the deck's local file path in the shared file and show no picture. The export now reads CSS with `cssRefSpans`, the reader the gallery gate, the Studio's export and the narrator share (Segno R4). Every deck in the repo exports the same bytes as before.
- The CLI's player no longer ships your folder's path when the deck sits in a folder whose name holds a parenthesis or a quote (`Decks (2024)`, `Bob's decks`). A relative picture there was neither embedded nor reported missing.
