- The Studio's player export now finds the pictures it embeds with the same HTML and CSS readers the web-image placeholder pass uses (`scanHtml` and `cssRefSpans` in `lib/core/remote-ref.js`), not its own regular expressions. Every deck in the repo exports byte-for-byte as before. Where the old patterns misread markup, the export now reads what the browser reads. It now embeds three pictures the old patterns missed, which shipped blank: an escaped `u\72l(…)`, an HTML `<image src>` (which the browser loads as an `<img>`), and a custom property's `url()` under any name, not only `--logo-mask`. It no longer fetches an `<img>` written inside a comment, a repeated `src` the browser ignores, or a malformed `url(…)` the browser never loads. (Segno R4.)
