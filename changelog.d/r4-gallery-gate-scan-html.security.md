- The package gallery gate (`lattice packages add` and the Studio's Library import) now reads a rendered sample slide with the same `scanHtml` reader the preview and every export use, instead of a parser of its own (parse5 in the CLI, `DOMParser` in the Studio). Where that reader cannot be sure how a browser builds the markup, the gallery is refused, and the reason names the character where it starts. That refuses some sample slides the gate used to admit: an inline SVG that carries a `<style>` or a `<foreignObject>`, a `<select>`, a `<noscript>`, and an HTML Mermaid `<div>` whose text holds markup such as a `<br>`. No shipped gallery is affected: the 96 shipped galleries still import, and all 446 rendered decks and galleries in the repo give the same references as before.
