- The package gallery gate (`lattice packages add` and the Studio's Library import) now reads a rendered sample slide with the same `scanHtml` reader the preview and every export use, instead of a parser of its own (parse5 in the CLI, `DOMParser` in the Studio). Where that reader cannot be sure how a browser builds the markup (HTML inside `<svg>` or `<math>`, `<select>`, `<noscript>`, an escaped script, a comment that never ends), or a Mermaid diagram holds markup other than text and highlight spans, the gallery is refused. No shipped gallery is affected: all 447 rendered decks and galleries in the repo give the same result as before.
