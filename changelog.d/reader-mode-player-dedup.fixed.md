- The exported player no longer hands reader-mode tools two copies of the deck. It carries the slides and the prose article in one document and switched between them with a stylesheet rule, which Readability (Firefox Reader View and its shake-to-summarize, and the reading modes Safari and Chrome ship) cannot see — so a summarizer received every sentence twice, 2255 extracted words for a 1080-word deck. `setView` now marks the inactive pane `hidden`, which those extractors do respect. The attribute lands only where the CSS already hides the pane, so nothing moves on screen, and only from JS, so the no-JS fallback still lays out every slide.
