- The exported player no longer hands reader-mode tools two copies of the deck. It carries the slides and the prose article in one document and switched between them with a stylesheet rule, which Readability (Firefox Reader View and its shake-to-summarize, and the reading modes Safari and Chrome ship) cannot see — so a summarizer received every sentence twice, 2255 extracted words for a 1080-word deck. The article's container now ships marked `hidden` and `setView` maintains that attribute as the view changes. Both halves are needed, because extractors reach the file two different ways: Firefox for iOS readerizes the live page, while Firefox on the desktop re-fetches the URL and parses it with no scripts run at all, where only the shipped attribute is visible. Nothing moves on screen in either case, and with scripting off every slide is still laid out.
