- Reader views now carry a **depth model**: a view is either a **rung** (an altitude in the deck's one containment-checked ladder) or a **cut** (a standalone slice). `kind: rung` in the front-matter `lenses:` block declares an altitude; absent means cut, so a view nobody declared a rung — a custom view, or one a deck already wrote out for itself — is never enrolled in a ladder.
- The ladder is **derived from what each rung shows**, not declared — `ladderRungs` orders rungs narrowest first with the full deck on top, so adding views in a different order never re-orders the depth chain (`order:` stays a picker position).
- New `validateLadder` reports, per slide, any slide a rung shows that the rung above it does not — the invariant that makes "go deeper" additive, now enforced for hand-tagged membership rather than only proved for the suggester. The Reader views panel surfaces these on the offending view, with a `Ladder` marker on its row.
- New `deeperLens` read-path primitive: the next rung that is reader-eligible *and* strictly contains the current view, or nothing. It fails closed, so a deck with a broken ladder still reads safely — it just cannot climb. The "go deeper" affordance in Present is a separate, not-yet-built slice.
- **The two starter views are rungs.** A deck inheriting the workspace defaults ("Default reader views" on, the shipped setting) now shows a `Bottom line → The evidence → Full deck` ladder without doing anything — deliberately, since those two are exactly the pair that provably nests. If such a deck's hand-tagged membership breaks the nesting, the Reader views panel now says so where it was previously silent.
