- **Breaking:** the `etching` look is now `etch`, in all three places it was a value: `marks: etch` (and the `marks-etch` slide class), `icon: … etch`, and `spark: … etch`. `etching` is no longer accepted: front matter reports `unknown-marks`, `unknown-icon` or `unknown-spark`, the `marks-etching` and old `chart-finish-etching` slide classes report `unknown-class`, and an inline `^{shield, etching}` or `~{1 2 3, etching}` stops being an icon or a spark and renders as plain code (`icon-literal` / `spark-literal`). There is no alias because the language is not GA. The LFM 1.1 spec table and its conformance fixtures are updated to match. Decks that wrote `etching` need a find-and-replace.
