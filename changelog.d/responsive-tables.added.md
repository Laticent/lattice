- **Tables reflow when they run out of width.** A record list (each row one thing: a person, a file, a risk) becomes one card per row, its first cell the card's title and every other cell a `LABEL value` line, the values aligned in one column (a label past 10 characters sits above its value); a two-column table puts each label above its value. Every other table keeps its grid. The engine names each table's kind on its own (`lib/core/table-shape.js`), and the switch is a container query on the table's own box, so it fires in a narrow pane, on a portrait canvas or on a phone, and never on a full-width or half-pane 16:9 slide. On a slide it switches only where the new layout fits: when the cards would make the slide overflow, the table keeps its table form and the export says so with an `ⓘ` line. Overrule a wrong guess per slide with `table-cards`, `table-pairs` or `no-table-reflow` (a slide's override reaches its panes; a pane marker can name its own). The components that own a table follow: a `glossary` puts each term above its definition, a `math derivation` puts each justification under its step, and `obligation-matrix` and the `statute-stack lane` take the cards; `matrix-grid` and `roadmap` keep their grid. In a table that reflows, each body cell carries its column header as `data-lat-col`, and the table carries ARIA table roles.
- **`npm run lab:build`**, the Frame Lab: every component's gallery in a frame you can narrow, with type held at slide size and no height limit, to see how each one responds. **`npm run tables:bakeoff`** scores the table-kind detectors against 225 independently labeled tables.
- **Rows of cards drop columns when their box narrows.** `cards-grid`, `verdict-grid`, `pricing`, `stats`, `statute-stack`, `decision`, `list-steps`, `compare-prose`, `team-profile`, `cards-stack horizontal`, `q-and-a`, `inventory cards`/`timeline` and `kpi` respond to the width of their content area, not only to the deck's aspect, through one shared rule (`lib/base/base.card-reflow.css`); a full-width 16:9 slide never changes, and on a slide a row that would overflow keeps its columns. statute-stack's status pill no longer lands on the label in a narrow card.
- **Fixed:** a `cards-grid three` grid stayed three across on portrait and mobile decks; it now stacks one card per row, as `cards-grid` always intended.
