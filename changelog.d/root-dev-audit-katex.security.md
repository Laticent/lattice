- **Updated KaTeX to 0.18.2** (from 0.16.46), the copy the math plugin bundles for every surface: the CLI, the docs site, the HTML player and the Export-to-Marp bundle. Rendered math is unchanged: the math demo decks render byte-identical PDFs in light and dark, and an Export-to-Marp bundle renders pixel-identical pages through marp-cli. KaTeX 0.18 prefixes 21 of its internal class names (`base` → `katex-base`, `strut` → `katex-strut`, `sizing` → `katex-sizing`, …). Exported HTML and Marp bundles carry the new names together with the matching stylesheet, so only a custom style aimed at one of the old internal names needs updating.
