- **Breaking:** a custom style aimed at one of KaTeX's own internal class names inside rendered math needs the new name. **Updated KaTeX to 0.18.2** (from 0.16.46), the copy the math plugin bundles for every surface: the CLI, the docs site, the HTML player and the Export-to-Marp bundle. KaTeX 0.18 prefixes 21 of its internal class names (`base` → `katex-base`, `strut` → `katex-strut`, `sizing` → `katex-sizing`, …). Exported HTML and Marp bundles carry the new names together with the matching stylesheet. Rendered math is otherwise unchanged: the math demo decks render byte-identical PDFs in light and dark, and an Export-to-Marp bundle renders pixel-identical pages through marp-cli. `.katex`, `.katex-display`, `.katex-error` and `.katex-mathml` keep their names.
