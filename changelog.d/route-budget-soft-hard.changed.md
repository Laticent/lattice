- The docs build's per-route byte budget now has a soft target and a hard limit (soft + 3%). Between the two the build passes and prints the room left, so most PRs that grow the Studio no longer edit `docs/route-budget.json` or conflict with each other on it. Past the hard limit it still fails; a reset that raises a number (`npm run route-budget:rebaseline -- --raise` in `docs/`) needs the owner's OK, and every reset records itself in `docs/route-budget.history.md`.
- Each PR may add at most 2KB of gzipped startup JavaScript to any docs route, measured against `main` in CI. Past that, the docs build fails unless the PR adds its own explanation file under `docs/route-budget.d/`; the next budget reset folds those files into `docs/route-budget.history.md`.
