- The docs build's per-route byte budget now has a soft target and a ceiling per route. Between the two the build passes and warns on the CI summary page; past the ceiling it fails. `docs/route-budget.json` changes only through `npm run route-budget:rebaseline` (in `docs/`), which records each change in `docs/route-budget.history.md`; raising a number needs the owner's OK.
- Each PR that runs the docs build may add up to 2KB of gzipped startup JavaScript to a route, measured against `main` in CI, while the route stays at or under its soft target. Every byte above soft is declared per route (`studio: +N` plus why) in the PR's own file under `docs/route-budget.d/`.
- The route budget now counts the code a page's scripts import statically, not only the scripts named in its HTML. Home, components and getting-started read 262KB, 167KB and 150KB gzipped instead of 80KB, 81KB and 77KB; their budgets were reset to match.
