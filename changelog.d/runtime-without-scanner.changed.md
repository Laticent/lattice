- **The player runtime and the engine bundle no longer carry the web-reference scanner.** `lattice-runtime-min.js` (the script every exported deck loads) bundled all of `remote-ref.js` for one constant, the blocked-image placeholder, and `sampleName`/`assetName`. Those now come from `media-sources.js`, the leaf the scanner already depended on. Measured with the build's own esbuild settings: the minified runtime goes from 1,314,190 B (460,726 B gzipped) on `main` to 1,295,975 B (453,526 B gzipped), 7.2 KB gzipped smaller, and 8.1 KB smaller than the same runtime with the scanner's new checks.
