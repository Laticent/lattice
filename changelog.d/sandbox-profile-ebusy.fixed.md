- On Windows, a render with a code package or npm plugin no longer fails with `EBUSY: resource busy or locked, unlink …\Cache_Data\sqldb0` when the sandbox browser closes. Chromium's helper processes can hold a file in the browser's temporary profile for a moment after it exits; the code sandbox now removes that folder with Node's retry-on-EBUSY backoff (up to about 5.5 s) instead of a single attempt.
