- On Windows, the code sandbox now retries removing the sandbox browser's temporary profile when a file in it is still busy, instead of giving up at once. A render with a code package or npm plugin could fail with `EBUSY: resource busy or locked, unlink …\Cache_Data\sqldb0`, because Chromium's helper processes can hold a file there for a moment after the browser exits. The removal now uses Node's retry-on-EBUSY backoff, up to about 5.5 s.
