- **Breaking:** a slide's spoken line is now `<!-- say: … -->`, and the front-matter map is `say:` (slide number → line). `<!-- caption: … -->` and `captions:` are retired: the engine no longer reads them, `lint:deck` reports them as a `caption-key-retired` error, and the render warns. Rename the key; the value keeps its shape. The key is lowercase only: `<!-- Say: … -->` stays a private speaker note, so a presenter's "Say: …" note-to-self is never published, and `lint:deck` warns (`say-key-case`) in case it was meant to be spoken. "Caption" now means only visible text: the on-screen band, the `.vtt` sidecar and figure captions.
- **Breaking:** `--strip-captions` is now `--strip-say`. The old flag exits with an error that names the new one. `--captions` (the `.vtt` sidecar) is unchanged.
- The Studio's per-slide field is now **Say — what this slide says aloud**, and writes `<!-- say: … -->`. Its help text no longer claims an empty field falls back to the speaker note; it falls back to the generated narration.
