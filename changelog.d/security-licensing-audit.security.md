- **Security dependency bumps.** DOMPurify 3.4.17 (a critical advisory) and markdown-it 14.3.3 (four quadratic-time advisories), with linkify-it, undici, ws, js-yaml and the rest of `npm audit fix`'s non-major set, at the root and in the docs site. `npm audit --omit=dev` goes from 19 (1 critical) to 11 at the root and from 16 (1 critical) to 4 in docs/; what is left needs a major (puppeteer 25, image-size 2, sharp 0.35, esbuild 0.28). markdown-it 14.3 is linear on unclosed inline `<!--` by itself, so Lattice's own `html_inline` guard is retired. One authoring edge moves with it: a `<!-- … -->` directive opened in a list item and closed after a blank line now runs to its `-->` and applies, as CommonMark says; before, the item's end cut it off.
- **The vendored Mermaid moves to 11.17.2**, so diagram labels are sanitized by DOMPurify 3.4.12 instead of 3.3.1 (21 published advisories down to 5). C4 diagrams now draw people as a head and body, and honor `mode: sketch`. Mermaid 11.17 writes C4 box colors inline, out of the stylesheet's reach, so the engine now sends the deck palette through Mermaid's own C4 color keys. A block diagram's cylinders size to their labels. C4 relationship labels now sit centered just above their line, with a halo, instead of drifting into the target box or onto the arrowhead.
- **Raw HTML can no longer forge a slide's number.** An author's `data-lattice-slide` in raw HTML becomes `data-x-lattice-slide`, the way `data-split-*` and `data-fluid-*` already did, so a quote carried across two HTML tokens cannot plant a slide index the split, the slide rail or the Studio would trust. Other `data-lattice-*` names an author writes, such as `data-lattice-motion`, are untouched. The rename also reaches an author `<style>` block, so a selector like `section[data-lattice-slide="2"]` there no longer matches; give the slide a `_class` and select that. A speaker note that mentions one of these reserved names is now stripped by `--strip-notes` too; before, the rename made the note's rendered text differ from its source, and the strip left it in the embedded source.
- **The Export-to-Marp bundle carries its license texts.** Every bundle, from the CLI and from the Studio, now ships `THIRD-PARTY-LICENSES.txt` with the full MIT and SIL OFL 1.1 texts for Mermaid, dagre-d3-es, Lodash, Tabler Icons and the fonts, and its README names the file. The Marp kit ships the same file from the same source.
- **Live says who sees your IP address.** The Start live session card and the lobby now say that a guest's browser connects directly to everyone in the session, before being let in, and that the public servers that help browsers find each other see the address too.
