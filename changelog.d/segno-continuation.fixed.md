- The /segno playground now READS the grammar box instead of running it as JavaScript. The box keeps the same `const … ; return { start, rules }` shape, and every preset builds the same grammar as before, but only grammar helpers, strings, numbers, objects and earlier names are understood. A `for (;;) {}` used to freeze the tab; now it is an error with a line and column. A grammar that reuses names to double in size (under 1 KB of text, millions of pieces) is refused at 10,000 pieces instead of freezing the tab while it compiles. No visitor text is ever executed.
