- `NUMERIC_PILL` in `lib/core/chart-values.js` now runs in linear time. It is Segno's rewrite of the same pattern and accepts the same strings (0 disagreements on a 300,000-case fuzz). A failing match on `1` + 50,000 tabs + `x!` took about 3 s and now takes 0.2 ms.
- The /segno playground READS the grammar box instead of running it as JavaScript, and builds the grammar in a Web Worker with a 1.5 s limit. The box keeps the same `const … ; return { start, rules }` shape, and every preset builds the same grammar as before, but only grammar helpers, strings, numbers, objects and earlier names are understood. No visitor text is ever executed. A `for (;;) {}`, which used to freeze the tab, is now an error with a line and column. A grammar that reuses names until it doubles past 10,000 pieces is refused at once. Any other grammar that Segno is slow to build, such as an `alt()` of 3,000 literals, which took about 10 s, is stopped at 1.5 s while the page keeps running.
