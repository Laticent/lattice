- Segno: a record whose first character is `>` is a description, `{> prose}`, with prose to the first unescaped `}` (`\}` and `\\` escape). The reader returns a `description` value, and a slot that takes values reports `description-not-here`. A record's first bare item can no longer start with `>`: `{>5}` is a description, not the number 5 (no deck in the repo wrote one); later items keep it (`{3, >5}`).
