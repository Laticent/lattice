- **A pill reads about a third faster, and so does every other plain `{…}` span.** Segno binds a `{…}` span of bare words and `name=value` items (a pill, a chart point, a state) straight from the parser's tree, without building an object per item. A span it cannot bind that way (a quote, a nested record or list, an unknown word, any error) takes the full path, which alone words a diagnostic, so errors read as before. The slot's bind alone went from about 355 ns to 260 ns on the shipped decks' pills, and the dispatcher's decision for a pill from about 480 ns to about 370 ns (same machine, interleaved runs; `npm run parser:bakeoff:segno`). A unit test holds the two paths equal on every one-to-three-item span built from a 37-item pool, in four slots.
- **Types Segno builds are marked as its own.** A type of your own (a `read` you wrote, or a copy of a built-in with a new `read`) keeps the full bind, because its `read` may parse a span of its own and overwrite the buffer the fast read walks. `isBuiltIn(type)` is exported from `types.ts` for that check; it is not part of the published API.
- `isDirective` no longer tests the tag set for a span that opens with `{`, `isName` replaces a regular expression, and the icons plugin's `canonical` skips `trim().toLowerCase()` for a name that is already spelled as the set spells it. The pill reader keeps the canonical icon it found in the decision and reuses it to build the result, which asked the icons service a second time before.
