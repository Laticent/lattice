- The web-reference scanner no longer misses an image or `<source>` that MathML `<mi>`/`<mtext>` or SVG `<desc>`/`<title>`/`<foreignObject>` let through: a `<![CDATA[` section there (terminated or not), a start tag inside one, and a `</svg>` or `</math>` the browser ignores inside one now hand the markup to the spec parser. Each fetched in Chromium as written. No deck in the corpus is affected.
- A stray `<body>` tag (`<table><td><body background=…>`) no longer carries a web address past the scanner's spec-parser check: the tree builder gives its attributes to the page's own body, which the check never looked at. Found by the browser fuzz; it fetched in Chromium, WebKit and Firefox.
- Scanning markup with many comments is linear: 400 KB of comments took 29 s and now takes milliseconds.
- Segno R3: an HTML reader generated from a Segno grammar (`lib/core/html-ref-grammar.js`) is built and held to the live scanner and to a spec parser (`npm run check:html-ref-spans`, `--fuzz` for seeded streams). It reports `unsure` spans, each with a reason. The scanner does not use it yet: the switch waits on the Studio's route-budget ceiling.
