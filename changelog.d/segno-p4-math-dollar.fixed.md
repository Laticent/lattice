- A paragraph with many unclosed `$` signs (prices, or a pasted table of amounts) no longer costs time that grows with the square of its length: math's inline `$` rule searched to the end of the paragraph again for every `$` that had no closer. It now remembers that no closer lies ahead, separately inside each link label, so a paragraph like `Costs $5 per seat, see [the $5 plan](u).` repeated is read once too. Ten times the input now costs ten times the work (measured in characters read; it was a hundred times). The math a deck renders is unchanged.
