- The CLI no longer adds a second copy of the engine stylesheet to a palette that writes a `/*` inside a string before its `@import 'lattice'` (for example `content: "/*"`). It reads whether a palette imports a theme the way CSS reads it, so an `@import` inside a comment or a string doesn't count, and one written in capitals or with escapes does.
- Math exports read KaTeX's font faces the way CSS reads them: a `src:` or a `@font-face` inside a comment or a string is no longer inlined or moved, and a `}` inside a string no longer ends a face early. KaTeX's own sheet exports byte for byte as before.
- The webpage player's font cut reads its `@font-face` rules the way CSS reads them: a `}` inside a family name no longer hides the face's font from the cut, and a face written inside a comment no longer counts.
- The webpage player's font prune and merge read each `@font-face` the way CSS reads it: a `}` inside a family name no longer splits the face in two, and a face written inside a comment no longer counts as declared.
- PDF exports read a local stylesheet's `@font-face` rules the way CSS reads them: a face inside a comment is no longer embedded, a `}` inside a family name no longer cuts a face short, and a face written `@FONT-FACE` or with a comment before its `{` is no longer missed.
- A deck's own `:root` color overrides reach every slide of a PDF, PowerPoint or webpage export even when its CSS writes `/*` inside a string (for example `content: "/*"`), or a selector such as `:is(:root, .brand)`. Before, the first dropped every override after the string, and the second wrote a broken selector.
- Export to Marp copies only the font files its stylesheet really asks for: a `url(fonts/…)` written inside a string no longer counts, and a `URL(…)` in capitals does. It drops the emoji faces whole, so a `}` inside a quoted name no longer leaves half a face behind.
- The VS Code theme stub that Export to Marp and the copy-and-go kit register no longer lists an `@import` that sits inside a comment or a string, and it reads one written `@IMPORT`.
- An export no longer fails on a deck whose own CSS nests `@media` or `@supports` rules thousands deep. In a deck's `:root` overrides, a string that a line break cuts off drops only its own declaration, and an escaped space at the end of a name (`\ `) keeps its space.
