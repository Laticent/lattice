- **Segno's generated `parse()` allocates nothing per successful call.** It reuses one result object (its tree was already valid only until the next parse, because the buffer is shared) and skips the rule-table lookup for the grammar's default rule. A pill's grammar stage went from about 270 ns to about 225 ns, and the shipped decision for a pill from about 500 ns to about 480 ns (same machine, interleaved runs of `npm run parser:bakeoff:segno`). Trees and errors are unchanged; the 305 Segno tests and `inline-code-table.test.js` pass. The generated parsers in `lib/core` (`flowchart-row`, `list-text`) pick the change up too.
- **`npm run parser:bakeoff:segno` times a row's columns alternately.** It used to time the retired kernel, the arm's copy and the shipped dispatcher one after another, so a slow stretch of the machine landed on one column: the same code read 1.0x to 1.65x for the every-span ratio. It now reads 1.18x to 1.37x over five runs. Each column also gets a timer function of its own.
