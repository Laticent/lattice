- The docs site no longer loads any runtime dependency from a third-party CDN. Mermaid and KaTeX were self-hosted on the Studio and Playground but fell back to jsdelivr wherever a host did not pass a URL — including the landing page, which renders diagrams and passed none, so it executed a floating `mermaid@11` with no `integrity` check inside the preview frame. Every host now passes the locally-vendored copy, the CDN fallbacks are gone, and a missing URL leaves the diagram unrendered rather than reaching out.
- Exports no longer fetch a stylesheet from a third party at export time. The Studio's `.html` export inlines KaTeX CSS; it used to fall back to a CDN URL when the caller passed none, making a third-party request part of building a file the author hands to someone else.
