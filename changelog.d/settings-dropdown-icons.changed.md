- Studio Settings: every picker in the deck and slide panels now opens with one `Auto — <what it resolves to>` row, marked with the Auto link icon, and never lists that value a second time. Before, heads read "(default)", "Default — tab", "Finish's own", "Theme default" or just the default value with no Auto row. On the deck that value is the preset's or the engine's default; on a slide it is the deck's. Picking the Auto row removes the setting.
- Studio Settings: Color mode, Size and Venue are now the same picker as the rest of the panel, with an Auto row and icons. Venue keeps its "who it is for" line under each room.
- Studio Settings: the bar, rule, alignment, card-row, corner and fit previews drew as solid squares. The preview chip wrote an empty `background-size`, and that wiped the sizing out of every swatch that uses a `var()` in its background. Each chip now draws its real shape again.
- Studio Settings: options that pick a position, an alignment, a spacing or a fit action now show an icon from the site's icon set, sized and colored to match the color swatches. Bar and card-rail placement, headline and tag-text alignment, card rows, corners, fit, slide splitting, tag size, venue, logo position and scope, and the image card's placement and density all have one.
- Studio Settings: options for Lattice's own looks show a small drawing of the result: every stamp shape and tone shape, card tag color and placement, slide size as its aspect ratio, logo color and size, delivery, a level meter for motion speed and pace, and the image card's ink, size and shape. The heading-rule chips draw a heading with its rule beneath, the eyebrow Arrow chip draws a real chevron, Brand bar None draws the hairline it leaves, and the Claim and Sketch chips are easier to see.
- Studio Settings: the card rail's "follow the bar" value reads "Match bar", and the deck's stamp and tone shape rows record their change under their own names, so a live session can point at them.
- Studio and site menus: on iPhone and iPad, a tap outside an open picker or menu now closes it. Before, the list stayed open, and tapping another picker opened a second list on top of the first. Every dropdown built on the shared select and menu gets the fix, and a tap outside now only closes the list instead of also pressing whatever was underneath.
- Studio: Debug overlay and the Audit panel's "Style judged as" are now the same picker as the rest of Settings, with an Auto row and icons. Debug overlay was a hand-built menu, and the profile picker was a browser `<select>`.
- Engine: six per-slide restore tokens return one slide to a register's default inside a deck that set another value: `spectrum-on`, `spectrum-edge-top`, `spectrum-card-edge-left`, `rule-auto`, `eyebrow-plain` and `head-auto`. A slide in a `spectrum-edge: left` deck can now write `_class: spectrum-edge-top` to put its bar back on top, which no spelling allowed before. The Studio's slide pickers list each default as an ordinary choice and write the token. `lint:deck` warns (`conflicting-variants`) when a slide carries two tokens from one of these axes, such as `spectrum-on spectrum-solid`, because a restore token draws nothing and always loses to its rival.
