- **The CLI's PDF export now uses Lattice's own writer, the same code as the Studio's Export to PDF** (`lib/core/pdf-compose`). Each slide's background is one photo; words, charts, images and links go on top as real text in the deck's fonts, vector shapes, original images and clickable links, tagged for screen readers with the title and language. It draws several times faster in iOS Preview and Acrobat (a 9-slide finish deck: 13.1 s → 1.45 s in poppler, 335 KB → 237 KB). `--chrome-pdf` prints with Chrome as before.
- **`color-mode: print` no longer draws a finish**, on screen or in any export: the black-and-white handout carries no glow, texture or margin bar.
