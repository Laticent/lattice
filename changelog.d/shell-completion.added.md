- **Tab completion for the `lattice` command in bash, zsh, fish and PowerShell.** `lattice completion <shell>` prints a script you install with one line (for example `eval "$(lattice completion bash)"` in `~/.bashrc`, which works from bash 3.2, the macOS default, up). Tab then completes the subcommands, every option, the values an option takes (palettes, `--size` canvases, `--paper` sheets, plugin names, the image-set settings) and the packages you installed, and narrows paths to the files that fit. A Tab press costs one Node start, about 50 ms.
