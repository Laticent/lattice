  Three things catch an old deck. Rendering one prints a warning naming each affected slide. `lint:deck` flags the same slides with the marker to use. The new `npm run lint:deck -- --fix <deck>` rewrites every verdict-grid and pricing `[ ]` to `[!]`, which draws exactly what the deck drew before. Like any linter's `--fix`, it applies every machine fix; it names each one by rule and slide, and keeps the file's line endings and BOM. It rewrites only the slide each warning names, even when heading splits put several slides between two `---` lines. It leaves obligation-matrix alone, because an old `[ ]` there could mean exempt, not required or undetermined, and only the author knows which. None of them fires on a slide that already uses `[!]` or `[?]`, or on a label set that names `[ ]`. Every shipped deck and gallery is migrated.
