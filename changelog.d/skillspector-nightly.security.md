- **Agent skills and agent instructions we ship are now scanned nightly for security problems** with NVIDIA SkillSpector: the 19 skills in `.claude/skills/`, and from the agent kit exactly as users download it (`dist-kits`) its skills, the files an agent loads on its own (`CLAUDE.md`, `AGENTS.md`, `lattice.mdc`, the plugin manifests) and the paste-in instructions. A finding the reviewed baseline does not excuse opens a tracking issue and lands in the repository's code scanning tab. Run it locally with `npm run scan:skills`.
- Three skill sentences are reworded so the scanner's checks stay fully on: the `lattice-theme` skill writes "deltaE" for the Greek "ΔE", and the `cli` and `import` skills no longer use the phrase "no warning(s)" to describe a clean build.
- **The agent skills now run Lattice as `npx @laticent/lattice`.** They used to say `npx lattice`, and the unscoped `lattice` package on npm belongs to an unrelated publisher, so an agent following a skill outside a Lattice project downloaded and ran someone else's code. Until `@laticent/lattice` is published, the scoped command fails with "not found" instead.
