- **Fixed: a speaker note containing `$1`, `$&`, `` $` `` or `$'` no longer corrupts the render.** The note's `<aside>` was spliced into the slide with `String.replace` and a replacement STRING, where those sequences are backreferences rather than literals — so a note reading "$100" expanded to the first capture group (`<section`) plus `00`. The stray tag unbalanced the HTML, the depth-aware section walker then under-counted slides, and the page/note length mismatch made the exporter drop **every** note annotation from the PDF with only a warning. Prose about money was the ordinary way to hit it. The splice now uses a replacer function, whose return value is taken literally.
