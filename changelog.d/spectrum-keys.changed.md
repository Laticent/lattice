- **Breaking:** the spectrum settings are three keys, each named for the thing first and taking one word per axis in any order. `spectrum:` sets the stripe on the slide edge (`spectrum: solid left band`), `card-spectrum:` the stripe on each card (`card-spectrum: solid top`), and `trim-spectrum:` the accent on tables, timelines and rules (`trim-spectrum: mono`). No key follows another: each has its own default (the slide edge rainbow, the cards off, the trim quiet) and names its own style. `spectrum-edge:`, `spectrum-card:`, `spectrum-card-edge:`, `spectrum-trim:` and `spectrum: on` no longer render. `npm run lint:deck` reports each as an error, and `npm run lint:deck -- --fix` rewrites it: `spectrum: duo` plus `spectrum-edge: left` becomes `spectrum: duo left`, `spectrum-card: auto` and `spectrum-trim: on`, which copied the slide edge, become the style the deck was showing (`spectrum: duo` plus `spectrum-card: auto` becomes `card-spectrum: duo`), and `spectrum-trim: restrained` becomes `trim-spectrum: mono`.
- **Breaking:** the spectrum classes follow the keys: `spectrum-edge-left` is `spectrum-left`, `no-spectrum-edge` is `no-spectrum`, `with-spectrum-card` and `spectrum-card-rainbow` are `with-card-spectrum` (the rainbow), `spectrum-card-solid` is `card-spectrum-solid`, `spectrum-card-edge-top` is `card-spectrum-top`, and `with-spectrum-trim` / `spectrum-trim-restrained` / `no-spectrum-trim` are `trim-spectrum-rainbow` / `trim-spectrum-mono` / `trim-spectrum-quiet`. Lint fixes each in place.
- A new weight axis on `spectrum:` and `card-spectrum:`: `regular` (the default), `hairline` and `band`. A `band` slide edge is about 19px on a 1280px slide, and the slide's content, header, footer and page number stay exactly where they are.
- Deck settings label the three keys **Spectrum**, **Card spectrum** and **Trim spectrum**, with an Edge and a Weight row under each stripe, replacing "Brand bar", "Bar placement", "Card rail", "Card rail placement" and "Structural trim".
- A preset that sets a spectrum key fills only the parts the deck leaves out: on `preset: brand`, `spectrum: left` keeps Brand's solid style and moves the stripe to the left.
