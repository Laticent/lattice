- **A machine fix no longer edits a code fence.** When a slide quoted the wrong form in a fence above the real line (a fenced `<!-- _class: … -->`, a gantt span, a `- **Title.** body` card), the fix rewrote the fenced example and left the real line alone. That happened in "Fix all", in the editor's one-click fix and in `lint:deck --fix`. The fix now edits the real line and leaves the example as written. A `- **Title.** body` line inside a fence on a card, ledger, split or number slide is also no longer reported, because it is an example, not a card.
