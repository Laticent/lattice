- **Fixed: nine lint rules no longer report a fenced example.** A fenced sample of a wrong form is documentation, and the engine draws nothing from it, but the five gantt task rules, `unknown-map-region`, `statement-ol-bold`, `check-label-code` and `video-bullet` flagged it. Each now skips a top-level code fence, so a fenced gantt task also no longer counts as a task a live `after=` can name, and a fenced `@video{…}` record no longer counts as the slide's clip. They skip only a fence the renderer certainly draws as code, so a stray fence line in a list item or a speaker note never hides the live lines after it.
