- **Added: "Fix all" says which fixes it did not apply, and why.** The Studio's Fix all (its button, the command palette and the phone drawer) and the Playground's Alt-Shift-F now end with a notice: how many issues it fixed, then each fix the fix driver refused, by slide, rule and reason ("Slide 2, card-style-inline-title: Fix all stopped before reaching it; press Fix all again."). A refused fix keeps its underline, which before this came with no explanation. The fix driver also stops listing one refusal twice, and stops reporting a refusal whose issue a later fix resolved anyway.
