- **Changed: "Fix all" in the Studio and the Playground, and `lint:deck --fix`, now run through Squadra's fix driver.** Every fix that does not overlap another applies in one pass, where the old loop applied one fix and re-linted the whole deck after each. The driver never edits inside a code fence, so a fenced example of the wrong form stays as written. It never applies a fix that changes the number of slides or drops the front matter, unless the fix emptied the front matter on purpose. It reverts a fix that does not make its own finding go away. And it keeps going past a fix that cannot apply, where the old loop stopped at the first one. `lint:deck --fix` now prints each fix it refused, with the rule, the slide and the reason.
