- The front-matter island (internal; no deck renders or lints differently). `lib/core/front-matter-island.mjs` is now the one place that says where a deck's front matter ends and which of its lines are keys. The engine's `parseFrontMatter`, the register readers (`frontMatterValue`, `topLevelFrontMatterValue`), the slide splitter, the deck model, the plugin admission and the `lattice-deck` language read it, where each used to carry its own pattern. `lattice-deck` gains an `fm-key` node per front-matter key, with name and value spans, and the `deck.settings` fact. Three edges now read as the engine reads them: a lone carriage return as a line end in a raw-bytes reader, U+2028 as text inside a value, and a closing `---` followed by spaces in the splitter.
