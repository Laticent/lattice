- **Added: `@laticent/squadra`, a lint-and-fix library that refuses a rule it cannot prove works.** A rule must fire on its own bad examples at the spans they mark, stay quiet on its good ones, and its fix must turn each bad example into its fixed partner and keep the document's shape, or the rule does not load. Findings carry spans, not line text, and one fix driver checks every fix: no overlapping edits, no edits inside code fences, and no fix that changes the number of slides or drops the front matter unless its rule declares it. The core has no dependencies, no DOM and no file access, so the same rules run in Node and in the browser.
