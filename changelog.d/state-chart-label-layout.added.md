- `state-chart` edge labels now sit **off the line** — below it on `lr`, to the right of it on the default — so a multi-line label no longer knocks a hole through its own edge. Event text accepts explicit breaks (`\n` or `<br/>`) and wraps on its own when it is still too long, never mid-word.
- Edge length is **responsive**: the rank gap stretches so a `tb` machine fills the stage's height and an `lr` machine fills its width, floored at the room the labels actually need — so a sparse machine gets air and a label can never reach a node.
- The clearance each axis asks for now follows **where the label sits**: a `tb` label sits beside the vertical run, so its height is no longer stacked into the rank gap as well, and it wraps late because on `tb` the cross axis is the cheap one. A four-state `tb` machine gets its full width back and 17% of its height, which the fit spine spends scaling the diagram up.
- **Fixed:** a re-ranked chart no longer feeds its own output back into its next draw. The size pin the layout puts on the scale box was still there when the next draw measured the nodes inside it, so the column was narrower each time and labels wrapped that did not need to; on a live preview one chart alternated between two sizes forever. The pin now comes off before measuring, alongside the fit transform it sits next to.
- **Fixed:** an `lr` edge label no longer cuts the connector it labels. The offset positioned the label block's *center*, so the first line's box top landed half a pixel below the edge and the label's halo reached back across it — visible on two edges of the branching demo deck.
