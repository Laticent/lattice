- **state-chart: no more snap in the Studio and Playground.** After an edit, the chart now draws in the same frame the slide appears. Before, the raw measuring column showed for two frames and then the drawn chart snapped over it. The runtime's mutation observer now draws a newly inserted state chart in its microtask, and the layout pass observes every figure, including ones inserted after install.
- **state-chart: an idle slide stops redrawing.** Each draw rewrote the SVG and probed label lines through `innerHTML`, and the runtime answered those writes with another content pass. So a state-chart slide redrew every ~160ms for as long as it was open. The pass now skips a write that would change nothing, so the cycle settles after one lap.
- **state-chart: a status now paints the state, the way it paints a gantt bar.** A node with a status takes that status's tinted fill, edge and leading accent. A node with none is a quiet neutral tile with no accent. This removes the plain slate stripe that ran down every node's left edge and carried no information. The colored disc that used to overhang the corner is gone too; the ordinal is a quiet numeral on every node. `deferred` draws hollow and dashed, as on gantt. Status tiles use the pill's stops (18/30 light, 42/54 dark), so the state name clears 4.5:1 on every theme; `tools/composed-contrast.js` now scores the name and ordinal on each status tile.
- **Breaking (visual): state-chart picks its own direction and wraps a long machine instead of shrinking it.** Every state-chart slide without `lr` re-lays out: it no longer defaults to a single top-to-bottom column. Add `tb` to keep the column. No build or authoring syntax breaks; the slide changes shape on its own. With no direction modifier, the chart now scores both directions at every row count against the real stage and picks the one that sets the state names largest, capped a step above body size. A long chain wraps in reading order: each row runs left to right, and a connector drops to the next row. Measured on a bare 16:9 stage, a 10-state chain used to set its names at 4.6px. There, four and five states stay on one row, six wrap 3 + 3, and twelve take three rows of four. The row count depends on the room the slide leaves, so a slide with a subtitle and caption may keep six states on one row or put twelve on two. Every chain now shares one visual language: labels sit beside their line, loops nest instead of crossing, and `curved` rounds corners. A branching machine still goes to dagre, which picks its direction by fit, and a wrapped layout can beat it by a clear margin. A small machine no longer blows up to poster size: the fit stops at 1.6x body text. A node is never narrower than its longest word, so a long single-word state name no longer spills out of its tile on a narrow stage. Edge labels are laid out at the size they actually paint once the chart scales down, so they no longer land on nodes or past the figure, and no two edges ever draw as one line. A new `tb` modifier pins the old top-to-bottom direction, and `lr` still pins a row; both may still wrap.
- **state-chart: the ordinal reads, and the `inline` card list lines up.** The numeral on each state now sets at the chart's text floor (the size an edge label paints at, 11px on a 1280-wide stage), with equal air above and beside it, and the tile's side padding clears it. It used to sit 2px from the corner at the engine's 1% hard floor. On `inline`, the cards form one table, numeral | name | transitions, so names and chips start at the same x on every card instead of floating right on some. A status now tints its card (a `live` card used to paint neutral while its legend chip was green), `deferred` cards are hollow and dashed, the gap between cards opened from 4px to the small spacing step, and the end state's double ring is drawn inside its card, so the last card no longer sticks out past the others.
