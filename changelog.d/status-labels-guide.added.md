- **Added: a "Status and labels" guide on the docs site, replacing the single "Pills and marks" page.** Seven pages, read in order: a start page on which tool to reach for (state mark, pill, status word or label set) and which ones work on every slide versus only in certain components; the six answers and how to choose between the ones that look alike; each layout's words for the six answers, renaming them with a label set, and the `checks-*`, `heat` and `state-cells` switches; brace pills; the pills a component places from position; upgrading a deck written before the six answers; and a one-page cheat sheet. `/guides/pills/` redirects to the new start page.
- The component reference pages for the layouts that read marks, status words or positional pills now carry a **Guides** section linking to the page that teaches that grammar.
- The checklist, verdict-grid and pricing references now name the same words the engine speaks for each marker: checklist `[/]` is "skipped", verdict-grid `[-]` is "partial" and `[/]` "not applicable", and pricing `[/]` is "not included". An inline mark's accessible name for `[x]` is "yes", not "done", as `base.docs.md` had said.
- The docs-site glossary adds the status terms and lists **mark** as a fourth word with more than one meaning, and the theme track explains why the unknown, open and does-not-apply marks share one gray.
- **Added: a "Deck settings" guide and a generated front-matter reference.** The guide explains how the front-matter block works — it applies to every slide, one slide can differ, a wrong value is linted, and the Studio's Settings writes it — then walks the settings most decks want, with live examples. The new **Reference → Front matter** page lists all 60 keys with their accepted values, default, Studio control and per-slide form; its keys come from the Studio's autocomplete list and its values from the list `lint:deck` accepts, so it cannot drift from either.
- **Fixed: four false claims on the docs site.** The introduction said Lattice has no animation or presenter timer; it has chart motion, `_build` reveals and a rehearsal clock in Present mode (the PDF stays still). Getting Started sent readers to the removed Drawing Board for the Marp export (it is **Share → Marp bundle** in the Studio) and quoted stale layout counts. The authoring guide listed `loose`, which is not a modifier.
- The Studio's front-matter autocomplete now describes four keys correctly: `spectrum-trim` also takes `restrained`, `motion` reaches the exported player, `paginate` treats anything but `false` as on, and `debug` accepts `off`. The logo-size help text says an out-of-range value is clamped, which is what the engine does.
