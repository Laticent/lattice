- The Studio editor now completes everything the Playground editor does, because both run one shared list of completion sources: slide directive names after `<!-- _`, `_focus:` axes and `_focusStyle:` values, the keys of a nested `backdrop:` map, Mermaid keywords inside a `mermaid` fence, a component's slot skeleton on an empty slide, and region names on a `map` slide. Inside a nested `backdrop:` map the editor used to offer the deck's top-level keys; it now offers the map's own.
- Each platform's usual key opens suggestions in every Studio editor and the Playground: Ctrl-Space, plus Option-Esc on a Mac, where macOS uses Ctrl-Space to switch the keyboard input source. Tab now accepts a suggestion as Enter does, and only while the menu is open. Where nothing completes, the editor shows "No suggestions here" instead of doing nothing. The `?` shortcut list has an Editor section with these keys.
- Picking a front-matter key whose value completes (`theme`, `finish`, `pace`, …) opens its values at once, and a key the front matter already sets is no longer offered again.
