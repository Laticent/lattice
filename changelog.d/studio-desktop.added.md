- **Find and replace in the Studio's Markdown editor.** Press Ctrl+F (Cmd+F on a Mac), use the new Find button in the editor header, or pick "Find and replace in source" from the command palette; phones reach it from the Menu's command sheet. The bar counts matches ("3 of 12"), searches as you type, and has Match case, Whole word and Regular expression options. Ctrl+H (Cmd+Alt+F on a Mac) or the chevron opens the Replace row; Enter replaces one match and Ctrl+Enter replaces all. It is built from the Studio's own controls and colors, so it follows every palette in light and dark.
- To make room for the Find button, the editor header's Add, Reshape, Fix all and Refine buttons now show their text labels only when the editor pane is at least 44rem wide, and the "Edit" eyebrow hides on panes narrower than 26rem. The header stays on one row at every measured width from 820px to 1920px; it used to wrap to two rows at 1280px and 1390px whenever text was selected.
- **Lattice Studio for Linux (preview).** `desktop/` builds the Studio as a desktop app with Tauri 2 on WebKitGTK and packages it as a `.deb`. It is the same Studio as the website, running from the bundled build. Every export (PDF, PPTX, Markdown, `.lattice`, zips) now saves through the native file dialog instead of a browser download. Build steps are in `desktop/README.md`; why the app is shaped this way is in `engineering/decisions/2026-09-24-lattice-studio-desktop.md`.
