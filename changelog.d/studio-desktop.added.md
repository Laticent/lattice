- **Find and replace in the Studio's Markdown editor.** Press Ctrl+F (Cmd+F on a Mac), use the new Find button in the editor header, or pick "Find and replace" from the command palette; phones reach it from the Menu's command sheet. The bar counts matches ("3 of 12"), searches as you type, and has Match case, Whole word and Regular expression options. Ctrl+H (Cmd+Alt+F on a Mac) or the chevron opens the Replace row; Enter replaces one match and Ctrl+Enter replaces all. It is built from the Studio's own controls and colors, so it follows every palette in light and dark.
- **Find and replace in Compose.** Ctrl+F in Compose opens the same find bar over the visual editor, with the same options and keys. It searches every slide and jumps to each match. Replace all is one undo step. Slides that Compose shows locked are searched but never changed, and the bar says how many matches it skipped. Ctrl+F anywhere else in the Studio opens the bar for the editor you are in.
- **Print opens the print dialog for every layout.** Print for 2-up, 4-up and the notes handout used to build a PDF and open it in a new tab to print from there. It now prints the same pages straight through the print dialog, as 1-up always did. Ctrl+P opens the Print deck panel.
- To make room for the Find button, the editor header's Add, Reshape, Fix all and Refine buttons now show their text labels only when the editor pane is at least 44rem wide, and the "Edit" eyebrow hides on panes narrower than 26rem. The header stays on one row at every measured width from 820px to 1920px; it used to wrap to two rows at 1280px and 1390px whenever text was selected.
- **Lattice Studio for Linux (preview).** `desktop/` builds the Studio as a desktop app with Tauri 2 on WebKitGTK and packages it as a `.deb`. It is the same Studio as the website, running from the bundled build. Every export (PDF, PPTX, Markdown, `.lattice`, zips) now saves through the native file dialog instead of a browser download. The app's window never leaves the Studio: links to other sites open in your default browser, the mouse back button and swipes do nothing, and right-click shows only cut, copy, paste and spelling. Connecting OpenRouter opens its sign-in page in a separate window that closes itself once you approve. Build steps are in `desktop/README.md`; why the app is shaped this way is in `engineering/decisions/2026-09-24-lattice-studio-desktop.md`.
- **Lattice Studio for Windows (preview).** `npm --prefix desktop run build:windows` cross-builds an NSIS installer (`*_x64-setup.exe`) from Linux with `cargo-xwin`. The installer is unsigned, installs for the current user, and fetches Microsoft's WebView2 runtime if the machine lacks it. The owner's first run on Windows 11 passed 21 of 29 checks; this release fixes the three failures it found (Edge's find bar in Compose, Back returning to the OpenRouter page, and Print saving a PDF), and turns off WebView2's own shortcuts and right-click menu.
- CI builds Lattice Studio's `.deb` whenever `desktop/` changes (`.github/workflows/desktop.yml`), runs the Rust tests, cross-builds the Windows installer, and keeps both packages as downloadable artifacts for 14 days.
