- **Drop a deck file anywhere on the Studio to open it.** A `.lattice`, `.md`, `.html`, or a
  PDF or PowerPoint exported "Re-openable in Lattice" now opens as a new deck when you drag it
  onto the Studio, through the same reader and checks as **Import deck…**. A sign shows where
  the drop will land. The Library and the editor keep their own drops, and a drop never changes
  the deck you have open. (`docs/src/components/studio/deck-drop.ts`)
