- **Fixed: the Studio editor's loading status is now reachable in the accessibility tree.** `EditorSkeleton` wrapped its whole subtree — including the `sr-only` "Loading the editor…" status span — in `aria-hidden="true"`, which removes the entire subtree from the accessibility tree, so the status was invisible to assistive tech. `aria-hidden` now sits on the decorative gutter/line blocks only, and the status span carries `role="status"` outside it, mirroring the `ComposeSkeleton` fix that shipped alongside it in #1727.
