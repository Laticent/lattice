- **Studio:** the Architect chat no longer hangs the page while a reply streams. Each streamed frame re-rendered the whole panel and re-ran the sanitizer over every earlier reply, so the cost grew with the length of the thread: at 4x CPU throttle a fifth turn produced hundreds of long tasks against 6 on the first. The reply being written now repaints alone, settled replies are never re-rendered, and the paint rate backs off when frames get expensive. While a reply streams, the transcript follows it only while you are at the bottom, so you can scroll up and reread; it returns to the bottom when the reply finishes.
- **Studio:** the live preview no longer keeps the browser busy after it loads. A deck with no diagram ran a 60 Hz frame loop for ten seconds after every preview rewrite, waiting for a Mermaid library it did not need; an idle Studio now schedules no frames at all (about 180 frame callbacks in 3 seconds before, 0 after).
- **Studio:** a collage photo now pops and its neighbors recede when the mouse is over it in the live preview, as they already did in the Playground. The preview box takes no pointer events, so the host now hit-tests the pointer and marks the photo (`data-host-hover`), the way code-block copy buttons already worked. The code-block marker also stops rewriting an attribute that has not changed on every mouse move.
