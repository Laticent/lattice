- **Studio: the slide preview refuses any script it did not write.** The preview frame's Content Security Policy now carries a per-page nonce `script-src` with `'strict-dynamic'`, so an inline event handler or `<script>` in a shared deck cannot run there even if the slide sanitizer missed it. The author's AI keys no longer rest on the sanitizer alone. The CLI export and the other preview surfaces are unchanged.
- **Runtime: `lattice-runtime.js` no longer trusts a clobbered `document.currentScript`.** A deck element named `currentScript` could stand in for the runtime's own `<script>`, and the runtime would load its dagre and plugin-data files from that element's URL. It now accepts only a real `<script>` element.
