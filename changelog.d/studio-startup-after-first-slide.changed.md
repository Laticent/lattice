- The Studio no longer loads code for panels you have not opened while it is still showing your first slide. Compose, Present, the reading view, the Share and Workspace panels and the lint checker now load after the first slide is on screen and you pause typing for 3 seconds. On a throttled phone profile the main thread is about 30% less busy in the seconds after the slide (1.7 s against 2.2-2.5 s of work in the first 3 s).
- A deck that only mentions math inside inline code (such as `` `$x$` ``) no longer makes the Studio download the 20 math fonts and reload the theme. Exported files are unchanged.
