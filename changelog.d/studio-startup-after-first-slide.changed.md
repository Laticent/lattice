- The Studio no longer loads code for panels you have not opened while your first slide is still coming in. Compose, Present, the reading view and the Share and Workspace panels now load after the first slide is on screen and you have not clicked or typed for 3 seconds. The editor's lint and the Coach's first assessment wait for the first slide. On a throttled phone profile the main thread is about 30% less busy in the seconds after the slide (1.3-1.6 s against 2.2-2.5 s of work in the first 3 s), and the first slide arrives a little sooner (5.8-6.4 s against 6.2-7.7 s).
- A deck that mentions math only inside code (such as `` `$x$` ``) no longer makes the Studio download the 20 math fonts and reload the theme. Exported files are unchanged.
