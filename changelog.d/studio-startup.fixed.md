- **The Studio writes its live preview once on a first visit.** A second render that started while the first write was still loading used to write the whole document again, which parsed the 1.2 MB sheet twice at cold start (14 of 23 loaded first visits on `main`). It now waits for that write to load and patches it: 24 of 24 loaded first visits write once. On a slow device (Chrome's CPU throttled 20x) a first visit writes once and shows the slide 5.2 to 7.8 s after the first write, against three or four writes and 7.4 to 8.3 s before.
- **The chat chip names your OpenRouter model on a slow start.** When the Studio read the chat status before the model catalog had loaded, the chip showed only the tail of the model's id ("Model") until you opened it. It now fills in the catalog name and price when the catalog arrives.
