- The Studio no longer slows down as saved work piles up. Opening a deck used to read every saved version of every deck into memory, and to read and parse every deck's text just to name it in the deck list. Now a deck's versions load when that deck opens, and the list takes each deck's name from a small record written whenever the deck is saved. Details: `engineering/decisions/2026-11-11-studio-storage-pointer-records.md`.
- A deck save the browser refuses, most often because its storage is full, now tells you so with a notice that stays until you dismiss it. It used to fail silently, and your latest edits were lost on reload.
