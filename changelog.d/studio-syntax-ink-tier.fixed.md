- The Studio's code editors, its chat code blocks and the public Playground editor now paint keywords, strings and numbers from a derived **syntax ink tier** (`--syntax-keyword-ink` / `-string-ink` / `-number-ink`) instead of `--pass`, `--warn` and `--accent`. Strings and numbers are seeded from each palette's own `--hljs-*` code color — so the editor and the deck's rendered code panel agree on what a string looks like — and every role is solved onto the editor's own canvas: worst 4.65:1 against `--bg`/`--bg-alt` across all 18 base palettes in both modes. Reading `--hljs-*` directly would have been worse than the status tokens: 21 of 36 palette-modes put a raw syntax color below AA on the editor canvas, worst 1.01:1.
- **Editor keywords and Markdown headings are legible on every palette.** They were painted with `--accent`, which carries no contrast guarantee against the canvas: mustard/light read at 3.89:1 and burgundy/dark at 4.60:1. The other 34 palette-modes are visually unchanged, because a seed that already clears comes back untouched.
- **On `a11y-achromatopsia` the editor painted number literals byte-identical to comments** — the shipped `--warn` and `--text-muted` are both `#6E6E6E`, on the one palette with nothing but lightness to separate anything with. The string and number inks are now held apart from each other and from the text roles.
- On the four `a11y-*` palettes the string/number seeds come from that palette's own `--pass`/`--warn` pair rather than `--hljs-*`, because the inherited syntax pair (green 144° / yellow-green 104°) sits on the red-green axis those palettes exist to avoid. Achromatopsia gets its deliberate two-step grayscale. The emitted values there are therefore the status colors themselves — the decoupling below applies to the 14 hued palettes, not to those four.
- Retuning the status trio no longer repaints code on the hued palettes. Demonstrated during this change's own rebase: #1704 moved `--pass`/`--warn` on six palette-modes, which under the old code would have silently repainted string and number literals in the Studio's editors — from a PR about the surfaces components compose, with no editor in its diff.
- The Anima scene prompt no longer teaches `var(--text)`, a token the engine does not declare. The recommended scene palette is a real list the prompt is generated from, gated against the engine's own declarations, so a phantom token cannot be taught again.
