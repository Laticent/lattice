- `dist/styles/` — `lattice.css` cut into ordered style modules (187 today) plus a `manifest.json` (id, file, bytes, SHA-256, source). Joined in manifest order (the manifest's `note` gives the separator rule) they are `lattice.css` byte for byte, and no existing file changes. The package gains this folder and `dist/styles-min/` (about 0.94 MB gzipped together). First step toward loading only the CSS a deck uses (`engineering/decisions/2026-10-18-on-demand-styles.md`).
- `dist/styles-min/` — the minified twin of `dist/styles/`: same ids, file names and order; concatenating the files is `lattice-min.css` byte for byte (about 0.98 MB raw, 0.14 MB gzipped).
- `tools/style-baseline.mjs` — prints how much CSS a rendered deck carries and how much it uses, on Chromium and WebKit.
- `tools/style-needs.js` and `tools/style-needs-audit.mjs` — say which style modules a rendered document needs, with an audit that checks no needed module is skipped, in Chromium and WebKit (results in the decision note).
- `npm run branch:owner` (`tools/branch-owner.sh`) — lists the sessions whose commits are on a branch, so a session does not push to one another session owns (HARD RULE #31).
