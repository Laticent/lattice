- **A table of three or four columns turns into cards on a phone instead of running off the page.** Such a table now switches to its narrow card layout when its text column is under 24em wide, as wider tables already did, so a three-column table on a phone square or portrait slide no longer loses its last column past the edge. A table that still fits as a grid there now reads as cards; if the cards would not fit the slide, the table keeps its grid.
