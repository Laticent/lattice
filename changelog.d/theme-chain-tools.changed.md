- The five remaining `@import` flatteners in `tools/` now walk the declared theme graph instead of re-deriving it. `derive-cat-ink`, `derive-chart-cat-ink`, `contrast-audit`, `cvd-audit` and `build-docs-portal` each carried their own regex for "what does this palette extend" — the exact duplication the manifest-as-contract change removed from the four shipping paths, left behind because these read source-form themes off disk where the minified-form divergence cannot bite. All five call `themeChain()` over the manifest-baked edge map now, and `build-docs-portal` asks the manifest rather than the stylesheet which palettes are selectable. No output moves: the replacement is byte-for-byte identical to each old flattener across all 32 palettes (with reversed-order and leaf-only negative controls firing), every tool's report is unchanged, and `npm run build` regenerates `dist/` and the committed theme ink blocks with an empty diff.
- The docs site's palette picker gained a test for the one question it asks. `listBasePalettes()` decides which palettes the picker offers, and the edge map it consults has two shapes — the generated one omits root palettes, the manifest builder keeps them with an undefined value — so a predicate written against one of them silently empties the picker under the other. It now routes the question through `themeChain()`, which reconciles both, and `test/unit/theme/base-palette-predicate.test.js` drives the real function with each encoding.
