- A theme's name now has one owner: `themes/<name>.manifest.json`. The filename and the `@theme` directive are projections of it, and a new `check:ownership` gate fails if any of the three disagree. They agreed by discipline before, but nothing checked — `themes/foo.css` declaring `@theme bar` would pass every gate and register under a name no picker, manifest, or `@import` referred to.
- `addThemes()` accepts `{ name, css }` alongside a bare CSS string, on both the engine (`./engine`) and `window.LatticePlayground`. Passing the name is now the contract: every caller in the engine, CLI, and docs already had it and was discarding it, leaving the store to recover it by regex. A second gate keeps new callers in `lib/`, `docs/src/`, `tools/` and the emulator on the object form; it parses a real AST rather than scanning text, so a regex literal or a template can't hide a call site from it.
- Fixed: registering a stylesheet with no `@theme` directive scanned the entire buffer before giving up — hundreds of microseconds on a large sheet — and then registered nothing while returning a `false` no caller checked, so the theme vanished and the deck rendered unstyled with no signal. The legacy scan is now bounded to the file header.
- Fixed: a *named* registration could hit the same silent failure. `add(name, undefined)` discarded the name and scanned it as a stylesheet, and `add(name, null)` returned `true` while storing `null` — leaving `hasTheme(name)` permanently true, disarming the Playground's theme self-heal, while renders came back unstyled. Both now throw.
- **Breaking (narrow, external consumers only):** the bare-CSS form of `addThemes()` now looks for `@theme` in the first 4096 characters instead of the whole file. Every stylesheet Lattice ships declares it within 1005, so nothing in the package is affected — but a vendored or concatenated sheet carrying a banner longer than that before its directive will no longer register. Pass `{ name, css }` (or move the directive to the header) if you have one.
- `@theme` deliberately stays in source theme CSS, unlike `@size`: `@workwel/lattice/themes/<name>.css` is a published export documented as a Marp theme file, and Marp throws without the directive.
