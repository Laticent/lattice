- **Fixed: a theme that merely MENTIONED another palette in a comment inherited the whole thing.** A header comment reading `/* … like @import 'onyx'; but warmer … */` made the engine splice all 768 KB of `onyx` into a theme that declared no parent — and since comments are stripped afterwards, the rest of that sentence was left behind as live CSS, read as a selector, and swallowed the rule following it (a theme's own `@font-face`, in the case that surfaced). The Theme Studio puts a user's free-text description straight into that comment, so any description mentioning a palette by name was enough. The engine no longer reads a theme's comments as imports; everything else about the stylesheet comes back byte-identical, and composed output is unchanged for all 32 shipped palettes.
