- **Trama, the graph-chart library (`@laticent/trama`).** The flowchart's layout engine and browser pipeline move into a workspace package: dagre places the boxes, one solver routes every line, and a pipeline measures a chart in its own fonts, fits it, lays it out in a worker while you type in the Studio, and paints it through a chart adapter. It has no dependencies (dagre is passed in) and knows nothing of Markdown or CSS. Flowcharts draw exactly as before.
