- A new library, **Veduta** (`@laticent/veduta`, `docs/src/lib/veduta`): a headless, dependency-free core that decides which units of a long list a view should mount, at what fidelity and in what order, for a stage and a map beside it. Three window policies (single, multi, picture-in-picture), a fidelity ladder, a page-global live budget priced per connector, and a capacity the host reports. It costs the same at 120 and at 100,000 units, and its window equals the Playground filmstrip's. Has a mark, a catalog entry, a guide page and a demo page on the docs site; not yet published to npm.
