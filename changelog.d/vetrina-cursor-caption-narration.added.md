- **Vetrina — `caption: 'cursor'`**, a fifth narration style: a speech balloon anchored where the cursor is resting, which steps aside while the cursor performs (typing, clicking, dragging, a deictic stroke) and comes back when it stops. It never follows the pointer — a caption that drifts during a fixation cannot be read — and Exit moves to a persistent corner chip, so a caption that can hide never takes the escape hatch with it.
- **Vetrina — `bounds: 'host'`**, which confines the tour's chrome to the `root` element it drives instead of the window. It is a clamping box, not a containing block: the overlay layer stays `position: fixed` and click-through, and no host CSS has to change. This also fixes the `bar` style's `width: calc(100vw - 24px)`, measured at 704px of caption inside a 642px app.
- **Vetrina — a narration port (`Narrator`, `SILENT_NARRATOR`, `findCueWord`)** plus a Cadenza-backed adapter at `docs/src/lib/vetrina-narration/`. Wiring one in gives every `say` beat the line's real duration instead of a reading estimate, and a word clock — both with no audio, since a timed track is text arithmetic.
- **Vetrina — `Step.at` / `scene().at(word)`**, the word cue: the beat's action lands on the word that names it. Whichever side is behind waits, so the cursor arrives exactly as the narration reaches the word (measured: 1 ms). Degrades to the beat's normal order with no narrator, or when the line does not contain the word.
- **Vetrina — `pacing.ts`**, one cited duration model behind the five hand-tuned literals: Fitts's law for cursor travel (target size finally matters), a caption reading budget matched to Cadenza's 150 wpm and pinned to it by a cross-library test, a register beat that costs nothing when the cursor is already on target, and a typing reveal above the ~40 ms threshold at which characters stop resolving as separate events. **It is opt-in** — `theme.pacing` defaults to `'legacy'`, which reproduces the old literals byte for byte, because adopting the grounded numbers re-times an existing tour by ~21% and that is a decision, not an upgrade side effect.
