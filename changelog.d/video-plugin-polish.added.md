- The video plugin has its own page on the docs site (a live demo with three examples and a Learn page), a refreshed mark that matches the other plugins, and a full reference: the four providers with every address form each accepts, the layouts, the Studio player, exports and migration. The Plugins hub counts nine.
- A demo deck, `examples/video-plugin.md`, shows all four providers (YouTube, Vimeo, TikTok, Instagram), the companion, gallery and code layouts, the accepted address forms and a slide with no poster. The plugin's conformance cases and the Studio's player check now cover every provider, not only YouTube.
- `lint:deck` warns when an `@video{…}` record is on a slide that is not a `video` slide (`video-slide-class`), where it used to draw an unstyled blue link and say nothing; the clip is now a quiet text link in the deck's accent, and when a `video` slide holds a second record (`video-extra-record`), which used to drop the second clip silently.
- In the `gallery` layout the provider's badge now sits on the matte's lower edge. With a portrait or square poster (the usual shape of a TikTok or Instagram thumbnail) it used to hang off the picture's corner.
