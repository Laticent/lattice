- **On desktop, the Studio narrates with the on-device Kokoro voice by default.** The first read starts its download in the background, using the cloud voice when one is connected and captions only when none is. Later reads use the local voice, which is free per clip and works offline. A cloud model you picked yourself still takes precedence. Phones and tablets keep the cloud voice. (`docs/src/playground/voice-model.js`)
- **New Workspace switch: "Always use the cheapest voice"** (off by default). It narrates with the lowest-cost paid cloud voice, counting what a model charges for the audio it produces as well as the text you send. Within 10% on price, the better voice wins. It never picks a voice ranked below Kokoro, however cheap, so it can move to a better voice but never to a noisier one. Free, rate-limited voices are skipped, and a voice you picked always takes precedence. Hosted Kokoro stays the cloud default: Gemini 3.8 Flash TTS lists $0.50/M but was billed about $18.50 per million characters once its audio output was counted, about 30× Kokoro. (`docs/src/playground/tts-cost.js`)
- **Fixed:** the narrated-export cost quote now counts the audio a voice produces, not only the text sent. It had quoted Gemini voices about 37× too low.
- **Fixed:** picking Gemini 3.8 Flash TTS or Flash Lite TTS in the voice picker failed every clip with a 400 error, because those models only return raw PCM audio. The whole Gemini TTS family is now requested as PCM.
- **Fixed:** the on-device voice failed to load on a browser that exposes WebGPU with no usable GPU (Linux without GPU acceleration, VMs, blocklisted GPUs). It downloaded the ~330 MB full-precision model and never came up. It now checks for a usable GPU first and loads the smaller ~80 MB model otherwise. It also retries on that model if the GPU load fails.
