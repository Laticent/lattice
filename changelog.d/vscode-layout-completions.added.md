- **Layout names as you type in VS Code.** The Marp kit ships `lattice-layouts.vsix`, a small extension: type `<!-- _class: ` and a menu lists every layout with its one-line summary, again after a space for a second class. It answers nowhere else, so typing prose never opens a menu. Install it with **Extensions → ⋯ → Install from VSIX…** or `code --install-extension lattice-layouts.vsix`. An Export-to-Marp bundle's README links to the kit's copy.
