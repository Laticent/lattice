- **Breaking:** `numbered` no longer numbers a `list`. The marker decides in every register: a `1.` list numbers its rows and a `-` list does not. So a `list takeaway` written as `1.` without `numbered` now shows its counters (they were hidden). A deck that wrote `list takeaway numbered` over `-` items loses its counters until the items are written as `1.`; `lint:deck` names each such slide (`list-modifier-inert`). The repo's own decks are migrated.
- **Breaking:** `ledger-inline-title` is deprecated and no longer emitted. The inline `- **Title.** body` shape on a ledger layout (agenda, kpi, list-steps, …) is now reported as `card-style-inline-title`, whose autofix keeps your marker instead of rewriting it to `1.`.
- One list contract for every layout. Each component that reads a list now declares what `1.` versus `-` means on it (`lists` in its manifest): `prose` (`content`, `list`: `1.` numbers, `-` bullets), `numbered-tags` (`cards-grid`, `cards-stack`, `list-steps`, `split-panel steps` and `watermark`: `1.` turns the number tags on, `-` leaves them off) or `neutral` (every other layout: both render the same). The engine enforces it before any layout reads the slide (`lib/core/list-contract.js`), so `agenda`, `kpi`, `stats`, `premise` and `list-tabular` no longer collapse on `-`; `cycle`, `inventory`, `glossary`, `pricing`, `logo-wall`, `big-number`, `policy-recommendation`, `verdict-grid` and `journey` no longer collapse on `1.`; and the thirteen chart kinds that read nested rows draw the same chart from nested `1.` rows.
- `list-steps` written as `-` renders the same step cards without the STEP tag (it collapsed to plain text), and `list principles` written as `-` draws a dot before each principle (it fell back to the default pills).
- `slot-contract` no longer reports a list marker: on every layout that reads a list, either marker renders as its contract says.
- A list inside a blockquote (a Key Insight callout) is left as you wrote it on every layout.
