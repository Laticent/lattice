- **Closed 30 ways a deck's CSS or HTML could load a web resource past Lattice's web-reference checks.** A CSS string a form feed or carriage return ends, escaped or string-only spellings of a URL, character references and attribute separators the HTML parser accepts, an SVG `<style>` the regexes read as plain text, and an address in an SVG paint attribute, an SVG filter image or a table's `background` each let a stranger's gallery past the Library's Insert gate or a deck's images load in the Studio's Reading view without the reader's say-so. Every check now reads CSS with one tokenizer and HTML tags with one scanner, and markup inside `<svg>` that the scanner cannot model is checked with the page's own HTML parser.
- In the Studio's Reading view, which has no content-security policy behind it, a deck's web fonts now wait for the reader's choice like its web images.
- A crafted deck could freeze the Studio while its web images were being blocked: two regexes took 25-50 seconds on 1,000 repeated fragments. The scanner that replaces them reads the same input in milliseconds.
