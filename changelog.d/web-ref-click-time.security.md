- **The web-reference scanner now removes a web `ping`, `action` and `formaction`.** They send a request when the reader clicks a link or submits a form, not when the page renders, so the scanner had left them in place; the Reading view and the preview frame stopped them with the slide sanitizer and the content-security policy, but a host with neither (the `fonts: true` mode) did not. A web address in one now goes, with its attribute, and appears in `blocked` with its origin so a host can offer to approve it; a relative address, a fragment or an approved origin stays. Exported files change only for a deck that carries a web `ping`, `action` or `formaction`: all 384 decks under `examples/`, the baseline decks and `exemplars/` export byte for byte the same.
