- On Windows, when a render with a code package or npm plugin runs out of time, Lattice no longer kills the sandbox browser by its process id. By then Windows has usually ended the browser already and may have given that id to another program, which Lattice could have killed instead. Lattice now stops the processes that name the browser's temporary profile folder, its helper processes included, and then removes the folder. It falls back to the process id only when that search cannot run.
