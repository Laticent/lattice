- **Windows: npm plugins are no longer refused because a renderer was still starting.** The code sandbox reads Chromium's `chrome://sandbox` page to confirm its OS sandbox is on. A renderer that is still starting is listed there as not sandboxed for a moment, and one such reading made the sandbox measure OFF, so the npm plugins in a deck were refused on a machine whose sandbox was on. It now reads the page again and counts a renderer as unsandboxed only when it stays that way, as every renderer does in a browser started without the sandbox.
