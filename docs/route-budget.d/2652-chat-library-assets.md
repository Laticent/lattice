The Studio chat can now use Library photos. CI measured +74 bytes gz of eager Studio JavaScript against main on the final code; the declared figure leaves room for gzip spread between builds. The growth is in the two modules the Studio already loads eagerly: a small getter in `media-urls.ts` that the chat reads to learn which deck is open, and the caption field and its writer in `media-store.ts`. Everything else is in the lazy chat-agent chunk: the Library list, the three tools, the thumbnail code and the caption cleaner (`agent-assets.ts`, `agent-assets-browser.ts`), so a Studio that never opens the chat does not load them.
