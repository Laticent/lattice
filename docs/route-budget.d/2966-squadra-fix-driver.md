"Fix all" in the Studio now runs through Squadra's fix driver, and the driver is NOT in the lint core: lint-core loads it on demand (`loadFixDriver`, an `import()` that the ESM build splits into a chunk of its own), so it costs nothing until "Fix all" is pressed. What stays in `esm/lint.js` is the loader and `fencedLines` (lint-core's rules and the fix-line walk now skip code fences); the bridge takes the slide split and the fence reader from lint-core as arguments, because a module both sides import becomes a shared chunk of its own, which cost 1.7 KB gzipped. `esm/lint.js` and its static imports beyond the engine measure 125,034 bytes gzipped on main and 125,459 here (+425), built by `tools/build-playground.js` on both. The first version of this PR bundled the driver statically and measured 130.7KB in CI, past the 122.3KB ceiling; that is what made it load on demand.
