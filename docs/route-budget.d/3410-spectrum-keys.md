The spectrum keys (#3410) give the Studio a new weight axis and a mirror of the three keys' axes (spectrum-keys.ts, spectrum-weight-catalog.ts), so the deck and slide panels can read and write one axis at a time. That growth took the Studio's eager JS 0.2KB past its ceiling, so the PR gives back more than it adds: the deck-level `backdrop:`, `tag:` and `image-card:` tables move from slide-provenance.ts to deck-axes.ts, and the slide drawer's provenance code now loads with the drawer (SlideContext, lazy) instead of at Studio start. Measured locally, the Studio's eager JS falls by 2,014 bytes against the PR before the split, which leaves it below `main`, so it declares no growth. The playground and home grow by the new key names in the meta-keys table.
