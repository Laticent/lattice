Every key a deck's front matter can carry. To learn how front matter works, and
which settings most decks want, start with [Deck settings](/guides/deck-settings/).

This page is **generated** from the engine's table of front-matter keys
(`lib/core/deck-settings.js`), the same table the Studio editor completes from and
`lint:deck` checks against. A key Lattice does not read draws an `unknown-key`
warning, and a value outside a key's list draws `unknown-<key>`, so `finsh: halo` or
`size: huge` is caught instead of rendering the default. Marp's own keys (`marp:`,
`headingDivider:`, `author:` and the like) are accepted and ignored, and are not listed
here. The groups match the
sections under **Settings → Deck** in the Studio, in the same order.

For an editor outside the Studio, `npm run build` writes the same table as a JSON
Schema, `dist/schemas/front-matter.schema.json`. Point your editor's YAML support at
it to complete keys and values as you type.

**One slide** can differ from the deck through the per-slide form a row names.
Where it reads `<value>`, put the value there: the deck's `spectrum: off` is
`spectrum-off` on one slide. Not every value has a class (there is no
`spectrum-on`, because `on` is what a slide gets with no class), and a key whose
row names no per-slide form, such as `theme:` or `size:`, applies to the whole
deck only.

The [LFM specification](/spec/lfm/) defines a portable subset of these keys, for
tools other than Lattice. This page is what Lattice itself reads.
