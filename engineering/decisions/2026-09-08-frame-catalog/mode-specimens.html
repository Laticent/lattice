Lattice · Finish · Specimen sheet 03 mode: — the deck-wide hand

Mode Specimens

Six postures, rendering the same content so the only variable is the hand. Every lever below moves one of the contract's six channels across all six at once — and the Frame lever changes the reading, which no Mode is allowed to touch. If a hand survives every lever and every frame, it is a Mode; if it only works at one setting, it is a look.

01 / How to read the bench

The levers are the contract

Each control is one of the six channels a Mode value must set — type is fixed per Mode (it is the strongest carrier of a hand and not worth randomizing), and line, box, mark, measure and ornament are yours to move. A Mode that only reads correctly at its own default is not robust enough to ship.

The Frame lever proves M2

Changing Frame changes the reading — where the thesis sits, what holds the reserved position. Every Mode must survive all five without redefining itself. That is clause M2, and it is the reason Frame and Mode compose instead of collide.

Watch for M4 failures

Switch components and look for a shape that snaps back to the baseline hand. That is total-coverage failing, and it is the state sketch is in today — boxed blockquotes and bordered rows still bend a CSS radius while everything around them is drawn.

02 / What is real and what is a stand-in
