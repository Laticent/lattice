## Method and artifacts

- Decks: `decks/<component>.md` (one slide per universal appended to the manifest `sample`), `decks2/` (eyebrow/subtitle re-probe that REPLACES the sample's own kicker/subtitle), `decks/posters*.md` (targeted re-checks).
- Render: `node lattice.js <deck> <html> indaco -q --no-split`, opened in puppeteer/Chrome; `probe.js` walks each slide for the marker text, its DOM chain, visibility (display/opacity, inside slide, ancestor clip, elementFromPoint) and the CLI's OVERFLOW page list. Raw: `results.json`, `results2.json`, `classified.json`.
- Lint: `node tools/lint-deck.js --json` per deck, `lint/<component>.json`; a finding counts only if absent on the bare slide.
- Screenshots: `kpi-coda.png` (4th tile clipped under the coda), `premise-eyebrow.png` (eyebrow = raw code chip as a 3rd column), `premise-subtitle.png` (list collapses off-slide), `mg-coda.png`.
- Not probed (UNVERIFIED): annotation (`_italic_` trailer), labeled corner tag, universal variants (covered by `npm run check:modifier-effects`), sparks, `_build`, registers, logo, header/footer chrome, PPTX/PDF notes channel.
