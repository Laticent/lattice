# Which dot is this name?

`quadrant · scatter · the shared label kernel`

A crowded plot asks the reader two questions. **Which mark does this name belong to**, and **in what order do these names go?** The label kernel now answers both — a hairline from a name that had to travel, and a column that never reads against the dots it labels.

---

<!-- _class: statement silent -->

## Beside is not the same as nearest.

`placeLabels` has always kept a name **beside its own mark**. On a crowded plot that stops being enough: measured on the stress slide two pages on, six of fourteen names sat closer to another initiative's dot than to their own. A quadrant carries no leader lines, no value pills and no axis to read a position off — proximity was the only channel it had, and it gave the wrong answer six times.

## One emitter, one hairline, one rule.

The leader lives in the shared label kernel and both charts draw the same mark from it — quieter than the type, springing from the mark's rim, stopping short of the box. The order preference lives beside it, priced in the same currency as the eight anchor positions: enough to buy the whole vertical family before it gives up on the order, and not enough to buy a name set sideways.
