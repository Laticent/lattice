# One word picks the type

`typography:` chooses the heading and body faces, the eyebrow and the chart text together. This slide is `classic`, the default.

---

`Classic · the default`

## Playfair Display over Outfit

- The eyebrow above now speaks in the heading face's italic, not the header's mono capitals
- The header, meta line, footer and page number keep their mono voice, so they read as the frame
- Every deck that names no set gets this look; its faces are unchanged

## Newsreader over Inter

- Each face carries its own size factor, so the x-height a reader sees holds wherever Inter or Newsreader is drawn

- Newsreader has tabular figures, so it also sets the chart's data labels
