# @laticent/lattice

Lattice follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html) with one explicit
contract: **layouts and palette tokens are stable surfaces.** Breaking changes to either are major
version bumps. New layouts and new themes are additive minor versions. Mermaid CSS overrides are
internal and may change in patch versions.

`changeset version` writes each release's section below. The history before the first npm release
is in [`changelog/pre-release-archive.md`](https://github.com/Laticent/lattice/blob/main/changelog/pre-release-archive.md).
