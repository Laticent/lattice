# Lattice 1.0.0

Lattice turns a Markdown file into a laid-out slide deck: PDF, PowerPoint, LibreOffice Impress,
PNG or HTML. 1.0.0 is its first release on npm.

```sh
npm i -g @laticent/lattice
lattice deck.md deck.pdf
```

It needs Node 22.13 or later. Installing downloads a Chromium build, which renders the slides.

`@laticent/trama`; Apache-2.0 for the other eight libraries below. Which part is which: [`LICENSING.md`](https://github.com/Laticent/lattice/blob/main/LICENSING.md).

## What you can do

- **Let Lattice do the layout.** You write headings and lists; it sets spacing, type size and
  pagination.
- **Pick from 80 slide components,** from title slides and comparison grids to Gantt charts,
  roadmaps, math proofs and legal clauses.
- **Choose from 14 palettes, each in light and dark, plus 4 more built for color-vision
  deficiencies.** Layouts take every color from the palette, so switching palettes recolors a
  slide without moving anything on it.
- **Export one source to five formats:** PDF, PowerPoint, LibreOffice Impress, a PNG per slide,
  and HTML. By default each PowerPoint and Impress slide is a picture; add `--editable` to get
  real text boxes in the deck's own font.
- **Write Mermaid diagrams and KaTeX math in the deck.** They render when you export.
- **Let an AI model write decks.** The agent kit packages the deck format and the component
  catalog for a model to read. It is not in the npm package: get it from the release zip
  attached here, or from the [`dist-kits`](https://github.com/Laticent/lattice/tree/dist-kits)
  branch.

## Twelve libraries, published separately

Each library is its own package, at `0.1.0`. A `0.x` library may still change its API in a minor
version. Only `@laticent/lattice` is stable: it makes no breaking change before 2.0.

| Package | What it does |
|---|---|
| `@laticent/ltt` | A file format for when each slide and caption appears, with types, a JSON Schema and a validator |
| `@laticent/cadenza` | Turns text into a timed caption track, and writes WebVTT and SRT |
| `@laticent/calco` | Turns rendered slides into editable PowerPoint and OpenDocument files |
| `@laticent/fluido` | Decides how content fits its box: which slides stay whole, which split across pages |
| `@laticent/lastra` | Reads, resizes, strips and re-encodes JPEG and PNG images |
| `@laticent/lente` | Shows one deck to several audiences, each a subset of its slides, without editing it |
| `@laticent/markup` | Walks HTML strings without breaking open tags, for highlighted code and rendered slides |
| `@laticent/mosaico` | Packs boxes into a container: grids, justified rows, exact small layouts |
| `@laticent/segno` | A parser builder for small notations, and the inline value notation decks use |
| `@laticent/segno-languages` | The deck model for Lattice-flavored Markdown, exported as `@laticent/segno-languages/markdown` |
| `@laticent/squadra` | A lint-and-autofix engine that rejects a rule until its own examples show it fires and its fix is safe |
| `@laticent/trama` | Lays out graph charts: connectors routed around boxes, and radial charts |

Installing `@laticent/lattice` pulls in the eleven it uses. `lente` works on Lattice decks but is
not an engine dependency: install it with `npm i @laticent/lente`.
