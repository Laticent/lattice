Lattice Frame Lab

Every component's gallery slides, rendered by the engine, in a frame you can narrow. The slide has no height limit: it grows to fit its content. The engine's shape labels are removed, so only the CSS responds.

Type
Prototype

Holds size: text stays at its 1280px-slide size, so a narrower frame has to reflow. This is the responsive test. Scales with frame: text is a fraction of the frame's width, so a narrower frame is a smaller copy of the same layout. Each slide is at least 16:9 for its width, so full-bleed slides with nothing in normal flow keep a shape; content can grow it from there. Red badges mark content, or the header and footer, spilling past the frame's right edge. They miss content that overflows a box inside the slide, such as a pill running out of its card, so look as well. Light mode, indaco palette.
