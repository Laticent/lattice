Edge-shift sweep: does choosing a different spectrum-bar placement MOVE anything on the slide? Renders one deck (every component's manifest skeleton in light and dark, plus plain slides carrying each state stamp) once per `spectrum-edge:` value with the running chrome on (header, footer, page number), measures every element's distance from each slide edge in Chromium, and reports any element whose position differs between placements. The bar is a real `border`, so it takes layout room and shifts the content box and every absolutely positioned element that measures from the padding box. `check:jank` asks whether a layout stays put as CONTENT grows; this asks whether it stays put as the BAR moves. `--placements`, `--components`, `--limit`, `--family`, `--theme`, `--tolerance PX`, `--no-dark`, `--no-chrome`, `--detail`, `--json`, `--advisory`. Exits 1 on any shift, 2 when it could not measure (no Chromium, or a placement that did not take effect, which would make it compare a deck with itself); on-demand, not a CI gate. Header of `tools/check-edge-shift.js` has the method.
