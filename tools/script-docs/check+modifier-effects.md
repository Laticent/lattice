Does each `_class:` modifier actually CHANGE the slide on the components the editor offers it on? Renders every component's sample and stress sample bare and once per modifier acting on a probed surface (heading, eyebrow, table, card row, card lift, card rail; chart motion by its host selector), re-probes each declared variant for the card surfaces, and fingerprints every element's computed style and box. Two identical control slides must match or the run fails. Compares against lib/core/modifier-effects.generated.json, which the editor's completion reads as the source for those surfaces. On-demand (about two minutes), not a CI gate.
