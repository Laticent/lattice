The REFEREE for `contrast:palette` — it re-renders all 32 palettes FOR REAL (the same `runEmulator` path as the integration tier, no swap, no simulation) and answers the two questions the fast sweep cannot ask about itself: does the sweep still AGREE with a native render, and what about the runs the sweep structurally DROPS. The sweep re-themes one render in place, which is what makes a per-PR 32-palette matrix affordable — and that speed rests on a TEXTUAL assumption about the export shell. An earlier version got the equivalent assumption wrong, inverted the cascade for 30 of 126 tokens, and reported confident per-palette numbers wrong in both directions; a human reading the diff caught it, and a reviewer is not a gate. Mermaid bakes its own stylesheet into the SVG, so no swap can move it and the sweep drops those runs — a native render scores them, recovering the coverage rather than merely disclosing it. ~11-13s per palette (~6-7 min for the matrix) against the sweep's ~70s, so: nightly, auditing the per-PR gate.
