A seeded fuzz of the web-reference scanners (lib/core/remote-ref.js) in Chromium, WebKit and Firefox. It generates CSS and HTML from the tokenizer rules (test/fixtures/web-ref-fuzz.js), rewrites each input with `blockWebImages` and `blockWebCss`, loads the result as a document and as a fragment against a loopback server, and fails on any request. It also loads each input unrewritten and reports how many fetch as written (about 16%: CSS 5%, HTML 25%), and it pins a request on an input only when it reproduces with that input alone. `--compose plain|reading|preview` runs the scanner alone, through the Studio's Reading view (scanner, slide sanitizer, scanner; stylesheet through the scanner and the style sanitizer) or through a preview frame (own origin allowed, `fonts: false`, sanitizer, content-security policy); `--playwright-chromium` uses Playwright's Chromium; `--scanner-file <path>` scans with a stub to show what the other layers stop alone. `--wide` adds click, submit and `rel=preconnect` inputs and an idle-connection oracle (`sees` in WebKit, `blind` in headless Chromium and Firefox). `--seed`, `--count` (the published run is 100000 per engine), `--from`, `--engines`, `--batch`, `--json`; `--ref <git ref>` scans with that ref's remote-ref.js, which is how to watch the fuzz fail on code before a fix. A 600-input Chromium slice runs on every PR in test/integration/invariants/web-ref-fuzz.test.js. On-demand otherwise (HARD RULE #22).
