A seeded fuzz of the web-reference scanners (lib/core/remote-ref.js) in Chromium, WebKit and Firefox. It generates CSS and HTML from the tokenizer rules (test/fixtures/web-ref-fuzz.js), rewrites each input with `blockWebImages` and `blockWebCss`, loads the result as a document and as a fragment against a loopback server, and fails on any request. It also loads each input unrewritten and reports how many fetch as written (about 16%: CSS 5%, HTML 25%), and it pins a request on an input only when it reproduces with that input alone. `--seed`, `--count` (the published run is 100000 per engine), `--from`, `--engines`, `--batch`, `--json`; `--ref <git ref>` scans with that ref's remote-ref.js, which is how to watch the fuzz fail on code before a fix. WebKit and Firefox install with `npx playwright install firefox webkit` in docs/ (plus `install-deps`). A 600-input Chromium slice runs on every PR in test/integration/invariants/web-ref-fuzz.test.js. On-demand otherwise (HARD RULE #22).
