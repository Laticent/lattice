Re-runs the pick-surface bake-off with real agents, so its numbers are harness-written not hand-transcribed (#1734, run in #1897). Spawns N Opus agents per condition, each in a temp dir holding ONLY its surface (components.pick.md vs components.json). The pin is the sandbox PLUS the deliberate absence of a `Read` grant: `--allowed-tools Read` is a whole-tool allow rule overriding the working-directory refusal — measured, an agent given it read a repo file outside its sandbox with `permission_denials` EMPTY. Without it, containment allows the in-sandbox read and refuses the rest, recording the attempted path. Writes each agent's RAW return, a per-call `tool_calls` ledger and the usage/cost accounting, then scores strict (`expect`) and defensible (`expect ∪ ok`) against committed ground truth, reporting strict-only misses separately so a defensible-but-wrong pick cannot hide. Distinct from `intent:pick-eval`, a LOCAL LEXICAL RANKER over pick rows that spawns nothing.
